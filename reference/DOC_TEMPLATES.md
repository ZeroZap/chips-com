# Documentation Templates

## 目标

本文提供知识库新增协议和实战文档时的统一模板，保证后续内容结构一致。

## 协议基础文档模板

```markdown
# 协议名称

## 定位

说明协议解决什么问题，常见在哪些芯片、模块或系统中。

## 核心特点

- 信号线数量。
- 同步或异步。
- 点对点或多设备。
- 全双工或半双工。
- 典型速率和距离。

## 硬件连接

说明引脚、收发器、电平转换、终端电阻、上拉/下拉、时钟和电源要求。

## 通信流程

说明初始化、读写、响应、错误处理和典型事务。

## 常见应用

列出典型芯片、模块和产品场景。

## 常见错误

用表格列出现象和优先检查方向。

## 延伸阅读

链接到 practical、deep-dive、debug 文档。
```


## 深入文档模板

```markdown
# 协议 Deep Dive

## 目标

说明深入主题和边界。

## 深度检查清单

```

## 故障案例模板

````markdown
# 故障案例：一句话现象

## 现象

描述可观测现象、发生条件、影响范围和复现概率。

## 环境

```text
主控 / 固件版本：
接口 / 速率：
从设备 / 模块：
工具 / 探头：
温度 / 电压：
```

## 排查过程

| 步骤 | 动作 | 观察 | 结论 |
| ---- | ---- | ---- | ---- |
| 1    |      |      |      |

## 根因

说明直接原因、根本原因和为什么现有测试没有拦住。

## 修复

说明代码、硬件、配置或流程修改，以及验证结果。

## 回归项

- 增加的最小复现用例。
- 增加的自动化测试。
- 增加的观测指标或告警。

## 经验

用 1-3 条可复用结论收尾。
````

## 评审 / 质量门禁模板

```markdown
# 通信设计评审

## 范围与风险等级

说明接口、速率、环境、法规和安全等级。

## 硬件检查

- 电平、电源、复位、时钟。
- 上拉、终端、偏置、隔离。
- ESD、浪涌、EMC。

## 软件检查

- 初始化顺序。
- 超时、重试、错误码。
- DMA、中断、缓存一致性。
- RTOS 并发和优先级。

## 协议检查

- 帧格式、地址、校验。
- 状态机和异常响应。
- 版本兼容和广播/多主场景。

## 测试检查

- 最小通信。
- 边界参数。
- 故障注入。
- 长稳和回归。

## 结论

| 项目                       | 结论 | 证据 | 负责人 |
| -------------------------- | ---- | ---- | ------ |
| 通过 / 有条件通过 / 不通过 |      |      |        |
```

## 网关设计模板

````markdown
说明上行协议、下行协议、点位规模、实时性和可靠性要求。

上行主站 / 云平台
  ↓
协议栈 A

```

## 点位映射
````
