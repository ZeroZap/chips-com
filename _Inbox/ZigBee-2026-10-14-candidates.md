# ZigBee 候选素材 @ 2026-10-14 22:45

## 协议速览
- 是什么:基于 IEEE 802.15.4 的低功耗 Mesh 组网协议(2.4GHz,DSSS,250kbps)
- 解决什么:工业/家居多节点自组网,弱信号自愈路由
- 跟 L4 关联:实验室 OK 产线挂的典型协议 — 抗干扰 / Mesh 拓扑 / 大规模组网是 L4 高频考点

### 1. Zigbee工业组网:当"自愈"变成"自杀"
- 链接:https://tsight.io/articles/12807223
- 来源:tsight.io(技术博客)
- 摘要:某化工厂无线传感器网关凌晨 3 点频繁掉线。频谱仪抓到金属罐体多径效应引发延迟抖动,触发 MAC 层重传;ED 持续偏高,父节点判定子节点丢失并发离网广播,瞬间广播风暴。
- 关键实战点:① 多径抖动可触发重传风暴 ② ED 偏高 + 重传 = 父节点误判孤儿 ③ 金属反射是隐形杀手
- 推荐动作:扩 deep-dive(写进"抗干扰边界"章节)

### 2. ZigBee Mesh 路由坍塌与抗干扰边界
- 链接:https://tsight.io/articles/10687747
- 来源:tsight.io
- 摘要:50+ 节点工业场景,Mesh 自愈演变成灾难。拓扑变化触发 Route Discovery 指数级广播风暴,Neighbor Table / Routing Table 迅速饱和,RREQ 溢出。
- 关键实战点:① 50 节点是转折点 ② Neighbor Table 溢出触发路由洪水 ③ RSSI 强不代表链路好,要 SNR
- 推荐动作:扩 deep-dive + 实战案例

### 3. 全国产ZigBee模组:信道实测数据
