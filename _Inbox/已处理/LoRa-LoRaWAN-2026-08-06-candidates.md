# LoRa / LoRaWAN 候选素材 @ 2026-08-06 12:00
## 协议速览
- 是什么：基于 CSS 啁啾扩频的 Sub-GHz LPWAN，物理层 Semtech LoRa，MAC 由 LoRa Alliance 维护
- 解决什么：电池传感器在数公里-十公里、穿透金属/墙体场景的低速率（0.3-50 kbps）通信
- 跟 L4 关联：与 BLE/ZigBee 互补的远距离 IoT 选项，工业/水务/农业大量实战
