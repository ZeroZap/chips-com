# LoRa / LoRaWAN 候选素材 @ 2026-08-11 12:00

## 协议速览
- 是什么：低功耗广域网扩频（Semtech LoRa PHY + LoRaWAN MAC），433/470/868/915 MHz 免许可
- 解决什么：电池设备 km 级小数据上行（农业/抄表/远程监控），替代 GSM/4G 降功耗
- 跟 L4 关联：IoT/可穿戴方向优先级；PLB 船舶求救回传候选；与 BLE/ZigBee 互补

## 候选文章（5 条）

### 1. 亿佰特 E77 LoRa 调试实战（RSSI/SNR/丢包阈值表）
- 链接：https://blog.csdn.net/weixin_30443747/article/details/98537754
- 来源：CSDN（亿佰特工程师）
- 摘要：STM32WLE5CCU6 + E77，阈值三档。农业实测：RSSI=-92/SNR=2 丢包 45%，调天线至 -87/7 降至 0.3%
- 实战点：工程阈值 RSSI 故障线 -90 dBm、SNR 故障线 3 dB；"连接成功"≠"通信可靠"；RSSI 高 SNR 低 = 同频干扰
- 推荐动作：**扩 deep-dive**——L4 缺"阈值+实测"诊断表

### 2. 50Ω 阻抗匹配 + LoRa 天线选型避坑
- 链接：https://so.html5.qq.com/page/real/search_news?docid=70000021_0136a5625c262752
- 来源：腾讯企鹅号（亿佰特）
- 摘要：阻抗/增益/安装三维度。射频全段 50Ω（VSWR<1.5），增益按距离选，天线 +10m 视距 +5.5km
- 实战点：π 型 LC 匹配网络；PCB 微带线 50Ω（FR4 线宽=2.2×介质厚）；433/868/915 频段不可混用
- 推荐动作：**写实战案例**——L4 缺的天线匹配工程细节

### 3. LORA 通信距离差（400m vs km 级）排查
- 链接：https://zhuanlan.zhihu.com/p/84784514
- 来源：知乎（利尔达工程师）
- 摘要：LSD4RF-2F717M90 SF7 实测仅 400m（应 km）。5 步分段：传导→走线→IPX→天线→PCB，每段 ≤1dB
- 实战点：分段定位模板；PCB 干扰源（大线圈/变压器/开关器件）；天线耦合 -30 dBm 正常，<-40 异常
- 推荐动作：**入主题笔记**——L4 "分段定位"调试流程模板

### 4. 山地 LoRa 距离实测（100km 步道覆盖）
- 链接：https://www.toutiao.com/article/7272682078557438500/
- 来源：今日头条（万维物联）
- 摘要：重庆仙女山 SF12/BW125 测试，灵敏度 -142dBm，单站 20+km 路径 / 直线 4.9km，丢包 <10%

- 推荐动作：**扩 deep-dive**——L4 缺"地形→部署→覆盖"完整案例
