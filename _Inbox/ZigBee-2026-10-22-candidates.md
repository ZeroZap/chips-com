# ZigBee 候选素材 @ 2026-10-22 00:05

## 协议速览
- 是什么：IEEE 802.15.4 低功耗 Mesh（2.4GHz OQPSK / 250kbps，26 信道）。
- 解决什么：电池节点撑 2-3 年 + 多跳自组网，代价是链路预算极紧。
- L4 关联：本轮全打「实验室 OK、产线挂」——量产一致性 / 射频匹配 / 拼板三张成绩单。

### 1. Zigbee 模块量产射频性能自动化测试系统设计与一致性管控
- 链接：https://www.21ic.com/a/1013725.html
- 来源：21IC 电子网
- 摘要：年产 30 万片线的秒级射频自测方案，STM32H7 + 8 通道 SPDT 切换，金属隔腔隔离度 60dB 以上。
- 实战点：① 实验室频谱仪调好的模块一到产线就崩，批次间发射功率离散 ±3dB ② 半柔同轴 ≤15cm、插损 <1.2dB，配自动校准回路抵消线缆老化与温漂 ③ 数字可调电容自动校准，Tx 偏低不良品修复率 >90%，良率 89%→98.2%
- 推荐动作：**扩 deep-dive**（射频量产测试这条线 KB 空白）
- ⚠️ 数字偏整，采信前先核原始数据

### 2. Debugging Python Zigbee Networks with zigbee2mqtt and wireshark
- 链接：https://www.johal.in/debugging-python-zigbee-networks-with-zigbee2mqtt-and-wireshark-3
- 来源：个人工程 blog（附可跑诊断代码 + SQLite 落库）
- 摘要：把 LQI / 重传率 / 离线路由器做成可复用诊断框架，直接对 pcap 判网络级故障。
- 实战点：① LQI 骤降的**周期性间隔**是判周期性干扰源的关键，只看平均值会漏 ② 低于阈值的节点占比 >20% 判全网退化，而非单个坏节点 ③ 重传率超阈 + 消息速率超阈 = 拥塞，不是掉线，别往路由方向查
- 推荐动作：**入主题笔记**（LQI / 重传率量化基线）

### 3. Zigbee 天线选型与调试实战：从 2.4GHz 协议到量产落地
- 链接：https://blog.csdn.net/weixin_29191761/article/details/164141989
- 来源：CSDN（射频工程实践）
- 摘要：2.4GHz 波长仅 12.5cm，传播近似直线；26 信道全挤在 2400–2483.5MHz。
- 实战点：① 贴片天线下方禁铺地，常被结构工程为散热 / 固定铜皮破坏 ② 高频匹配电感必须绕线型，叠层电感自谐振常只有几百 MHz，在 2.4GHz 已严重偏离理想电感 ③ 射频前端留余量后，ZigBee → Matter over Thread 只改协议栈 + 匹配参数，不改板
- 推荐动作：**写实战案例**
