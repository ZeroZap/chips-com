## 投标响应常见问题

```text
Q：是否支持 IEC 60870-5-104:2002？
A：主流厂商均支持 IEC 60870:2002。最新支持 2010 版（含扩展 GI / 文件传输）。

Q：是否支持 GI 通用分类？
A：主流厂商均支持 GI（ASDU 240-249）。配网场景必备。

Q：是否支持双点命令（Select → Operate）？
A：所有厂商均支持。高端厂商支持 Enhanced Security（带定时 + 序列号）。

Q：是否支持文件传输（ICD/SCD 下载）？
A：高端厂商支持。低端可能不支持（需明确需求）。

Q：是否支持多主站连接？
A：国内厂商通常限制 1 主站；ABB / Siemens / SEL 支持多主站。

Q：是否支持 ASV / ASW 加密？
A：极少厂商支持 IEC 104 应用层加密。依赖网络层 VPN / 专网。

Q：一致性测试报告？
A：国内：国网 / 电力科学研究院；海外：DNV KEMA / TUV。
```

## 关键技术点

```text
1. k/w/t 参数协商：所有厂商支持
2. CP56Time2a 编解码：所有厂商支持
3. GI 通用分类（ASDU 240-249）：配网场景必备
4. 文件传输：高端项目必备
5. 加密扩展：极少厂商支持，依赖网络层
6. 多主站：海外厂商支持，国内厂商多限制
7. 一致性测试：项目验收必要
```
