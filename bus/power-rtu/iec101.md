# IEC 60870-5-101

## 定位

IEC 60870-5-101（简称 IEC 101）是串行远动规约，用于电力系统 RTU 与主站之间的串行（RS485/RS232）通信。

```text
IEC 101 = 串行（FT1.2 帧）远动
IEC 104 = 101 的 TCP 版本
```

应用层（ASDU）和 IEC 104 完全相同，区别只在传输层：101 用 FT1.2 串行帧，104 用 TCP 字节流。

```text
物理层：RS485 / RS232
链路层：FT1.2 帧
应用层：ASDU（同 IEC 104）
```

101 主要用于存量电力主站、电厂 RTU、海外项目仍用串行口等场景。

## 工作模式

```text
非平衡传输（UNB）：只有主站能起传输，从站被动响应。
平衡传输（BAL）：主站和从站都可主动起传输。
```

工程实践：

- 国内配电 RTU 常见非平衡模式。
- 厂站 RTU 平衡模式可减少延迟。

## FT1.2 帧结构

FT1.2 定义两类帧：

```text
固定长度帧：用于链路控制（复位、请求链路状态、请求数据）
            控制域 1 字节 + 10 字节定长
可变长度帧：用于 ASDU 传送
            控制域 1 字节 + 长度 1 字节 + ASDU + 校验
```

### 固定长度帧格式

```text
10 01 [C] [Addr] 00 [CS] 16
```

- `10` 启动字符（固定）。
- `01` 长度（=1 表示固定长度帧，ASDU 长度 = 0）。
- `C` 控制域 1 字节。
- `Addr` 链路地址 1 字节。
- `00` ASDU 长度 = 0。
- `CS` 校验字节 = 控制域、链路地址、ASDU 长度三字节累加和取低 8 位。
- `16` 结束字符。

### 可变长度帧格式

```text
68 [L] [L] [68] [C] [Addr] [ASDU] [CS] 16
```

- `68` 启动字符（可变）。
- `L` 长度 = 控制域 + 地址 + ASDU 总字节数。
- `68` 第二个启动字符。
- `C` 控制域 1 字节。
- `Addr` 链路地址 1 字节。
- `ASDU` 应用数据。
- `CS` 校验字节。
- `16` 结束字符。

注意 101 用 1 个字节校验，CRC16 在 104 之前不需要。

## 控制域详解（1 字节）

控制域 1 字节编码含义：

```text
bit 7：DIR（1 = 主站→从站，0 = 从站→主站）
bit 6：PRM（启动位，1 = 启动方）
bit 5：FCB（帧计数位）
bit 4：FCV（帧计数有效）
bit 3..0：功能码
```

非平衡模式下：

```text
主站启动：DIR=0, PRM=1
从站响应：DIR=1, PRM=0
```

平衡模式下：

```text
双方都可启动：DIR 与 PRM 配合标识启动方
```

### 功能码（5 bit 中的低 4 位，主站启动）

```text
0  = 复位远方链路
1  = 复位用户进程
2  = 链路测试（平衡模式）
3  = 请求数据（1 级）
4  = 请求数据（2 级）
5  = 请求 / 响应 不带数据请求
6  = 请求 / 响应 不带数据确认
8  = 请求链路状态
9  = 请求 1 级用户数据
10 = 请求 2 级用户数据
11 = 请求 / 响应 2 级数据确认
```

## 链路过程（典型流程）

```text
1. 主站 → 复位远方链路 (FC=0)
2. 从站 → 复位确认 (FC=0)
3. 主站 → 请求链路状态 (FC=8)
4. 从站 → 链路状态 OK (FC=11)
5. 主站 → 总召唤 C_IC_NA_1 (FC=3)
6. 从站 → 总召唤响应（多个 ASDU）
7. 从站 → 总召唤结束 C_IC_NA_1 激活结束
8. 周期性时钟同步 C_CS_NA_1
```

帧计数（FCB/FCV）：

```text
非平衡模式：每对通信 FCB 翻转一次（0→1→0→1）
       FCV = 1 标识 FCB 有效
       FCV = 0 标识 FCB 忽略（如复位命令）
从站响应 FCB 必须复制主站请求
```

## 应用层（ASDU）

与 IEC 104 完全共用：

```text
类型标识（1 字节）
VSQ（1 字节）
COT 传输原因（2 字节）
公共地址（1/2 字节）
信息体（IOA + 数据 + 时序）
```

IOA 在 101 中常见 2 字节，104 是 3 字节。工程实践常用 3 字节 101（兼容 104）。

## 时序

CP24Time2a（4 字节）：101 早期
CP56Time2a（7 字节）：101/104 共用

## 适用场景

- 厂站 RTU 串行口通信。
- 存量电力调度主站。
- 海外串行口 SCADA 系统。
- 工业现场 RS485 总线远动。
- 电厂 DCS 上行。

## 检查清单

- RS485/RS232 串口参数与主站一致。
- 帧定界 10 01 ... 16（固定）和 68 ... 16（可变）正确解析。
- 控制域 DIR / PRM / FCB / FCV / 功能码解析正确。
- 链路过程（复位 → 状态 → 总召唤 → 时钟）已调通。
- FCB 翻转正确（主站侧）。
- ASDU 类型 / COT / IOA 解析正确。
- 校验字节 CS 计算正确。
- 串口隔离 / 终端电阻 / 方向控制（半双工）符合 RS485 工程要求。
