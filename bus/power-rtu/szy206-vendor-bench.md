# SZY 206 主流厂商 / 产品对标

## 定位

SZY 206-2016 是国内水资源监测数据传输规约。本文梳理 SZY 206 在水利行业的典型厂商和产品。

> 说明：本文档基于公开资料整理，**具体型号 / 规格请以厂商官网为准**。

## 国内厂商

| 厂商 | 典型产品 | SZY 206 能力 |
| --- | --- | --- |
| **四创电子** | SC-取水 RTU | ✅ TCP / GSM / 北斗、要素编码、累计流量 |
| **国睿科技** | GR-水资源 RTU | ✅ TCP / GSM / 北斗 |
| **聚光科技** | 水资源 RTU | ✅ TCP / GSM |
| **南京南自** | NAS-水资源 RTU | ✅ TCP / GSM |
| **中电科** | 水资源 RTU | ✅ TCP / GSM |
| **江苏华健** | 取水计量 RTU | ✅ 取水流量、阀门 |
