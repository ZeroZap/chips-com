# SZY 206-2016

## 定位

SZY 206-2016 是水利部行业标准《水资源监测数据传输规约》，用于取水口、地下水、灌区监测，与 SL 651-2014 配套。

```text
SL 651-2014：水文监测（河道、水库、雨量）
SZY 206-2016：水资源监测（取水、地下水、灌区）
SL/T 427：水资源监测补充
```

## 应用场景

- 取水口在线监测。
- 地下水监测井。
- 灌区用水监测。
- 水资源调度。

## 协议分层

```text
物理层：4G / 北斗 / 光纤 / 短信
链路层：TCP（主）/ UDP / 短信
应用层：信息帧
```

## 网络结构

```text
中心站（server，多个）
    ↕
测站（client，多个）→ 中心站
```

## 帧结构（与 SL 651 类似）

### 链路帧

```text
F1/F2/F3/F4 + 中心站地址 + 测站地址 + 链路标识 + CRC + 帧尾
```

帧首：

```text
F1：链路维持
F2：链路建立
F3：链路释放
F4：链路测试
```

### 信息帧

```text
STX + LEN + 中心站地址 + 测站地址 + FC + 数据 + CRC16 + ETX
```

```text
STX = 0x02
LEN = 1 字节
中心站地址：1-2 字节 BCD
测站地址：1-2 字节 BCD
FC：功能码
数据：可变
CRC16：2 字节
ETX = 0x03
```

## 功能码（FC）

| FC | 含义 | 方向 |
| --- | --- | --- |
| 0x30 | 自报小时数据 | 测站→中心 |
| 0x31 | 自报分钟数据 | 测站→中心 |
| 0x32 | 加报 | 测站→中心 |
| 0x33 | 召测 | 中心→测站 |
| 0x34 | 召测应答 | 测站→中心 |
| 0x38 | 时间校准 | 中心→测站 |
| 0x39 | 时间校准应答 | 测站→中心 |
| 0x3A | 控制命令 | 中心→测站 |
| 0x3B | 控制应答 | 测站→中心 |

## 报文示例

### 自报小时数据（FC=0x30）

```text
STX + LEN + 中心站地址 + 测站地址 + 0x30
   YYMMDDHHmm + 流量 + 累计流量 + 水位
CRC + ETX
```

### 召测（FC=0x33）

```text
STX + LEN + 中心站地址 + 测站地址 + 0x33 + 召测类型 + CRC + ETX
```

### 召测应答（FC=0x34）

```text
STX + LEN + 中心站地址 + 测站地址 + 0x34 + 数据 + CRC + ETX
```

## 水资源要素编码

SZY206 重点是取水要素：

```text
0x00  累计流量（m³）
0x01  瞬时流量（m³/h）
0x02  日累计流量
0x03  月累计流量
0x10  水位（m）
0x20  瞬时取水量
0x21  日累计取水量
0x30  地下水位
0x31  地下水埋深
0x40  水质参数（pH、电导率、温度等）
0x50  阀门开度
0x51  阀门状态
0x60  泵运行状态
0x70  取水许可状态
```

## 数据格式

数据段编码（与 SL 651 类似）：

```text
要素类型 + 测量类型 + 数值字节数 + 小数位 + BCD 数值
```

例：流量 100.32 m³/h

```text
0x01 0x01 0x04 0x02
[0x01][0x01][0x04][0x02][0x10][0x03][0x20][0x00]
要素类型 + 测量类型 + 4 字节数值 + 2 位小数 + 1003200 = 10032.00 / 100 = 100.32 m³/h
```

## 通信流程

```text
1. 测站主动连接中心站
3. 链路建立 F2
5. 链路维持 F1（心跳）
7. 业务交互（自报 / 召测 / 控制 / 时间校准）
9. 链路释放 F3
```

## 自报策略

```text
定时自报（FC=0x30 / 0x31）：
  每 1 / 5 / 30 分钟 / 1 小时
  流量、水位、累计量

加报（FC=0x32）：
  流量超阈值
  水位变幅超阈值
  设备故障
  取水异常
```

## 控制命令（FC=0x3A）

中心可下发：

```text
阀门开关
泵启停
设备参数调整
设备维护状态切换
```

控制应答（FC=0x3B）：

```text
执行结果（成功 / 失败）
```

## 与 SL 651 区别

| 维度 | SL 651 | SZY 206 |
| --- | --- | --- |
| 应用 | 水文监测 | 水资源监测 |
| 重点要素 | 雨量、水位、流量、流速 | 取水流量、累计量、地下水位 |
| 设备类型 | 水文站、雨量站 | 取水口、地下水井 |
| 中心站 | 省级 / 流域水文中心 | 省级 / 地市级水资源中心 |
| 编码体系 | 4 字节要素 | 类似但要素字典不同 |

## 检查清单

- TCP 端口已开。
- 链路建立 F2 流程跑通。
- 链路维持 F1 心跳正常。
- 自报周期符合省级要求。
- 召测应答能正常返回。
- 控制命令能正确应答。
- 时间校准能正常执行。
- 加报阈值合理。
- GSM 短信备份信道正常。
- 加密扩展（省级要求）。
