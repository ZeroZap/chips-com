# SZY 206-2016 Deep Dive

## 目标

本文深入 SZY 206 工程细节，重点解决取水监测数据模型、累计流量精度、自报 / 召测 / 控制命令链路、GSM 短信备份、多信道策略和省级水资源平台对接差异。

## 协议栈分层

```text
物理层：4G / GSM / 北斗 / 光纤 / 卫星 IoT
链路层：TCP / UDP / 短信
应用层：SZY 206 信息帧
```

SZY 206 与 SL 651 同源（均为水利部行业标准），结构相同，但应用领域和数据字典不同。

## 协议版本

- SZY 206-2016（当前主流）
- 部分省份扩展版本（湖南、广东等）

## 帧结构详解

### 链路帧

```text
F1/F2/F3/F4 + 中心站地址 + 测站地址 + 链路标识 + CRC + 帧尾
```

帧首编码：

```text
F1 = 0x46 0x31（链路维持）
F2 = 0x46 0x32（链路建立）
F3 = 0x46 0x33（链路释放）
F4 = 0x46 0x34（链路测试）
```

帧尾 = 0x03

### 信息帧

```text
STX + LEN + 中心站地址 + 测站地址 + FC + 数据 + CRC16 + ETX
```

字段说明：

```text
STX = 0x02
LEN = 1 字节
中心站地址：BCD 编码 1-2 字节
测站地址：BCD 编码 1-2 字节
FC：功能码
数据：可变
CRC16：CRC-16/MODBUS 同款
ETX = 0x03
```

## CRC16 计算

SZY 206 CRC16 与 SL 651 / Modbus 相同算法：

```text
多项式：0xA001
初值：0xFFFF
低字节在前
```

工程实现：

```text
uint16_t crc = 0xFFFF;
for (i = start; i < end; i++) {
    crc ^= data[i];
    for (j = 0; j < 8; j++) {
        if (crc & 1) {
            crc = (crc >> 1) ^ 0xA001;
        } else {
            crc >>= 1;
        }
    }
}
```

## 功能码（FC）

监测类：

```text
0x30  自报小时数据
0x31  自报分钟数据
0x32  加报
0x40  状态上报
```

控制类：

```text
0x33  召测
0x36  设置参数
0x38  时间校准
0x3A  控制命令
0x50  应急广播
```

应答类：

```text
0x34  召测应答
0x35  控制应答
0x37  设置参数应答
0x39  时间校准应答
0x3B  控制应答
```

## 报文解析步骤

```text
1. 收到 STX（0x02）→ 启动
3. 读 LEN（1 字节）
5. 读 LEN - 1 个字节（包括 ETX）
7. 验证 STX 位置正确
9. 解析中心站地址、测站地址、FC
11. 读数据段（FC 决定格式）
13. 读 CRC16
15. 读 ETX（0x03）
17. 验证 CRC16
19. 发送应答或下一报文
```

工程实现：

```text
parser 状态机：
  IDLE → WAIT_STX → READ_LEN → READ_ADDR → READ_FC → READ_DATA → READ_CRC → WAIT_ETX → IDLE
```

## 要素编码详解

SZY 206 重点是取水要素：

```text
0x00  累计流量
0x01  瞬时流量
0x02  日累计流量
0x03  月累计流量
0x10  水位
0x20  瞬时取水量
0x21  日累计取水量
0x30  地下水位
0x31  地下水埋深
0x40  水质参数
0x50  阀门开度
0x51  阀门状态
0x60  泵运行状态
0x70  取水许可状态
```

测量类型：

```text
0x01  瞬时值
0x02  累计值
0x03  平均值
0x04  最大值
0x05  最小值
```

### 取水流量 100.32 m³/h

```text
0x01 0x01 0x04 0x02
[0x01][0x01][0x04][0x02][0x10][0x03][0x20][0x00]
要素类型 + 测量类型 + 4 字节数值 + 2 位小数 + 1003200 = 10032.00 / 100 = 100.32 m³/h
```

### 累计流量 1234.56 m³

```text
0x00 0x02 0x04 0x04
[0x00][0x02][0x04][0x04][0x12][0x34][0x56][0x00]
要素类型 + 测量类型 + 4 字节数值 + 4 位小数 + 12345600 = 12345600 / 10000 = 1234.56 m³
```

### 地下水位 5.32 m

```text
0x30 0x01 0x03 0x02
[0x30][0x01][0x03][0x02][0x05][0x32][0x00]
要素类型 + 测量类型 + 3 字节数值 + 2 位小数 + 53200 = 532.00 / 100 = 5.32 m
```

## 自报策略

### 定时自报（FC=0x30 / 0x31）

```text
每 1 / 5 / 30 分钟 / 1 小时
要素固定（流量 / 累计流量 / 水位）
```

### 加报（FC=0x32）

```text
瞬时流量超阈值（变化超 20%）
水位变幅超过 0.05 m / 5 min
地下水位变幅超过 0.1 m
阀门状态变化
泵运行状态变化
设备故障
取水异常（如许可超量）
```

## 召测（FC=0x33 / 0x34）

中心 → 测站：

```text
0x02 LEN 中心站 测站 0x33
   0x01 召测所有要素
   0x02 召测指定要素
   0x03 召测设备状态
CRC 0x03
```

测站 → 中心：

```text
0x02 LEN 中心站 测站 0x34
   24 09 18 10 20  时间
   数据
CRC 0x03
```

## 控制命令（FC=0x3A / 0x3B）

中心 → 测站（控制命令）：

```text
0x02 LEN 中心站 测站 0x3A
   [控制类型][控制值]
CRC 0x03
```

控制类型：

```text
0x01  阀门开关
0x02  阀门开度调整
0x03  泵启停
0x04  设备维护状态
0x05  取水许可
```

测站 → 中心（控制应答）：

```text
0x02 LEN 中心站 测站 0x3B
   [结果]  0x00 成功 / 0xFF 失败
CRC 0x03
```

## 时间校准（FC=0x38 / 0x39）

```text
0x02 LEN 中心站 测站 0x38
   24 09 18 10 25 00  时间 YYMMDDHHmmss
CRC 0x03
```

测站收到后：

```text
更新本地 RTC
回应 FC=0x39 + 应答
```

## GSM 短信备份

短信编码：

```text
短信内容 = SZY 206 信息帧（去 STX/ETX）
PDU 7-bit 编码
中心站号：固定 SIM 卡号
```

工程实现：

```text
1. 编码 SZY 206 信息帧（去 STX/ETX）
3. 7-bit 编码
5. 计算 UDL（7-bit 单位）
7. 拼装 PDU
10. AT 指令发送
11. 返回 +CMGS 响应
```

## 多信道备份策略

```text
主信道：TCP / 4G
备份 1：GSM 短信
备份 2：北斗短报文
备份 3：卫星 IoT
```

工程实现：

```text
状态机：
  TCP_OK → 主信道
  TCP_FAIL_30s → GSM 短信
  GSM_FAIL_60s → 北斗
  ALL_FAIL → 本地存储 + 重连
```

## 与 SL 651 的差异

| 维度 | SL 651 | SZY 206 |
| --- | --- | --- |
| 应用 | 水文监测 | 水资源监测 |
| 重点要素 | 雨量、水位、流量、流速 | 取水流量、累计、地下水位 |
| 设备类型 | 水文站、雨量站 | 取水口、地下水井 |
| 中心站 | 水文中心 | 水资源中心 |
| 编码体系 | 4 字节要素 | 类似但要素字典不同 |
| 监管 | 水利部水文局 | 水利部水资源司 |
| 测试要求 | 省级水文测试 | 省级水资源测试 |

## 现场常见故障

| 现象 | 优先检查 |
| --- | --- |
| TCP 连不上 | IP / 端口 / 4G 信号 |
| 链路建立失败 | 地址错 |
| 自报收不到 | FC / 时间 / 要素编码 |
| 召测无应答 | 测站忙 |
| GSM 短信失败 | SIM 卡 / 信号 / PDU 编码 |
| 加报不触发 | 阈值 / 逻辑 |
| CRC 不一致 | 算法 |
| 中心站不存数据 | 要素代码错 |
| 取水许可超量 | 流量阈值 / 许可状态 |

## 深度检查清单

- TCP 端口与省级一致。
- 测站地址 / 中心站地址 BCD 编码正确。
- 链路建立 F2 流程跑通。
- 链路维持 F1 心跳正常。
- 自报周期符合省级要求。
- 加报触发逻辑正常。
- 召测应答能正常返回。
- 控制命令能正确应答。
- 时间校准能正常执行。
- 设置参数能生效。
- GSM 短信备份信道正常。
- 北斗短报文备份（可选）。
- 卫星 IoT 备份（可选）。
- 多信道切换状态机。
- CRC 计算正确。
- 要素编码正确。
- BCD 编码正确。
- 加密扩展（省级要求）。
- VPN / 专网配置。
- 省级平台对接测试。
