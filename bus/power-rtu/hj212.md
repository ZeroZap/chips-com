# HJ 212-2017

## 定位

HJ 212-2017 是中国环境保护行业标准《污染物在线监控（监测）系统数据传输标准》，用于污染源 / 排污口 / 空气站 / 噪声的联网数据传输。

```text
HJ 212-2005：第一版
HJ 212-2017：当前主流，扩展 TCP / 命令码体系
HJ 212-2025：下一代更新中
```

本文聚焦 HJ 212-2017。

## 应用领域

```text
污染源 / 排污口：COD、氨氮、pH、流量
环境空气站：SO2、NO2、PM10、PM2.5、CO、O3
地表水站：常规 9 参数
噪声：LeqA、噪声频谱
```

## 协议分层

```text
传输层：TCP（主推）/ UDP / 串口
应用层：字段名 + 数据值 + 命令码
字符集：ASCII
```

默认 TCP 端口：

```text
HJ 212 中心站端口：默认 8000 / 5000（不同省级平台不同）
```

## 数据帧结构

HJ 212 帧分三段：

```text
[Header]
[Data section]
[End]
```

完整格式：

```text
##YYYYMMDDhhmmsszzz;ST=22;CN=2011;PW=123456;MN=ABC1234567890;Flag=5;CP=&&
数据1;数据2;数据3...
&&\r\n
```

### Header 段

```text
QN=YYYYMMDDhhmmsszzz  请求编号（精确到毫秒）
ST=22                系统编号（22 = 污染源）
CN=2011              命令编号
PW=123456            访问密码
MN=ABC1234567890     设备唯一编号（13 位）
Flag=5               标志位
CP=&&                数据起始分隔符（固定 &&）
```

### Data 段

多个字段名 / 数据对，用 `;` 分隔：

```text
a21026-Rtd=123.45,a21026-Flag=N;a21011-Rtd=56.78,a21011-Flag=N;
```

### End 段

```text
&&\r\n（固定）
```

## 字段说明

### QN（请求编号）

```text
YYYYMMDDhhmmsszzz：年月日时分秒毫秒（3 位）
例：QN=20260928153045123
```

主站 / 从站每条报文必须带不同 QN，用于匹配请求和响应。

### ST（系统编号）

```text
ST=21  地表水
ST=22  污染源（最常见）
ST=23  空气
ST=24  噪声
ST=25  海水
ST=27  锅炉
```

### CN（命令编号）

常用 CN：

| CN | 命令 | 方向 |
| --- | --- | --- |
| 1000 | 心跳包 | 现场↔中心 |
| 1001 | 心跳应答 | 现场↔中心 |
| 2011 | 实时数据上传 | 现场→中心 |
| 2012 | 实时数据应答 | 中心→现场 |
| 2021 | 分钟数据上传 | 现场→中心 |
| 2031 | 小时数据上传 | 现场→中心 |
| 2041 | 日数据上传 | 现场→中心 |
| 2051 | 超标数据上传 | 现场→中心 |
| 2061 | 零点校准数据 | 现场→中心 |
| 3011 | 应答 | 中心→现场 |
| 3021 | 命令请求 | 中心→现场 |
| 3031 | 命令应答 | 现场→中心 |
| 9011 | 设置参数请求 | 中心→现场 |
| 9031 | 设置参数应答 | 现场→中心 |
| 1011 | 事件上报 | 现场→中心 |
| 9051 | 零点校准请求 | 中心→现场 |
| 9061 | 即时采样请求 | 中心→现场 |

### PW（访问密码）

```text
6 位数字
主站发给从站时使用
```

### MN（设备唯一编号）

```text
13 位数字
现场设备标识（与环保部门注册一致）
```

### Flag（标志位）

```text
Bit 0：数据压缩
Bit 1：数据加密
Bit 2：临时设备编码
Bit 3：应答要求
Bit 4-15：保留
```

### CP / &&

```text
CP=&& 固定
&& 数据段起始
&& 数据段结束
```

## 常用因子编码

HJ 212 用因子编码标识污染物：

### 污染源

```text
a21002  SO2（mg/L）
a21003  NO2（mg/L）
a21004  CO（mg/m³）
a21005  O3（mg/m³）
a21011  PM10（mg/m³）
a21026  流量（m³/h）
a21028  烟气流速
a21029  烟气温度
a01001  pH
w01001  水温
w01002  电导率（μS/cm）
w01003  浊度
w01009  溶解氧
w01014  氨氮
w01016  COD
w01017  总磷
w01018  总氮
w01019  高锰酸盐指数
w01020  BOD5
```

### 空气

```text
a21001  SO2（μg/m³）
a21008  NO2（μg/m³）
a21004  CO（mg/m³）
a21005  O3（μg/m³）
a21011  PM10（μg/m³）
a21012  PM2.5（μg/m³）
```

每个因子上传 4 个字段：

```text
<因子>-Rtd：实时数据
<因子>-Flag：数据状态（N 正常 / B 异常 / F 超标 / etc.）
<因子>-Min：最小值（可选）
<因子>-Max：最大值（可选）
<因子>-Avg：平均值（可选）
```

## 报文示例

### 心跳包（CN=1000）

现场→中心：

```text
##QN=20260928153045123;ST=22;CN=1000;PW=123456;MN=ABC1234567890;Flag=0;CP=&&
&&\r\n
```

中心应答（CN=1001）：

```text
##QN=20260928153045200;ST=22;CN=1001;PW=123456;MN=ABC1234567890;Flag=0;CP=&&
&&\r\n
```

### 实时数据上传（CN=2011）

```text
##QN=20260928153045200;ST=22;CN=2011;PW=123456;MN=ABC1234567890;Flag=0;CP=&&
a21026-Rtd=123.45,a21026-Flag=N;
a21002-Rtd=15.32,a21002-Flag=N;
a21011-Rtd=56.78,a21011-Flag=N;
&&\r\n
```

中心应答（CN=2012）：

```text
##QN=20260928153045201;ST=22;CN=2012;PW=123456;MN=ABC1234567890;Flag=0;CP=&&
&&\r\n
```

### 分钟数据（CN=2021）

```text
##QN=20260928153100000;ST=22;CN=2021;PW=123456;MN=ABC1234567890;Flag=0;CP=&&
a21026-Rtd=124.5,a21026-Flag=N,a21026-Avg=124.0,a21026-Max=126.0,a21026-Min=122.0;
&&\r\n
```

### 命令请求（CN=3021）

中心→现场（设置参数）：

```text
##QN=20260928153110000;ST=22;CN=3021;PW=123456;MN=ABC1234567890;Flag=0;CP=&&
DataTime=202609281530;Pol-a:123456;&&\r\n
```

现场应答（CN=3031）：

```text
##QN=20260928153110500;ST=22;CN=3031;PW=123456;MN=ABC1234567890;Flag=0;CP=&&
&&\r\n
```

### 设置参数（CN=9011）

```text
##QN=20260928153120000;ST=22;CN=9011;PW=123456;MN=ABC1234567890;Flag=0;CP=&&
Pol-time=60;&&\r\n
```

## 标志位 Flag

```text
Flag=0  默认
Flag=1  数据压缩
Flag=2  数据加密
Flag=4  临时编码
Flag=8  应答要求
```

## 数据状态（Flag-N 子字段）

```text
N  正常
B  异常
F  超标
M  维护
T  停运
C  校准
K  超上限
L  超下限
V  离线数据
D  故障
```

## 心跳

HJ 212 心跳：

```text
每 1-3 分钟发送 1 次（不同省份要求不同）
心跳超时：3-5 分钟未收 → 链路异常
```

## 适用场景

- 空气站联网。
- 噪声在线监测。
- 地表水监测。
- 锅炉烟气监测。

## 检查清单

- TCP 端口已开（HJ 默认端口）。
- Header 段所有字段完整（QN、ST、CN、PW、MN、Flag、CP）。
- Data 段格式正确（字段名-Rtd=值,Flag=N;）。
- End 段固定 &&\r\n。
- MN（设备唯一编号）已注册。
- PW 密码匹配。
- 因子编码与省级平台字典一致。
- 心跳周期符合省级要求。
- 数据状态 Flag-N 字段正确。
- CRC 校验（HJ 212-2017 部分场景要求）。
- 超标数据标记正确。
