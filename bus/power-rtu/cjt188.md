# CJ/T 188

## 定位

CJ/T 188 是中国城镇建设行业标准《户用计量仪表数据传输技术条件》，用于冷水表 / 热量表 / 燃气表的通信。

```text
CJ/T 188-2002：早期
CJ/T 188-2018：当前主流
```

## 应用场景

- 居民冷水表 / 热水表。
- 热量表（北方供暖）。
- 燃气表。
- 智能水务 / 智慧城市。

## 协议分层

```text
物理层：RS485（主推）/ M-Bus / 红外
链路层：主-从半双工串行
应用层：数据标识 + 数据项
```

## 与 DL/T 645 的关系

CJ/T 188 与 DL/T 645 同源（均为表计串行通信），区别：

| 维度 | DL/T 645 | CJ/T 188 |
| --- | --- | --- |
| 应用 | 电能表 | 水 / 气 / 热量表 |
| 表地址 | 6 字节 BCD | 7 字节 BCD |
| DI 编码 | 4 字节（4+4 划分） | 4 字节 |
| 数据格式 | BCD 不同 | BCD 编码 |

## 帧格式

```text
68 A0 A1 A2 A3 A4 A5 A6 68 C L [DI] [DATA] CS 16
```

字段：

```text
68      ：起始符 1
A0..A6  ：表地址（7 字节 BCD）
68      ：第二起始符
C       ：控制码 1 字节
L       ：数据长度 1 字节
[DI]    ：数据标识 4 字节
[DATA]  ：数据
CS      ：校验字节（68 A0..A6 68 C L DI DATA 累加和取低 8 位）
16      ：结束符
```

表地址 7 字节 BCD（比 645 多 1 字节）：

```text
出厂默认 9999999999999（13 个 9）
广播地址 AA AA AA AA AA AA AA
```

## 控制码（C）

主站控制：

```text
0x01  读数据
0x02  读数据（续）
0x03  重读
0x04  写数据
0x05  写数据（续）
0x06  修改密码
0x07  清除金额（热量表）
0x08  清零（特定）
0x09  设置地址
0x0A  读历史数据
0x0B  读密钥
```

从站响应（主站控制 + 0x80）：

```text
0x81  读数据响应
0x82  读数据（续）响应
0x83  重读响应
0x84  写数据响应
0x85  写数据（续）响应
0x86  修改密码响应
0x87  清零响应
0x88  状态响应
0x89  设置地址响应
0x8A  读历史数据响应
0x8B  读密钥响应
```

异常响应（主站控制 + 0xC0）：

```text
0xC1  异常响应（含 ERR 字段）
```

## 数据标识（DI）

DI 4 字节：

```text
D0 D1 D2 D3
```

D0 数据类别：

```text
0x00  当前累计流量
0x01  当前累计热量
0x02  当前流量
0x03  当前热量功率
0x04  温度
0x05  压力
0x06  状态
0x07  历史数据
0x08  金额（热量表）
0x09  故障记录
```

常用 DI：

```text
00000000  当前累计流量（m³）
00010000  当前反向累计流量（某些型号）
01000000  当前累计热量（GJ/MWh）
02000000  当前瞬时流量（m³/h）
03000000  当前瞬时热量功率（kW）
04000100  入口水温（°C）
04000200  出口水温（°C）
04000300  温差
05000100  入口压力（kPa）
05000200  出口压力（kPa）
06000000  阀门状态（开 / 关）
07000000  历史数据起始
08000000  剩余金额
```

## 数据格式

冷水表数据：

```text
当前累计流量：4 字节 BCD，单位 0.001 m³
例：0x00 0x12 0x34 0x56 → 1234.56 / 1000 = 1.23456 m³

瞬时流量：3 字节 BCD，单位 0.01 m³/h
例：0x05 0x00 0x32 → 5.00 / 100 = 0.05 m³/h

水温：2 字节 BCD，单位 0.01 °C
例：0x21 0x03 → 21.03 °C
```

热量表数据：

```text
累计热量：4 字节 BCD，单位 0.001 GJ
瞬时热量功率：3 字节 BCD，单位 0.01 kW
```

## 报文示例

### 读累计流量（DI=00000000）

主站：

```text
68 AA AA AA AA AA AA AA 68 01 04 00 00 00 00 CS 16
```

字段：

```text
68 起始符
AA AA AA AA AA AA AA 表地址
68 第二起始符
01 控制码（读数据）
04 数据长度 4 字节
00 00 00 00 DI
CS 校验
16 结束
```

从站响应：

```text
68 12 34 56 78 90 12 34 68 81 08 00 00 00 00 12 34 56 78 CS 16
```

字段：

```text
12 34 56 78 90 12 34 表地址 7 字节
81 控制码 0x81
08 数据长度 8 字节
00 00 00 00 DI
12 34 56 78 累计流量（BCD）
```

实际：

```text
BCD 解码：0x12345678 → 12345678 / 1000 = 12345.678 m³
```

### 读入口水温（DI=04000100）

主站：

```text
68 12 34 56 78 90 12 34 68 01 04 04 00 01 00 CS 16
```

从站响应：

```text
68 12 34 56 78 90 12 34 68 81 06 04 00 01 00 XX XX CS 16
```

DATA = 2 字节 BCD。

### 设置地址（控制码 0x09）

主站：

```text
68 AA AA AA AA AA AA AA 68 09 12 + 新地址 + CS + 16
```

从站：

```text
68 12 34 56 78 90 12 34 68 89 CS 16
```

注意：设置地址前必须验证密码。

### 修改密码（控制码 0x06）

主站：

```text
68 AA AA AA AA AA AA AA 68 06 0C + 旧密码 4 + 新密码 4 + CS + 16
```

从站：

```text
68 12 34 56 78 90 12 34 68 86 CS 16
```

## 密码管理

CJ/T 188 密码 4 字节：

```text
默认密码：00000000（每家厂商可能不同）
```

权限分级：

```text
0 级：厂家
1 级：抄表者
2 级：购电
3 级：用户
```

## 多帧协议（块读）

数据量大时：

```text
1. 主站：0x01 + DI
3. 从站：0x81 + DI + 部分数据（D0 最高位 = 1 标识后续）
5. 主站：0x02 + DI（读后续）
7. 从站：0x82 + DI + 后续部分
9. 重复直到 D0 最高位 = 0
```

## 异常响应（ERR）

异常帧：

```text
68 ... 68 C1 ERR CS 16
```

ERR 字节错误码：

```text
0x00  正确
0x01  其他错误
0x02  请求数据不存在
0x03  数据标识错
0x05  数据长度错
0x06  密码错
0x07  权限不足
0x08  密码权限不够
0x09  数据溢出
0x40  ESAM 错
```

## 历史数据（控制码 0x0A）

主站读取历史数据：

```text
68 AA AA AA AA AA AA AA 68 0A 04 + DI + 时间 + CS + 16
```

时间格式：YYMMDDHHmm（5 字节 BCD）。

从站返回历史数据帧。

## 串口参数

```text
2400 / 4800 / 9600 baud（最常见）
8E1 / 8N1
```

工程实践：

- 2400 8E1 默认。
- 多表分时轮询。

## 通信速率自适应

部分水表支持自适应：

```text
1. 主站发读命令（2400）
3. 失败 → 试 4800 / 9600
5. 成功 → 锁定
```

## 红外通信

部分水表支持红外：

```text
38 kHz 调制
1200 baud
8E1
```

红外参数与 DL/T 645 类似。

## 检查清单

- RS485 串口参数一致（2400 8E1 默认）。
- 帧格式 68 ... 68 ... 16 解析正确。
- 表地址 7 字节 BCD。
- 控制码主站 / 从站 / 异常三种区分。
- DI 4 字节字典正确。
- DATA BCD 解码正确。
- 校验字节 CS 计算正确。
- 写数据前密码流程正确。
- 多帧协议（块读）支持。
- 异常 ERR 字段处理。
- 多表分时轮询避免总线冲突。
- RS485 半双工 DE 时序正确。
