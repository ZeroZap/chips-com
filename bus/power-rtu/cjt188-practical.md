# CJ/T 188 Practical Guide

## 目标

本文用于把 CJ/T 188 工程链路调通：RS485 接线、串口参数、帧收发、数据项解析、密码流程、读写操作和调试方法。

## 硬件接线

```text
MCU TX  → RS485 DI
MCU RX  ← RS485 RO
GPIO    → RS485 DE/RE
A/B     → 水表 A/B
GND     → 参考地
```

工程注意：

- 半双工：DE 等待 UART TC。
- 长线两端 120Ω 终端。
- 工业现场隔离收发器。

## 串口参数

```text
2400 8E1（默认）
4800 8E1
9600 8E1
```

## 帧格式速记

```text
68 A0 A1 A2 A3 A4 A5 A6 68 C L [DI] [DATA] CS 16
```

字段：

```text
68：起始符（2 个）
A0..A6：表地址 7 字节 BCD
68：第二起始符
C：控制码
L：数据长度
DI：4 字节
DATA：可变
CS：校验字节
16：结束符
```

## 报文示例（十六进制）

### 读当前累计流量（DI=00000000）

主站（广播读）：

```text
68 AA AA AA AA AA AA AA 68 01 04 00 00 00 00 CS 16
```

CS 计算：

```text
0x68 + 0xAA*7 + 0x68 + 0x01 + 0x04 + 0x00*4
= 0x68 + 0x550 + 0x68 + 0x05
= 0x6C5 + 0x05 = 0x6CA
取低 8 位：0xCA
```

从站响应（单表）：

```text
68 12 34 56 78 90 12 34 68 81 08 00 00 00 00 12 34 56 78 CS 16
```

字段：

```text
12 34 56 78 90 12 34：表地址 7 字节
81：控制码（正常读）
08：数据长度 8（DI 4 + DATA 4）
00 00 00 00：DI
12 34 56 78：累计流量（BCD）

BCD 解码：0x12345678 → 12345678 / 1000 = 12345.678 m³
```

### 读入口水温（DI=04000100）

主站：

```text
68 12 34 56 78 90 12 34 68 01 04 04 00 01 00 CS 16
```

从站响应：

```text
68 12 34 56 78 90 12 34 68 81 06 04 00 01 00 XX XX XX XX XX XX CS 16
```

DATA = 6 字节（DI + DATA）？

实际 CJ/T 188 DATA 长度可变，水温通常 2 字节 BCD。

### 设置地址（控制码 0x09）

主站：

```text
68 AA AA AA AA AA AA AA 68 09 12 [新地址 7 字节] CS 16
```

从站：

```text
68 [新地址 7 字节] 68 89 CS 16
```

注意：设置地址前**必须**验证密码。

### 修改密码（控制码 0x06）

主站：

```text
68 [地址 7 字节] 68 06 0C [旧密码 4 字节] [新密码 4 字节] CS 16
```

从站：

```text
68 [地址 7 字节] 68 86 CS 16
```

## 控制码速查

```text
主站 → 从站
0x01 读数据
0x02 读数据（续）
0x04 写数据
0x05 写数据（续）
0x06 修改密码
0x08 清零
0x09 设置地址
0x0A 读历史数据

从站 → 主站
0x81 读数据响应
0x82 读数据（续）响应
0x84 写数据响应
0x86 修改密码响应
0x89 设置地址响应
0x8A 读历史数据响应
0xC1 异常响应（ERR 字段）
```

## 读 / 写流程

### 读数据

```text
1. 主站发 0x01 + DI
3. 从站回 0x81 + DI + DATA
5. 主站解析 DATA
```

### 写数据

```text
1. 主站发 0x06 + 旧密码 + 新密码（修改密码）
3. 从站回 0x86 成功
5. 主站发 0x04 + DI + DATA（写数据）
7. 从站回 0x84 成功
```

写通讯地址（0x09 控制码）：

```text
1. 主站发 0x09 + 新地址
3. 从站回 0x89 确认（地址变更）
```

注意：写通讯地址前**必须**验证密码。

## 密码管理

CJ/T 188 密码 4 字节：

```text
0 级：00000000（厂家）
1 级：抄表者
2 级：购电
3 级：用户
```

读写密码：

```text
DI=00000000 + LEN=4 + 4 字节密码
```

## 多帧协议（块读）

块读数据项超过单帧容量时：

```text
1. 主站发 0x01 + DI（D0 最高位 = 1 表示后续）
3. 从站发 0x81 + DI + 部分数据（D0 最高位 = 1）
5. 主站发 0x02 + DI（读后续）
7. 从站发 0x82 + DI + 后续部分
9. 重复直到 D0 最高位 = 0
```

## 调试工具

- USB-RS485 转换器。
- 抄表器：水表厂家调试工具。
- Wireshark：CJ/T 188 dissector（有限支持）。
- 串口调试助手：AccessPort、ComTools。

## 调试步骤

1. 用 USB-RS485 转换器 + 抄表软件先调通单表。
2. 确认表地址 7 字节 BCD（出厂 9999999999999）。
3. 串口参数 2400 8E1 与表一致。
4. 发读命令 0x01 + DI=00000000，确认能读回累计流量。
5. 测试读水温（热量表）。
6. 测试写密码 + 写数据流程。
7. 多表并接：分时轮询，避免冲突。

## 常见问题

| 现象 | 优先检查 |
| --- | --- |
| 完全无响应 | A/B、波特率、校验、地址 |
| 表读不到数据 | 表地址错、未配地址 |
| 数据格式错 | DI 字节序、BCD 解码 |
| 多帧读完不完整 | 0x02 后续读流程 |
| 写数据失败 | 密码错误 |
| ERR 错误码 | 查 ERR 定义 |
| CRC 累加失败 | CS 计算错误 |

## 实战检查清单

- RS485 半双工 DE 时序正确。
- 串口参数 2400 8E1（默认）。
- 表地址 7 字节 BCD。
- 控制码区分主站 / 从站。
- DI 4 字节编码正确。
- DATA BCD 解码正确。
- CS 校验字节正确。
- 读流程正常。
- 写流程密码验证正确。
- 多帧协议支持。
- 异常 ERR 字段处理。
- 多表分时访问避免总线冲突。
