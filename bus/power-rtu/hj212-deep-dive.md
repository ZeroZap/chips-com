# HJ 212-2017 Deep Dive

## 目标

本文深入 HJ 212 工程细节，重点解决 TCP 接入、字段解析状态机、因子字典、心跳策略、命令应答链、加密扩展、省级平台对接差异和现场排障。

## 协议栈分层

```text
应用层：HJ 212 数据帧（字段名 + 数据值 + 命令码）
传输层：TCP（主推）/ UDP / 串口
网络层：IPv4（IPv6 部分支持）
物理层：以太网 / 4G / 光纤
```

HJ 212 是基于文本行的应用层协议，结构类似 HTTP 但更紧凑。

## 版本与扩展

### HJ 212-2005

```text
简单数据上报协议
字段较少
```



## 数据帧完整结构

```text
## [QN];ST=[22];CN=[2011];PW=[123456];MN=[ABC1234567890];Flag=[0];CP=&&
## [数据段]
&&\r\n
```

段结构：

```text
## 报文开始标识
Header 字段段（QN、ST、CN、PW、MN、Flag、CP）
&& 数据段开始
Data 字段段（多个因子字段用 ; 分隔）
&& 数据段结束
```

工程注意 `\r\n`：

```
\r = 0x0D
\n = 0x0A
报文结束必须有这两个字节
```

## Header 字段详解

### QN（请求编号）

```text
格式：YYYYMMDDhhmmsszzz
精度：毫秒
主站 / 从站每条报文唯一
```

QN 用于请求 - 应答匹配：

```text
主站：QN=20260928153045000 CN=3021（命令）
从站：QN=20260928153045500 CN=3031（应答）
```

工程实现：

```text
维护最近 1000 个 QN
超时未应答 → 重发或告警
QN 唯一性 → 毫秒级时间戳 + 随机后缀
```

### ST（系统编号）

```text
21  地表水
22  污染源（最常见）
23  环境空气
24  噪声
25  海水
26  土壤
27  锅炉
31  厂界
```

不同 ST 对应不同因子字典：

```text
ST=22 污染源 → a21026、a21002、w01014 等
ST=23 空气  → a21001、a21011、a21012 等
ST=24 噪声  → a50001、a50002
```

### PW（密码）

```text
6 位数字
注册时分配
可为空（明文）
```

加密传输时：

```text
PW 字段 + 数据段加密（DES/AES）
```

### MN（设备唯一编号）

```text
13 位数字
省级平台注册后确定
不可修改（只能通过设置参数变更）
```

例：

```text
MN=1234567890123
MN=ABC1234567890（HJ 212 允许字母，但实际以数字为主）
```

### Flag（标志位）

```text
Bit 0：是否压缩（1 = 压缩）
Bit 1：是否加密（1 = 加密）
Bit 2：临时编码（1 = 是）
Bit 3：应答要求（1 = 必答）
Bit 4-15：保留
```

例：

```text
Flag=0  默认
Flag=4  临时编码
Flag=8  必答
Flag=12 = 8+4 必答 + 临时编码
```

### CP（数据起始标识）

```text
固定 CP=&&
```

## Data 段详解

每条因子格式：

```text
<Factor>-<Field>=<Value>
```

Factor：

```text
因子编码（如 a21026、w01014）
4 位行业 + 4 位分类 + 4 位序号的 HJ 标准编码
```

Field：

```text
-Rtd    实时数据
-Avg    平均值（小时 / 日数据）
-Max    最大值
-Min    最小值
-Zs     累计值（流量等）
-Flag   数据状态（N/B/F/M/T/C/K/L/V/D）
```

### 字段举例

```text
a21026-Rtd=123.45,a21026-Flag=N
a21002-Rtd=15.32,a21002-Flag=N
w01014-Rtd=2.34,w01014-Flag=F
```

### 完整数据段

```text
a21026-Rtd=123.45,a21026-Flag=N;
a21026-Avg=124.0,a21026-Max=126.0,a21026-Min=122.0;
a21002-Rtd=15.32,a21002-Flag=N;
w01014-Rtd=2.34,w01014-Flag=F;
```

每条因子以 `;` 结束，最后一条可以省略 `;`。

## 数据上报策略

### 实时数据（CN=2011）

```text
频次：1-5 分钟 1 次（不同因子不同）
时机：因子测量后立即上报
格式：实时因子
```

工程实现：

```text
1. 测量周期 30 秒
3. 测量完成 → 数据帧打包
5. TCP 上报 → 等应答
7. 应答失败 → 重发
```

### 分钟数据（CN=2021）

```text
频次：每分钟 1 次
时机：每分钟整点
格式：实时因子（可加 Avg）
```

### 小时数据（CN=2031）

```text
频次：每小时 1 次
时机：每小时整点
格式：实时因子 + Avg + Max + Min
```

### 日数据（CN=2041）

```text
频次：每天 1 次
时机：每天 0 点
格式：日均数据
```

### 超标数据（CN=2051）

```text
时机：因子超阈值时立即上报
格式：超标因子 + Flag-N=F
```

## TCP 接入

HJ 212 典型连接：

```text
RTU（client）→ TCP → 中心站（server）
中心站端口：8000 / 5000 / 9501（省级差异）
```

连接管理：

```text
1. RTU 主动连接（4G/以太网）
3. 长连接保活（应用层心跳 + TCP Keepalive）
5. 异常断开自动重连
```

## UDP 接入

部分省份支持 UDP：

```text
RTU → UDP → 中心站
UDP 端口：8000 / 9501
UDP 不可靠传输：需应用层重传
```

工程实现：

```text
UDP 包 → 中心站接收 → 应答
超时 1 秒未应答 → 重发（最多 3 次）
```

## CRC 校验

HJ 212-2017 部分场景（涉及加密）使用 CRC：

```text
CRC-16/Modbus：多项式 0xA001，初值 0xFFFF
计算范围：Header 数据段（不含 ## 和结束标识）
结果：4 字节十六进制大写
```

工程实现：

```text
uint16_t crc = 0xFFFF;
for (i = 0; i < len; i++) {
    crc ^= data[i];
    for (j = 0; j < 8; j++) {
        if (crc & 0xA) {
            crc = (crc >> 1) ^ 0xA001;
        } else {
            crc >>= 1;
        }
    }
}
```

但 CRC 不是 HJ 212-2017 必填项，实际工程常省略。

## 加密扩展

部分省级平台要求加密传输：

```text
DES / AES 加密
加密范围：数据段
密钥：每台设备独立
加密标志：Flag bit 1 = 1
```

工程实践：

- 加密场景通常要求双向认证。
- 现场 RTU 必须支持加密算法。
- 加密因子通常用业务要求决定（无强制）。

## 命令执行链

中心 → 现场命令：

```text
1. 主站：CN=3021 + 命令内容
3. 现场：CN=3031 应答 + 执行结果
5. 主站：根据应答确认执行状态
```

命令类型：

```text
即时采样：触发实时测量
零点校准：触发校准
设置参数：写入新参数
校时：时间同步
```

## 心跳策略

工程实际心跳频率：

```text
通常 1-3 分钟 1 次
不同省份要求不同
心跳超时：3-5 分钟
```

```text
RTU → CN=1000
中心 → CN=1001 应答
RTU：超时未应答 → TCP 重连
```

## 重连机制

HJ 212 TCP 异常处理：

```text
1. TCP 断开（心跳超时 / 网络中断）
3. 立即重连
5. 重连失败后定时重试
9. 数据缓存到本地（异常数据补传）
```

补传机制：

```text
1. 上报实时数据 → 异常未应答
3. 缓存到本地（含时间戳）
5. TCP 恢复 → 批量补传（CN=2011 + 历史数据）
```
