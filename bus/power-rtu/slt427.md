# SL/T 427

## 定位

SL/T 427 是水利部行业标准《水资源监测数据传输补充规定》，与 SZY 206-2016 配套使用，覆盖水资源监测中 SZY 206 未明确的细分场景。

```text
SL 651-2014：水文监测
SZY 206-2016：水资源监测
SL/T 427-2014：水资源监测补充
```

## 应用场景

- 灌区用水监测细分。
- 水质监测数据扩展。
- 多中心站数据汇聚。
- 加密信道扩展。
- 取水许可精细化监控。

## 与 SZY 206 关系

SL/T 427 是 SZY 206 的扩展与补充：

```text
SZY 206：基础数据传输规约
SL/T 427：
  - 扩展要素编码
  - 扩展中心站管理
  - 加密信道
  - 多语言支持
  - 扩展历史数据回传
```

## 协议分层

```text
物理层：4G / 北斗 / 光纤 / 短信
链路层：TCP（主）/ UDP / 短信
应用层：信息帧（与 SZY 206 兼容 + 扩展）
```

## 帧结构（与 SZY 206 兼容）

### 链路帧

```text
F1/F2/F3/F4 + 中心站地址 + 测站地址 + 链路标识 + CRC + 帧尾
```

### 信息帧

```text
STX + LEN + 中心站地址 + 测站地址 + FC + 数据 + CRC16 + ETX
```

```text
STX = 0x02
LEN = 1 字节
中心站地址：1-2 字节 BCD
测站地址：1-2 字节 BCD
FC：功能码
数据：可变
CRC16：2 字节
ETX = 0x03
```

## 功能码（FC）扩展

在 SZY 206 基础上扩展：

| FC | 含义 | 方向 |
| --- | --- | --- |
| 0x30 | 自报小时数据 | 测站→中心 |
| 0x31 | 自报分钟数据 | 测站→中心 |
| 0x32 | 加报 | 测站→中心 |
| 0x33 | 召测 | 中心→测站 |
| 0x34 | 召测应答 | 测站→中心 |
| 0x35 | 历史数据回传 | 测站→中心 |
| 0x38 | 时间校准 | 中心→测站 |
| 0x39 | 时间校准应答 | 测站→中心 |
| 0x3A | 控制命令 | 中心→测站 |
| 0x3B | 控制应答 | 测站→中心 |
| 0x60 | 多中心站切换 | 测站↔中心 |
| 0x61 | 多中心站切换应答 | 测站↔中心 |

## 历史数据回传（FC=0x35）

```text
测站 → 中心站：
  STX + LEN + 中心站 + 测站 + 0x35
    数据起始时间（YYMMDDHHmm）
    数据结束时间（YYMMDDHHmm）
    数据段（多个要素 + 时间 + 数值）
  CRC + ETX
```

工程实践：

```text
1. 中心站发送回传请求
3. 测站从本地存储读取历史数据
5. 分批上传（按时间段）
7. CRC 验证
```

## 多中心站切换（FC=0x60 / 0x61）

```text
0x60  测站发多中心站切换请求
0x61  新中心站确认
```

工程实现：

```text
1. 测站连接多中心站（如省级 + 地市级）
3. 主中心站失效 → 切到备用中心站
5. FC=0x60 触发切换
7. 新中心站 FC=0x61 确认
```

## 加密扩展

SL/T 427 部分省份要求加密信道：

```text
DES / 3DES / AES 加密
密钥：每台设备独立
```

工程实现：

```text
加密标志：0x01 DES / 0x02 AES
加密范围：数据段
密钥协商：连接建立时
```

## 通信流程（与 SZY 206 类似）

```text
1. 测站主动连接中心站 TCP
3. 链路建立 F2
5. 链路维持 F1（心跳）
7. 业务交互（自报 / 召测 / 历史回传 / 控制）
9. 链路释放 F3
```

## 数据格式

要素编码与 SZY 206 一致：

```text
要素类型 + 测量类型 + 数值字节数 + 小数位 + BCD 数值
```

## 与 SZY 206 区别

| 维度 | SZY 206 | SL/T 427 |
| --- | --- | --- |
| 应用 | 基础水资源 | 水资源扩展 |
| 重点 | 取水流量 | 水质 + 灌区 + 取水许可细化 |
| 编码 | 基础要素 | 扩展要素（水质 / 灌区） |
| 中心站 | 单 / 双中心站 | 多中心站 |
| 加密 | 可选 | 部分省份强制 |
| 历史数据 | 简单 | 完整历史回传 |

## 适用场景

- 水资源精细化监测。
- 灌区用水监测。
- 水质监测数据传输。
- 多中心站水资源调度。
- 加密信道数据传输。

- TCP 端口已开。
- 链路建立 F2 流程跑通。
- 链路维持 F1 心跳正常。
- 自报周期符合省级要求。
- 召测应答能正常返回。
- 控制命令能正确应答。
- 时间校准能正常执行。
- 历史数据回传支持。
- 多中心站切换支持。
- 加密信道（如省级要求）。
- 水质要素字典配置。
