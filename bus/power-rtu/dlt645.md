# DL/T 645

## 定位

DL/T 645 是国内多功能电能表通信规约，用于电力集抄、配电监测和 RTU 接入电表。

```text
DL/T 645-1997：第一版，部分地区仍在用
DL/T 645-2007：当前主流版本
DL/T 698.45：下一代（基于对象/类，面向未来）
```

本文聚焦 DL/T 645-2007（行业简称 645）。

## 协议分层

```text
物理层：RS485（主推）/ 红外（手持抄表）/ PLC（部分）
链路层：主-从半双工
应用层：数据标识编码 + 数据项
```

物理接口：

```text
RS485：半双工，最常用
红外：38 kHz 调制，手持抄表
电力载波：部分老表
```

## 数据模型

DL/T 645 用 **数据标识编码 DI（4 字节）** 标识数据项：

```text
D0 D1 D2 D3 → DI 高字节到低字节
```

DI 编码规则：

```text
D0：数据类别（如 00 = 电能）
D1：变量类型（如 00 = 当前，01 = 上月）
D2..D3：数据项和费率 / 时段细分
```

常用数据项：

```text
00000000  当前组合有功总电能
00010000  当前正向有功总电能
00020000  当前反向有功总电能
0001xxxx  当前正向有功（xxxx = 01..04 费率）
0001xxFF   块码（块读码块 / 块读码块）
02010100  当前 A 相电压
02010200  当前 A 相电流
02010300  当前 A 相有功功率
02010400  当前 A 相无功功率
02020100  当前 B 相电压
02020200  当前 B 相电流
02010300  瞬时有功功率
0201FF00  块码：所有瞬时量
0301xxxx  日冻结有功总电能
0302xxxx  月冻结有功总电能
0400xxxx  事件记录（掉电、需量清零等）
```

**编码示例**：

```text
00000100 表示：D0=00（电能）、D1=00（当前）、D2=01（正向有功）、D3=00（总）
```

DI 的字节序：

```text
DI 高字节（D0）先发，低字节（D3）后发
数值按高位在前发送（电能类应用）
```

数据格式：
```text
电能：XXX.XXXX kWh（4 位小数）→ 4 字节 BCD
电压：XXX.X V（1 位小数）→ 2 字节 BCD
电流：XXX.XXX A（3 位小数）→ 3 字节 BCD
功率：XX.XXXX kW（4 位小数）→ 3 字节 BCD
```

## 帧格式

```text
68 A0 A1 A2 A3 A4 A5 68 C L D0 D1 D2 D3 [DATA] CS 16
```

字段：

```text
68      ：起始符 1
A0..A5  ：表地址（6 字节 BCD，低字节 A5 = 表号低地址先识别）
68      ：第二起始符
C       ：控制码 1 字节
L       ：数据长度 1 字节（从 D0 到 DATA 末的字节数）
D0..D3  ：数据标识 DI 4 字节
DATA    ：数据（读响应有数据，加写入响应无数据，加写命令有数据）
CS      ：校验字节（从 68 到 DATA 累加和取低 8 位）
16      ：结束符
```

## 控制码（C）

主站控制码：

```text
0x01  读数据
0x02  读后续数据（多帧）
0x03  重读数据（异常重试）
0x04  读数据（写通讯地址）
0x06  写数据（指定 DI）
0x07  写后续数据（多帧）
0x08  修改密码
0x09  清零（最大需量）
0x0A  事件清零
```

从站响应控制码：

```text
0x81  正常读响应
0x82  正常读后续响应
0x84  写命令响应
0x88  修改密码响应
0x91  异常响应（错误信息字）
```

异常响应字节：

```text
0xC1 ERR（错误信息字）
0xC2 ...
ERR：1 字节，标识错误码
ERR=0x02  没有请求的数据
ERR=0x04  密码错 / 未授权
ERR=0x05  其他
```

## 读写流程

### 读数据（控制码 0x01）

主站请求：

```text
68 AA AA AA AA AA AA 68 01 02 D0 D1 D2 D3 CS 16
```

字段：

```text
AA AA AA AA AA AA ：表地址（默认 AA AA AA AA AA AA 表示广播）
01                ：控制码 0x01
02                ：数据长度 0x02（仅 DI 4 字节 = 8 字节？）

实际 645 数据长度 = D0..D3 + DATA 的总字节数
     DI 占 4 字节
     所以读请求时 L = 4
```

实际正确写法：

```text
68 AA AA AA AA AA AA 68 01 04 D0 D1 D2 D3 CS 16
```

从站响应：

```text
68 AA AA AA AA AA AA 68 81 [L] D0 D1 D2 D3 DATA CS 16
```

DATA 内容根据 DI 解析（BCD 编码）。

### 写数据（控制码 0x04 或 0x06）

645-2007 写数据需要先验证密码：

```text
1. 主站：68 01 04 0x000 07 PASSWORD CS 16 （写密码指令）
3. 从站：68 01 04 PASSWORD CS 16 → C 改为 0x84 表示成功
5. 主站：68 01 04 D0 D1 D2 D3 DATA CS 16 （写数据）
7. 从站：68 04 D0 D1 D2 D3 CS 16 → C 改为 0x84 确认
```

写密码流程：

```text
第 1 步：0x00000007 + 旧密码 + 新密码（按 04 控制码）
第 2 步：从站返回成功（控制码 0x84）
```

## 多帧协议（块读）

数据量大时一次读不完：

```text
1. 主站：68 01 04 D0 D1 D2 D3 CS 16 （请求）
3. 从站：68 81 [L] D0 D1 D2 D3 [PART1] CS 16 （部分数据 + 后续帧标志）
5. 主站：68 02 04 D0 D1 D2 D3 CS 16 （读后续）
7. 从站：68 82 [L] D0 D1 D2 D3 [PART2] CS 16 （后续部分）
9. 重复直到读完
```

后续帧标志：DI 中高字节（D0）最高位为 1 表示后续还有帧。

## 串口参数

```text
默认 2400 / 8E1 / 1200 / 2400 / 4800 / 9600
8E1（偶校验）
```

常用：

```text
2400 8E1（默认）
4800 8E1
9600 8E1
```

## 地址

表地址 6 字节 BCD 编码：

```text
出厂默认 999999999999（12 个 9，未配表地址）
本地配置 6 字节 BCD
广播地址 AA AA AA AA AA AA
```

## 通信速率自适应

部分电表支持自动识别波特率（自适应）：

```text
1. 主站发读命令
3. 如果没响应 → 尝试其他波特率
5. 通信成功 → 锁定波特率
```

工程实现：

- 初始 2400，失败重试 1200 / 4800 / 9600。
- 部分表需要 5 秒内的重试窗口。

## 密码

DL/T 645-2007 写数据需要密码（4 字节）：

```text
密码 0：最高权限（工厂）
密码 1：02 级密码（写参数）
密码 2：04 级密码（清零）
```

默认密码：

```text
DL/T 645-2007 默认密码通常 00000000（每家电表厂商可能不同）
```

## 检查清单

- RS485 串口参数与电表一致（2400 8E1 默认）。
- 帧格式 68 ... 68 CS 16 解析正确。
- 表地址 6 字节 BCD 默认 999999999999 / AA AA AA AA AA AA 广播。
- 控制码主站 0x01/0x04/0x06 + 从站 0x81/0x84 区分。
- 数据标识 DI 4 字节编码正确。
- 数据格式 BCD 编码解码正确。
- 校验字节 CS = 累加和取低 8 位。
- 写数据前密码流程正确。
- 多帧协议（块读）支持。
- 异常响应 ERR 字段正确处理。
- RS485 半双工 DE 时序正确。
