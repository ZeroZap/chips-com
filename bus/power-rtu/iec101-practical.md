# IEC 60870-5-101 Practical Guide

## 目标

本文用于把 IEC 101 串行链路工程调通：FT1.2 帧收发、链路建立、ASDU 解析、主从通信流程和调试方法。

## 串口参数

典型参数：

```text
1200 / 2400 / 9600 baud
8E1（数据 8 位 + 偶校验 + 1 停止位）较常见
或 8N1（无校验）
```

主站和 RTU 关键参数完全一致：

```text
baud rate
data bits
parity
stop bits
link address
common address
```

## 硬件连接

非平衡传输场景：

```text
主站串口 → RS485 收发器 → A/B → RTU 串口
或               RS232 直连
```

工程注意：

- 半双工 RS485：方向控制 DE 等待 UART TC。
- 长线两端 120Ω 终端。
- 隔离收发器（工业现场）。

## 帧格式速记

### 固定长度帧（10 字节）

```text
10 01 C A 00 CS 16
```

- `10`：启动字符（固定帧）。
- `01`：长度 = 1（仅 1 字节控制域）。
- `C`：控制域 1 字节。
- `A`：链路地址 1 字节。
- `00`：ASDU 长度 = 0。
- `CS`：校验字节。
- `16`：结束字符。

### 可变长度帧

```text
68 L L 68 C A [ASDU] CS 16
```

- `68`：启动字符（可变帧）。
- `L`：长度字节，重复 2 次。
- `68`：第二个启动字符。
- `C`：控制域。
- `A`：链路地址。
- `ASDU`：应用数据。
- `CS`：校验字节。
- `16`：结束字符。

校验字节 CS 计算：

```text
控制域 + 链路地址 + ASDU 长度（固定帧）/ ASDU（可变帧）字节累加和取低 8 位
```

## 控制域速记

主站启动（DIR=0, PRM=1）：

```text
控制域 = 0x40 + 功能码
例：复位远方链路 → 0x40
例：请求链路状态 → 0x48
```

从站响应（DIR=1, PRM=0）：

```text
控制域 = 0x80 + 功能码
例：复位确认 → 0x80
例：链路状态 OK → 0x8B
```

## 报文示例（十六进制）

### 复位远方链路

主站 → 从站（地址 1）：

```text
10 40 01 00 41 16
```

字段：

```text
10：启动字符（固定帧）
40：控制域 0x40（PRM=1, 功能码 0）
01：链路地址 1
00：ASDU 长度 0
41：CS = 0x40 + 0x01 + 0x00 = 0x41
16：结束字符
```

从站响应：

```text
10 80 01 00 81 16
```

字段：

```text
10：启动字符（固定帧）
80：控制域 0x80（PRM=0, 功能码 0）
01：链路地址 1
00：ASDU 长度 0
81：CS
16：结束字符
```

### 请求链路状态

主站：

```text
10 49 01 00 4A 16
```

从站响应：

```text
10 8B 01 00 8C 16
```

### 总召唤命令 C_IC_NA_1

可变长度帧（地址 1，公共地址 1，QOI=1 总召唤）：

```text
68 0C 0C 68 73 01
   64 01 06 00 01 00 00 01 00 00 00
   7D 16
```

字段：

```text
68：启动
0C：长度 12（控制域 + 地址 + ASDU）
68：第二启动
73：主站启动 (PRM=1)，功能码 = 0x13 (请求数据1级)，DIR=0, FCB 翻转
01：链路地址 1
64：类型 C_IC_NA_1
01：VSQ = 1
06：传输原因 = 6 激活
00 01：公共地址 = 1
00：QOI = 0
01：QOI 字节，0 = 总召唤不指定用途
00 00 00：信息体地址起点
7D：CS
16：结束
```

总召唤响应示例：单点信息 M_SP_NA_1。

```text
68 ...
   01 0A 07 00 01 00 00 01 01 03
```

含义：

```text
类型 01 = M_SP_NA_1
VSQ 0A = SQ=1, 10 个对象
COT 07 = 激活确认
公共地址 01 00
信息体地址起点 00 01 = 1
值：01 03 ... （合，良好）
```

## 链路建立过程

```text
1. 主站发复位远方链路 (10 40 01 00 CS 16)
3. 从站回复复位确认 (10 80 01 00 CS 16)
5. 主站发请求链路状态 (10 49 01 00 CS 16)
7. 从站回复链路状态 OK (10 8B 01 00 CS 16)
9. 主站发总召唤 (C_IC_NA_1)
11. 从站回复总召唤响应（多个 ASDU）
13. 从站回复总召唤结束
15. 周期性时钟同步 (C_CS_NA_1)
```

## FCB 翻转

```text
主站对同一从站依次发命令时：
  第 1 次：FCV=1, FCB=0
  第 2 次：FCV=1, FCB=1
  第 3 次：FCV=1, FCB=0
  ...
每次成功响应后 FCB 翻转
```

## 调试工具

- 串口抓包：WireShark + IEC 101 dissector（有限支持）。
- 串口转发到 TCP：socat 或硬件转换器。
- 串口调试助手：AccessPort、ComTools。
- IEC 101 主站模拟：openSCD、lib60870。

## 调试步骤

1. 用 USB-RS485 工具确认链路物理层（A/B、波特率、校验）。
2. 串口抓包确认 10 01 ... 16 和 68 ... 16 两种帧。
3. 控制域 DIR/PRM/FCB/FCV 解析正确。
4. 链路建立流程跑通（复位 → 状态 → 总召唤）。
5. 总召唤 ASDU 全部解析（Type / VSQ / COT / IOA）。
6. 变位突发模式触发，确认上传。
7. 命令下行（选择 + 执行）。

## 常见问题

| 现象 | 优先检查 |
| --- | --- |
| 收不到任何帧 | A/B、波特率、校验、地址 |
| 帧定界错 | 启动字符识别、长度字段、CS 校验 |
| 控制域解析错 | DIR/PRM 位掩码 |
| 总召唤响应不全 | ASDU 类型映射错 |
| 命令执行无确认 | SE 选择 → 执行流程错 |
| FCB 不同步 | 主站 / 从站重置逻辑 |
| 突发数据堆积 | 缓存或限速机制 |

## 实战检查清单

- 串口参数与主站一致。
- A/B、地址、波特率、校验确认。
- 帧定界 10 01 / 68 ... 68 / 16 解析正确。
- 控制域 DIR/PRM/FCB/FCV 解析正确。
- 链路建立流程跑通。
- 总召唤 / 时钟同步 / 突发上传三类基础正常。
- 校验字节 CS 计算正确。
- 命令带选择 → 执行流程正确。
- RS485 半双工 DE 时序正确。
- 工业现场隔离 / 终端电阻 / 偏置电阻符合。
