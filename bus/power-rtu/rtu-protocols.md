# RTU 协议全集

## 定位

本文从 **RTU 设备**（远动终端 / Remote Terminal Unit / SCADA Gateway）视角，汇总工业 / 电力 / 水利 / 环保 / 表计 / 楼宇 / 物联网项目的协议覆盖清单。

原则：

```text
先把协议清单做全，覆盖面上去了，才有资格谈特色。
```

RTU 设备的本质是 **多协议汇聚 + 北向上行**：

```text
现场设备 / 传感器 / 仪表
        |
        v
    RTU（远动终端）
        |
        v
调度中心 / 行业云平台 / MES
```

清单做全是 RTU 产品立项的第一关。任何细分场景（电力 / 水利 / 环保 / 楼宇 / 表计）都有"硬门槛"协议——不补齐直接出局。

## RTU 设备分层

```text
应用层    : MQTT / OPC UA / 北向 API / 私有云协议
协议层    : IEC 104 / DNP3 TCP / IEC 61850 / SL651 / HJ212 / BACnet / OPC UA
链路层    : IEC 101 / DNP3 Serial / Modbus RTU / DL/T 645 / CJ/T 188
物理层    : RS485 / RS232 / 以太网 / 光纤 / 4G/5G / NB-IoT
```

注意：

- 同一个协议可能跨多层，例如 DNP3 既是链路层也是协议层。
- "RTU" 在不同文档里有时指链路层传输模式（Modbus RTU / IEC 101 RTU 帧），有时指设备本身（远动终端）。本文采用后者。

## 必选协议工程要点

### IEC 60870-5-101 / 104

- 101 = 串行（RS485/RS232）远动，FT1.2 帧格式；104 = TCP 上的 101，主流上行方式。
- 数据模型：单点/双点命令、归一化值、标度化值、步位置、位串、文件传输。
- 链路层：平衡传输（双方都能起传输）和非平衡传输（主站主导）两种工作方式。
- 报文：ASDU（应用服务数据单元）+ 链路层控制域；下行命令要带选择-执行-撤销三步。
- 101 帧定界：固定 `0x68` 起始符 + 长度 + `0x68` + 控制域；104 用 TCP 字节流 + 长度前缀。

### DNP3

- 三层架构：链路层 + 传输层 + 应用层；传输层可分段长报文。
- 数据对象：Binary Input / Output / Counter / Analog / Octet String 等。
- 报告模式：Class 0/1/2/3 + 事件触发 + Integrity Poll（全局扫描）。
- Secure Authentication（SA v5/v6）：HMAC + 挑战应答，抗中间人和重放。
- 串行 vs TCP：链路层通用，仅物理介质不同。

### IEC 61850

- 建模核心：逻辑设备 LD + 逻辑节点 LN + 数据对象 DO + 数据属性 DA。
- 通信：MMS（Client/Server，TCP）+ GOOSE（多播，站内高速跳闸）+ Sampled Values（采样值）。
- 配置用 SCL 文件（ICD/SSD/IID/CID），系统集成商强相关。
- 高端 RTU 必备，MMS 必须支持，GOOSE 是差异化加分项。

### SL651-2014 / SZY206-2016 / SL/T 427

- 中心站-测站结构：定时自报 + 召测 + 响应三种基本交互。
- 链路层多基于 TCP/UDP + 短信（GSM 备份通道）。
- 数据类型：雨量、水位、流量、流速、含沙量、闸位等水文要素。
- 部分省份要求过省级水文接入测试才能落地。

### HJ212-2017

- TCP/UDP + JSON 文本协议，排污口 / 空气站 / 噪声通用。
- 命令码 + MN（设备唯一编号）+ 数据段；上传污染因子实时 + 分钟数据。
- 必须支持心跳、应答、命令响应三类基本交互。
- 多省环保平台有定制扩展（污染因子字典、命令集）。

### DL/T 645 / CJ/T 188

- 电力 / 水气表通信规约，串行 RS485 半双工。
- 主-从通信；帧结构：起始符 + 长度 + 控制码 + 数据 + 校验 + 结束符。
- 645-2007 是国内多功能电能表通讯规约，CJ/T 188 覆盖冷 / 热量表。
- 注意 645 多帧协议（数据超过单帧容量时分段）。

### BACnet

- 楼宇自动化协议，对象模型（Analog Value / Binary Value / Device / Schedule 等）。
- 物理层支持 BACnet/IP（以太网）+ BACnet MS/TP（RS485）+ BACnet Ethernet。
- 暖通空调、照明、安防、能源管理通用协议。
- 智慧城市 / 楼宇集成常作为对接标准。

### OPC UA

- 信息建模 + 加密传输，替代 OPC Classic。
- 地址空间 = 节点树，支持订阅、方法调用、历史访问。
- 工业 4.0 / 数字孪生 / 工厂 MES 对接。
- 与 MQTT 互补：MQTT 偏轻量上行，OPC UA 偏工业信息建模。

## RTU 协议组合典型场景

### 变电站 RTU

```text
现场：保护装置 / 测控装置（IEC 61850 MMS / GOOSE）
上行：调度中心（IEC 104 / DNP3 TCP）
```

### 配电房 RTU

```text
现场：电表（DL/T 645）/ 开关 / 传感器（Modbus RTU）
上行：配电主站（IEC 104 / DNP3）
```

### 水文站 RTU

```text
现场：水位计 / 雨量计（Modbus RTU / SL651 内部表示）
上行：省 / 市水文平台（SL651-2014）
```

### 取水口 RTU

```text
现场：流量计 / 阀门 / 水表（CJ/T 188 / Modbus RTU）
上行：水资源平台（SZY206-2016）
```

### 排污口 RTU

```text
现场：流量计 / COD / PH（Modbus RTU）
上行：环保平台（HJ212-2017）
```

### 楼宇边缘网关

```text
现场：暖通 / 照明 / 电表（BACnet / Modbus RTU / DL/T 645）
上行：云平台（MQTT / OPC UA）
```

### 工业 IoT 网关

```text
现场：PLC / 仪表（Modbus RTU / OPC UA）
上行：MES / 云（MQTT / OPC UA）
```

## 选型决策速查

| 场景 | 必选协议 | 加分协议 |
| --- | --- | --- |
| 国内电力 RTU | IEC 104 + DL/T 645 | IEC 101（兼容存量）、IEC 61850 |
| 出海电力 RTU | DNP3（Serial/TCP） | IEC 104、IEC 61850（高端）、DNP3 SA |
| 智慧水务 RTU | SL651-2014 + CJ/T 188 | SZY206-2016、Modbus RTU |
| 排污口 RTU | HJ212-2017 + Modbus RTU | DL/T 645（电表） |
| 楼宇边缘网关 | BACnet + Modbus RTU + MQTT | OPC UA、DL/T 645 |
| 工业 IoT 网关 | Modbus RTU + OPC UA + MQTT | BACnet（楼宇项目） |

## chips-com 覆盖现状与路线图

按"清单做全"原则盘点：

```text
✅ 已覆盖   ：Modbus RTU/TCP、MQTT
🔴 待建 A 档：IEC 101/104、HJ212-2017、SL651-2014、DL/T 645
🟠 待建 B 档：DNP3、SZY206-2016、IEC 61850
🟡 待建 C 档：BACnet、OPC UA、CJ/T 188
```

优先级建议：

- **A 档（高优先 / 国内必选）**：IEC 101/104、HJ212-2017、SL651-2014、DL/T 645。这些是国内 RTU 项目立项的基础门槛，缺一不可。
- **B 档（中优先 / 出海 + 差异化）**：DNP3（含 SA）、SZY206-2016、IEC 61850。出海电力 / 智慧水务 / 高端差异化场景必须。
- **C 档（低优先 / 拓展）**：BACnet、OPC UA、CJ/T 188。楼宇 / 工业 4.0 / 智慧水务细分场景按需补齐。

每个协议建议建立 **三件套**（参考现有 chips-com 命名）：

```text
<protocol>.md          # 总览（定位 / 数据模型 / 适用场景）
<protocol>-practical.md # 工程实战（接线 / 调试 / 排障）
<protocol>-deep-dive.md # 深度（状态机 / 边界 / 实现）
```
