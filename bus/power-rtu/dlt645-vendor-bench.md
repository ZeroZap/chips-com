# DL/T 645 主流厂商 / 产品对标

## 定位

DL/T 645 是国内电能表通信规约。本文梳理 DL/T 645 在电力行业的典型厂商和产品。

## 选型决策

```text
DL/T 645 应用场景
├── 居民电能表
│   └── 国内厂商首选（按省网招标）
├── 商业 / 工业电表
│   └── 国内厂商（按需 + 海外 Modbus 兼容）
├── 集中抄表系统
│   └── 集中器 + 电表（国内厂商）
├── 海外项目
│   └── 海外厂商（Modbus / IEC 62056）
└── 智能电表（下一代）
    └── DL/T 698.45（基于对象）
```

## 行业大厂对标补充

```text
国家电网招标：
- 主要供应商：三星 / 宁波水表 / 海兴 / 威胜 / 林洋 / 积成
- 各省电网独立招标，地区倾向不同

南方电网招标：
- 主要供应商：海兴 / 三星 / 宁波水表 / 华立

国网集中采购：
- 主流厂商均参加

地方电网（蒙西 / 陕西 / 广西）：
- 各厂商均可投标
```

## 关键参数

```text
1. 计量精度：1 级 / 2 级
2. 通信方式：RS485 / 红外 / 电力载波
3. 阶梯电价：必备（国网招标要求）
4. ESAM：必备（远程购电要求）
5. 远程控闸：必备（智能电表要求）
6. 历史冻结：必备
```
