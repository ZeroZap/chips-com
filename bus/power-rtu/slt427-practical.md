# SL/T 427 Practical Guide

## 目标

本文用于把 SL/T 427 工程链路调通：TCP 接入、信息帧解析、水质要素扩展、历史数据回传、多中心站切换、加密信道和省级水资源平台对接。

## TCP 接入

```text
测站（client）→ TCP:port → 中心站（server）
```

常见端口：与 SZY 206 一致（8000 / 5000）。

## 帧格式（与 SZY 206 兼容）

```text
STX + LEN + 中心站地址 + 测站地址 + FC + 数据 + CRC16 + ETX
```

字段：

```text
STX = 0x02
LEN = 1 字节
中心站地址：1-2 字节 BCD
测站地址：1-2 字节 BCD
FC：1 字节
数据：可变
CRC16：2 字节
ETX = 0x03
```

## 数据格式

要素编码与 SZY 206 一致：

```text
要素类型 + 测量类型 + 数值字节数 + 小数位 + BCD 数值
```

例：pH 6.8：

```text
0x41 0x01 0x03 0x01
[0x41][0x01][0x03][0x01][0x06][0x80][0x00]
要素类型 + 测量类型 + 3 字节数值 + 1 位小数 + 680 = 68.0 / 10 = 6.8
```

## 历史数据回传（FC=0x35）

```text
1. 中心站发召测历史数据请求
3. 测站从本地存储读取历史数据
5. 测站发 FC=0x35 + 历史数据
7. 数据分批上传（按时间段）
9. CRC 验证
```

工程实现：

```text
本地存储：
  Flash / SD 卡
  按时间索引
  压缩存储（如 gzip）
上传：
  按小时 / 天分批
  每批 < 1500 字节（避免分包）
```

## 多中心站切换

```text
1. 测站配置多中心站（主 + 备）
3. 主中心站心跳失败 3 次 → 切备
5. 测站发 FC=0x60 切换
7. 新中心站发 FC=0x61 确认
9. 测站连接新中心站
```

工程实现：

```text
主中心站列表：
  [{addr: 0x01, ip: "1.1.1.1", port: 8000}, ...]

心跳状态：
  每 30s 发送心跳
  失败累计 → 切换

切换流程：
  1. 断开主中心站
  3. TCP 连接备中心站
  5. 发 F2 链路建立
  7. 发 FC=0x60 切换
  9. 等待 FC=0x61 确认
  11. 继续业务交互
```

## 加密信道

加密扩展：

```text
DES / 3DES / AES
密钥：每台设备独立
加密范围：数据段
加密标志：FC 字段高字节
```

工程实现：

```text
加密标志：
  0x00 明文
  0x01 DES
  0x02 AES-128
  0x03 AES-256

密钥协商：
  连接建立时
  主密钥 + 临时密钥
  中心站认证
```

## 通信流程

```text
1. 测站连接主中心站
3. 链路建立 F2
5. 链路维持 F1（心跳）
7. 业务交互
9. 主中心站失效 → 切备中心站
11. 备中心站 FC=0x60 切换
13. 备中心站 FC=0x61 确认
15. 继续业务
```

## 自报策略

```text
定时自报（FC=0x30 / 0x31）：
  每 1 / 5 / 30 分钟 / 1 小时
  流量、累计、水位、水质参数

加报（FC=0x32）：
  水质超阈值
  流量超阈值
  设备故障
  取水异常
```

## 调试工具

- TCP 调试：网络调试助手。
- Wireshark：SL/T 427 dissector（有限，复用 SL 651）。
- 平台模拟器：省级水资源平台测试工具。

## 调试步骤

1. 确认测站地址 / 中心站地址已注册。
2. TCP 连接到中心站。
3. 发链路建立 F2，确认中心站确认。
4. 发链路维持 F1，确认中心站回应。
5. 发水质自报 FC=0x30，确认收到。
6. 发历史数据回传 FC=0x35。
7. 多中心站切换测试。
8. 加密信道（如省级要求）。

## 常见问题

| 现象 | 优先检查 |

| 历史回传失败 | 时间 / 数据段 |
| 多中心站切换失败 | 备中心站配置 |

## 实战检查清单

- TCP 端口与省级一致。
- 测站地址 / 中心站地址 BCD 编码正确。
- 链路建立 F2 流程跑通。
- 链路维持 F1 心跳正常。
- 自报周期符合省级要求。
- 水质数据上报正常。
- 灌区数据上报正常（如需要）。
- 历史数据回传支持。
- 多中心站切换支持。
- 加密信道（如省级要求）。
