# SZY 206-2016 Practical Guide

## 目标

本文用于把 SZY 206 工程链路调通：TCP 接入、链路帧与信息帧、要素编码、自报 / 召测 / 控制应答、GSM 短信备份和省级水资源平台对接。

## TCP 接入

```text
测站（client）→ TCP:port → 中心站（server）
```

常见端口：
- 8000（多数省份）
- 5000（部分省份）

工程注意：

- 不同省份端口不同，部署前确认。
- 部分省份需要 VPN / 专网。

## 帧格式速记

### 链路帧

```text
F1/F2/F3/F4 + 中心站地址 + 测站地址 + 链路标识 + CRC + 帧尾
```

帧首：

```text
F1 = 0x46 0x31
F2 = 0x46 0x32
F3 = 0x46 0x33
F4 = 0x46 0x34
```

帧尾 = 0x03

### 信息帧

```text
STX + LEN + 中心站地址 + 测站地址 + FC + 数据 + CRC16 + ETX
```

## 要素编码速查

```text
0x00  累计流量 m³
0x01  瞬时流量 m³/h
0x02  日累计流量
0x03  月累计流量
0x10  水位 m
0x20  瞬时取水量
0x21  日累计取水量
0x30  地下水位
0x31  地下水埋深
0x40  水质参数
0x50  阀门开度
0x51  阀门状态
0x60  泵运行状态
0x70  取水许可状态
```

## 测量类型

```text
0x01  瞬时值
0x02  累计值
0x03  平均值
0x04  最大值
0x05  最小值
```

## 通信流程

### 链路建立

```text
1. 测站连接中心站 TCP
3. 测站发 F2 链路建立
5. 中心站回 F2 确认
9. 进入业务交互
```

### 链路维持（心跳）

```text
测站每 1-5 分钟发 F1
中心站回 F1
超时 → TCP 重连
```

### 自报

```text
定时自报（FC=0x30 / 0x31）：每固定周期
加报（FC=0x32）：实时触发
```

### 召测应答

```text
中心站发 FC=0x33 + 召测类型
测站发 FC=0x34 + 召测数据
```

### 控制应答

```text
中心站发 FC=0x3A + 控制内容
测站发 FC=0x3B + 控制结果
```

### 时间校准

```text
中心站发 FC=0x38 + 时间
测站发 FC=0x39 + 应答
```

## GSM 短信备份

短信编码：

```text
短信内容 = SZY 206 信息帧（去 STX/ETX）
PDU 7-bit 编码
中心站号：固定 SIM 卡号
```

工程实现：

```text
1. TCP 连接失败 → 切到短信
3. 短信内容 = SZY 206 信息帧
5. 短信编码：7-bit 编码
7. 中心站号：因本号
10. 读取订单通过 ATINU + MDCMGS
```

## 加报阈值

工程常见加报阈值：

```text
瞬时流量：变化超过 20%
累计流量：每小时累计增量超阈值
水位：变幅超过 0.05 m / 5 min
地下水位：变幅超过 0.1 m
阀门状态：变化立即触发
泵运行：状态变化立即触发
```

- TCP 调试：网络调试助手。

- 短信调试：AT 命令 + 短信猫。
- 平台模拟器：省级水资源平台测试工具。

## 调试步骤

1. 确认测站地址 / 中心站地址已注册。
2. TCP 连接到中心站。
3. 发链路建立 F2，确认中心站确认。
4. 发链路维持 F1，确认中心站回应。
5. 发自报 FC=0x30，确认收到。
6. 发召测 FC=0x33，确认收到。
7. 发控制 FC=0x3A，确认收到。
8. 时间校准 FC=0x38，确认生效。
9. 切 GSM 短信备份，确认能发送。

## 常见问题

| 现象 | 优先检查 |
| --- | --- |
| TCP 连接失败 | IP / 端口 / 4G 信号 |
| 链路建立失败 | 测站地址 / 中心站地址 |
| 自报收不到 | FC / 时间 / 要素编码 |
| 召测无应答 | 测站忙 |
| GSM 短信失败 | SIM 卡 / 信号 |
| CRC 不一致 | 算法 |
| 中心站不存数据 | 要素代码 |

## 实战检查清单

- TCP 端口与省级一致。
- 测站地址 / 中心站地址 BCD 编码正确。
- 链路建立 F2 流程跑通。
- 链路维持 F1 心跳正常。
- 自报周期符合省级要求。
- 召测应答能正常返回。
- 控制命令能正确应答。
- 时间校准能正常执行。
- 加报阈值合理。
- 多信道备份（GSM / 北斗）。
- CRC 计算正确。
- 要素编码正确。
