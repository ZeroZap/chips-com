## 选型决策

```text
HJ 212 应用场景
├── 排污口 / 烟气
│   └── 聚光 / 先河 / 雪迪龙
├── 空气站
│   └── 聚光 / 先河 / 雪迪龙
├── 地表水
│   └── 聚光 / 力合
├── 噪声
│   └── 杭州爱华 / 嘉兴博远
├── 省级平台对接
│   └── 按省确认（佛山 / 浙江 / 江苏等定制）
└── 海外
    └── Sick / Horiba / 国产出海版
```

## 省级平台对接要点

```text
1. 不同省份端口不同
2. 不同省份因子字典可能不同
3. 不同省份加密要求可能不同
4. 不同省份超标阈值不同
5. 部署前必须与省级平台对接
```
