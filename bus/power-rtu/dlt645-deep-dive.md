# DL/T 645 Deep Dive

## 目标

本文深入 DL/T 645 工程细节，重点解决帧定界、表地址、数据标识编码、BCD 解码、密码管理、块读协议、安全合规和现场排障。

## 协议栈分层

```text
物理层：RS485（主）/ 红外 / 电力载波
链路层：主-从半双工串行
应用层：DI 编码 + 数据项
```

DL/T 645 与 IEC 62056-21（IEC 1107）相比：
- 62056-21：国际 IEC 标准，部分电表也支持
- 645：国内标准，国内电表主流

## 版本对比

### 645-1997

```text
帧格式：FE FE FE 68 A0 A1 A2 A3 A4 A5 68 C L [DI] [DATA] CS 16
头部：3 个 0xFE 前导
DI：2 字节
数据格式：与 2007 类似但更简单
密码：0 级默认 0x00000000
```

### 645-2007

```text
帧格式：68 A0 A1 A2 A3 A4 A5 68 C L [DI] [DATA] CS 16
头部：直接 0x68
DI：4 字节（更细分）
数据格式：BCD 编码
密码：4 字节
事件记录支持
多帧协议块读支持
```

### 698.45

下一代（基于对象类）：

```text
对象类标识 + 属性 + 方法
可变长度帧
支持 IPv6
面向对象建模
```

工程实践：

- 1997 版本基本淘汰。
- 2007 版本主流（2007 / 2007Q / 2018 等修订）。

## 帧格式详解

完整帧：

```text
68 A0 A1 A2 A3 A4 A5 68 C L D0 D1 D2 D3 [DATA] CS 16
```

**表地址（A0..A5）**：

- 6 字节 BCD 编码（高字节 A0 在前）。
- 出厂默认 `99 99 99 99 99 99`（12 个 9）。
- 写通讯地址前必须验证密码。
- 广播地址：`AA AA AA AA AA AA`。

**控制码（C）**：

主站控制：

```text
0x00 保留
0x01 读数据
0x02 读后续数据
0x03 重读数据
0x04 写通讯地址
0x05 写数据（保留）
0x06 写数据
0x07 写后续数据
0x08 修改密码
0x09 最大需量清零
0x0A 事件清零
0x0B 跳闸
0x0C 合闸
```

从站控制（主站控制码 + 0x80）：

```text
0x81 读响应
0x82 读后续响应
0x83 重读响应
0x84 写通讯地址响应
0x85 写数据响应（保留）
0x86 写数据响应
0x88 修改密码响应
0x89 清零响应
0x8A 事件清零响应
0x8B 跳闸响应
0x8C 合闸响应
```

异常响应：

```text
0xC1 异常响应（C = 主站控制 + 0xC0）
```

**数据长度（L）**：

```text
L = D0..DATA 字节数
读请求：L=4（仅 DI 4 字节）
读响应：L=4+N（DI + DATA）
写请求：L=4+M（DI + DATA，M 为写入字节数）
```

**数据标识（DI）**：

DI 4 字节结构：

```text
D0 D1 D2 D3
```

D0 数据类别：

```text
0x00 电能
0x01 最大需量
0x02 瞬时量（电压电流功率）
0x03 事件
0x04 参变量
0x05 冻结量
0x06 负荷记录
```

D1 变量类型：

```text
0x00 当前
0x01 上 1 结算日
0x02 上 2 结算日
...
0x0F 上 15 结算日
```

D2..D3 数据项：

```text
D2=0x00 D3=0x00 总
D2=0x01 D3=0x00 A 相
D2=0x01 D3=0x01..0x04 费率 1..4
D2=0x02 D3=0x00 B 相
D2=0x03 D3=0x00 C 相
D2=0xFF D3=0xFF 块码
```

DI 块码：

```text
0x00xxxxFF  所有电能
0x0001FF00  所有正向有功
0x0201FF00  所有瞬时量
```

## BCD 解码

DL/T 645 数据格式用 BCD：

```text
每个字节表示 2 位十进制
高 4 位：十位
低 4 位：个位
```

例：

```text
0x23 → 23
0x00 → 00
0x99 → 99
0x12 0x34 → 1234
```

电能数据格式：

```text
4 字节 BCD（电能）
小数 4 位（kWh 后 4 位小数）
例：0x00 0x12 0x34 0x56 → 1234.56 / 10000 = 0.123456 kWh = 1234.56 kWh 不对
```

实际解码：

```text
原始字节（高字节在前）：00 12 34 56
BCD 解码：00 12 34 56 → 00123456
小数位 4：00123456 → 0012.3456 kWh
```

注意 **数据格式字典**：

```text
电能  ：4 字节 BCD，4 位小数（kWh）
电压  ：2 字节 BCD，1 位小数（V）
电流  ：3 字节 BCD，3 位小数（A）
有功功率：3 字节 BCD，4 位小数（kW）
无功功率：3 字节 BCD，4 位小数（kVar）
功率因数：2 字节 BCD，3 位小数
频率  ：2 字节 BCD，2 位小数（Hz）
温度  ：2 字节 BCD，1 位小数（°C）
```

## 校验字节（CS）

```text
CS = (0x68 + A0..A5 + 0x68 + C + L + D0..D3 + DATA) mod 256
```

即从第一个 0x68 开始到 DATA 末尾累加和取低 8 位。

工程实现：

```text
uint8_t cs = 0;
for (i = 0; i < frame_len - 2; i++) {
    cs += frame[i];
}
// cs 取低 8 位（实际 uint8_t 自动溢出）
```

## 异常响应（ERR）

异常帧：

```text
68 A0 A1 A2 A3 A4 A5 68 C1 ERR CS 16
```

ERR 字节错误码：

```text
0x00  正确（无错误）
0x01  其他错误
0x02  请求数据不存在
0x03  数据标识错
0x05  数据长度错
0x06  密码错
0x07  权限不足
0x08  密码权限不够
0x09  数据溢出
0x10  时段错误
0x11  费率数错误
0x12  日历错误
0x13  阶梯错误
0x40  ESAM 错（2007 安全扩展）
```

工程实现：

```text
解析 C = 0xC1 → 异常
读 ERR 字段 → 错误码
根据错误码生成告警（方式：日志 + 上行 IEC 104 / MQTT）
```

## 密码管理

DL/T 645-2007 支持多级密码：

```text
0 级：最高权限（厂家）
1 级：读 + 关键写（如通讯地址、需量清零）
3 级：抄表者 + 一般参数
```

密码读写：

```text
DI=00000007 密码读写
读密码：0x01 + DI=00000007 + LEN=4 → 4 字节密码
写密码：0x08 + DI=00000007 + 旧密码（4 字节）+ 新密码（4 字节）
```

默认密码：

```text
0 级：00000000（厂家）
其他：每家电表厂商不同
```

写密码验证：

```text
第 1 步：当前操作员密码是否匹配
第 2 步：当前密码权限是否满足目标操作
第 3 步：所有 645 操作前必须检查权限
```

## 多帧协议（块读）

块读触发条件：

```text
1. 数据项超过单帧容量（125 字节左右）
3. DI 块码标识（如 0201FF00 读所有瞬时量）
```

块读流程：

```text
1. 主站：0x01 + DI（D0 最高位 = 1）
3. 从站：0x81 + DI + 部分数据（D0 最高位 = 1 标识后续）
5. 主站：0x02 + DI（读后续）
7. 从站：0x82 + DI + 后续部分
9. 重复直到 D0 最高位 = 0
```

实际工程：

```text
DI=0201FF00 主站：
   0x01 + DI → 期望 0x81 + DI + 部分
   0x02 + DI → 期望 0x82 + DI + 部分
   0x02 + DI → 期望 0x82 + DI + 部分
   ...
```

## 事件记录

645-2007 支持事件记录：

```text
DI=0400xxxx 事件
事件类型：
  0x04000001 掉电事件
  0x04000002 上电事件
  0x04000003 编程事件
  0x04000004 清零事件
  0x04000005 需量清零
  ...
```

事件记录内容：

```text
DI（4 字节）+ 事件发生次数 + 累计次数 + 事件发生时间（CP56）
```

事件清零（控制码 0x0A）：

```text
0x0A + DI + 安全权限 → 从站清零事件计数
```

## 冻结量

DL/T 645-2007 支持冻结量：

```text
DI=0500xxxx  日冻结（按日）
DI=0600xxxx  月冻结（按月）
DI=0700xxxx  阶梯冻结
```

冻结时间点：

```text
日冻结：默认每日 0:00
月冻结：默认每月 1 日 0:00
阶梯冻结：按阶梯计费周期
```

工程实现：

```text
冻结时间点切换数据
冻结量可读同 DI 不同 D1 区分
```

## 红外通信

红外通信：

```text
38 kHz 调制（红外）
1200 baud 默认（红外）
8E1
```

主站是手持抄表器，红外对准电表红外口。

工程注意：

- 距离：1 cm - 30 cm
- 角度：±30°
- 不能在强光下

## 通信速率自适应

部分电表支持自适应：

```text
1. 主站发读命令（2400）
3. 3 秒内无响应 → 尝试 4800 / 9600 / 1200
5. 通信成功 → 锁定波特率
```

工程实现：

```text
状态机：2400 → 4800 → 9600 → 1200 → 失败
轮询每个波特率直到成功
```

## 安全合规

DL/T 645-2007 安全扩展：

```text
ESAM（Embedded Security Application Module）：
  - 安全存储密钥
  - 加密通信
  - 防篡改
安全传输：
  - 主站 + ESAM 双向认证
  - 报文加密 + MAC 校验
```

工程实践：

- 关键表（阶梯电价、远程购电）必须支持 ESAM。
- 远程充值、远程控闸等敏感操作需要 ESAM + 密码双重验证。

## 抓包排障

串口抓包 + Wireshark（DL/T 645 dissector）：

```text
1. 帧格式：68 ... 68 ... 16
2. 表地址 6 字节 BCD
3. 控制码
4. DI 4 字节
5. DATA（BCD 编码）
6. CS 校验值
```

工程排障清单：

```text
1. 帧定界错：启动字符识别
3. CS 错：累加和计算
4. 表地址错：BCD 编码
5. DI 错：字典映射
6. DATA 错：BCD 解码
7. 控制码错：主站 / 从站区分
8. ERR 处理：异常响应解析
9. 块读不完整：0x02 后续读流程
```

## 现场常见故障

| 现象 | 优先检查 |
| --- | --- |
| 完全无响应 | A/B、波特率、校验、地址 |
| 表读不到数据 | 表地址错、未配地址、广播模式 |
| 数据格式错 | DI 字节序、BCD 解码 |
| 多帧读完不完整 | 0x02 后续读流程 |
| 写数据失败 | 密码错、权限不足 |
| ERR 错误码 | 查 ERR 定义 |
| CRC 累加失败 | CS 计算错误 |
| 红外不通 | 距离 / 角度 / 38 kHz 调制 |
| ESAM 错 | ESAM 模块、密钥、ESAM 指令 |

## 深度检查清单

- RS485 半双工 DE 等待 UART TC。
- 串口参数与电表一致（默认 2400 8E1）。
- 帧格式 68 ... 68 ... 16 解析正确。
- 表地址 6 字节 BCD（默认 999999999999）。
- 控制码主站 / 从站 / 异常三种区分。
- DI 4 字节字典正确。
- DATA BCD 编码解码正确。
- CS 校验字节计算正确。
- 读数据流程。
- 写数据密码流程。
- 块读协议支持。
- 异常 ERR 字段处理。
- 红外通信（手持）。
- 通信速率自适应。
- 事件记录支持。
- 冻结量管理。
- ESAM 安全扩展（关键表）。
- 远程控闸合规。
- 多表轮询避免总线冲突。
- 数据上行映射（IEC 104 / MQTT）。
