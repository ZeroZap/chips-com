# SL 651 产线死机案例库

## 目标

把产线常见的 SL 651 水文通信失败、TCP 连通、链路状态机、要素编码、GSM 短信备份、省级平台差异等写成案例库。

## 案例 1：TCP 端口错

### 现象

测站连不上省级水文中心。

### 排查

```text
省级端口：8000
测站端口：5000
```

### 修复

修改测站端口 = 8000。

### 复盘

```text
1. 不同省份端口不同
2. 部署前必须与省级水文中心确认
3. 8000 / 5000 是常见端口
```

## 案例 5：BCD 解码错

### 现象

测站发水位 23.45 m，中心站解析为 23.45 m（实际数据正确）。

### 排查

```text
测站 DATA = 23 45 00 00
中心站解析：0x23450000 / 100 = 2345.00 m（错）
```

### 定位

中心站 BCD 解码错。

### 修复

```c
/* BCD 解码 */
uint32_t bcd_decode(uint8_t *data, int len) {
    uint32_t val = 0;
    for (int i = 0; i < len; i++) {
        val = val * 100 + ((data[i] >> 4) * 10) + (data[i] & 0x0F);
    }
    return val;
}
```

### 复盘

```text
1. SL 651 数据全部 BCD
2. 二进制解析会得到错误数据
3. 必须 BCD 解码
```
