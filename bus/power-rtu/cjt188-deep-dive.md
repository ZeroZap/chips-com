# CJ/T 188 Deep Dive

## 目标

本文深入 CJ/T 188 工程细节，重点解决表地址、BCD 解码、密码管理、块读协议、安全合规和现场排障。

## 协议栈分层

```text
物理层：RS485（主）/ M-Bus / 红外
链路层：主-从半双工串行
应用层：DI 编码 + 数据项
```

CJ/T 188 与 DL/T 645 同源，区别在数据字典和应用领域。

## 版本对比

### CJ/T 188-2002

```text
早期版本
地址 6 字节
DI 2 字节
部分老表使用
```

### CJ/T 188-2018

```text
当前主流
地址 7 字节
DI 4 字节
BCD 编码
```

## 帧格式详解

完整帧：

```text
68 A0 A1 A2 A3 A4 A5 A6 68 C L D0 D1 D2 D3 [DATA] CS 16
```

字段说明：

```text
68      ：起始符 1
A0..A6  ：表地址（7 字节 BCD）
68      ：第二起始符
C       ：控制码
L       ：数据长度
D0..D3  ：数据标识 DI 4 字节
DATA    ：数据
CS        ：校验字节
16      ：结束符
```

## 表地址

表地址 7 字节 BCD：

```text
出厂默认：99 99 99 99 99 99 99（13 个 9）
广播地址：AA AA AA AA AA AA AA
本地配置：7 字节 BCD
```

## 控制码详解

主站控制：

```text
0x00  保留
0x01  读数据
0x02  读数据（续）
0x03  重读
0x04  写数据
0x05  写数据（续）
0x06  修改密码
0x07  清除金额（热量表）
0x08  清零（特定）
0x09  设置地址
0x0A  读历史数据
0x0B  读密钥
0x0C  初始化
```

从站响应：

```text
0x81  读数据响应
0x82  读数据（续）响应
0x83  重读响应
0x84  写数据响应
0x85  写数据（续）响应
0x86  修改密码响应
0x87  清零响应
0x88  状态响应
0x89  设置地址响应
0x8A  读历史数据响应
0x8B  读密钥响应
```

异常响应：

```text
0xC1  异常响应（含 ERR 字段）
```

## 数据标识（DI）详解

DI 4 字节结构：

```text
D0 D1 D2 D3
```

D0 数据类别：

```text
0x00  当前累计流量
0x01  当前反向累计流量（部分）
0x02  当前累计热量
0x03  当前热量功率
0x04  温度
0x05  压力
0x06  状态
0x07  历史数据
0x08  金额（热量表）
0x09  故障记录
0x0A  报警记录
```

D1 测量类型：

```text
0x00  当前
0x01  历史
```

D2..D3 数据项：

```text
0x00 0x00  总
0x00 0x01  费率 1
0x00 0x02  费率 2
0x01 0x00  入口
0x02 0x00  出口
0x03 0x00  温差
```

## BCD 解码

CJ/T 188 数据格式用 BCD：

```text
每个字节表示 2 位十进制
高 4 位：十位
低 4 位：个位
```

数据格式字典：

```text
累计流量  ：4 字节 BCD，3 位小数（m³）
瞬时流量  ：3 字节 BCD，2 位小数（m³/h）
累计热量  ：4 字节 BCD，3 位小数（GJ/MWh）
瞬时热量功率：3 字节 BCD，2 位小数（kW）
水温      ：2 字节 BCD，2 位小数（°C）
压力      ：2 字节 BCD，1 位小数（kPa）
电池电压  ：1 字节 BCD，1 位小数（V）
阀门状态  ：1 字节（00 开 / 01 关）
金额      ：4 字节 BCD，2 位小数（元）
```

## 校验字节（CS）

```text
CS = (0x68 + A0..A6 + 0x68 + C + L + D0..D3 + DATA) mod 256
```

即从 68 到 DATA 累加和取低 8 位。

工程实现：

```text
uint8_t cs = 0;
for (i = 0; i < frame_len - 2; i++) {
    cs += frame[i];
}
// cs 取低 8 位（实际 uint8_t 自动溢出）
```

## 异常响应（ERR）

异常帧：

```text
68 ... 68 C1 ERR CS 16
```

ERR 字节错误码：

```text
0x00  正确
0x01  其他错误
0x02  请求数据不存在
0x03  数据标识错
0x05  数据长度错
0x06  密码错
0x07  权限不足
0x08  密码权限不够
0x09  数据溢出
0x0A  校验错
0x10  时段错误
0x40  ESAM 错
0x50  表异常
```

## 密码管理

CJ/T 188 密码 4 字节：

```text
默认密码：00000000（每家电表厂商可能不同）
```

权限分级：

```text
0 级：厂家最高权限
1 级：抄表者 + 关键写
2 级：购电 / 充值
3 级：用户
```

密码读写 DI：

```text
DI=00000000 + LEN=4 + 4 字节密码
```

## 多帧协议（块读）

块读触发条件：

```text
1. 数据项超过单帧容量
3. DI 块码标识
```

块读流程：

```text
1. 主站：0x01 + DI（D0 最高位 = 1）
3. 从站：0x81 + DI + 部分数据（D0 最高位 = 1 标识后续）
5. 主站：0x02 + DI（读后续）
7. 从站：0x82 + DI + 后续部分
9. 重复直到 D0 最高位 = 0
```

## 历史数据（控制码 0x0A）

主站读取历史数据：

```text
68 AA AA AA AA AA AA AA 68 0A 04 + DI + 时间 CS 16
```

时间格式：YYMMDDHHmm（5 字节 BCD）。

从站返回历史数据帧：

```text
68 [地址] 68 8A LEN DI 时间 DATA CS 16
```

## 红外通信

红外通信：

```text
38 kHz 调制（红外）
1200 baud 默认
8E1
```

手持抄表器常用红外通信。

## 通信速率自适应

部分水表支持自适应：

```text
1. 主站发读命令（2400）
3. 3 秒内无响应 → 尝试 4800 / 9600
5. 通信成功 → 锁定波特率
```

工程实现：

```text
状态机：2400 → 4800 → 9600 → 1200 → 失败
轮询每个波特率直到成功
```

## 安全合规

CJ/T 188-2018 安全扩展：

```text
ESAM 模块
密钥存储
防篡改
双向认证
```

工程实践：

- 关键表（如热量表、阶梯水价表）支持 ESAM。
- 远程控制（如关阀）需 ESAM + 密码双重验证。

## 抓包排障

串口抓包 + Wireshark（CJ/T 188 dissector 有限）：

```text
1. 帧格式：68 ... 68 ... 16
2. 表地址 7 字节 BCD
3. 控制码
4. DI 4 字节
5. DATA（BCD 编码）
6. CS 校验值
```

工程排障清单：

```text
1. 帧定界错：启动字符识别
3. CS 错：累加和计算
4. 表地址错：BCD 编码
5. DI 错：字典映射
6. DATA 错：BCD 解码
7. 控制码错：主站 / 从站区分
8. ERR 处理：异常响应解析
9. 块读不完整：0x02 后续读流程
```

## 现场常见故障

| 现象 | 优先检查 |
| --- | --- |
| 完全无响应 | A/B、波特率、校验、地址 |
| 表读不到数据 | 表地址错、未配地址 |
| 数据格式错 | DI 字节序、BCD 解码 |
| 多帧读完不完整 | 0x02 后续读流程 |
| 写数据失败 | 密码错 |
| ERR 错误码 | 查 ERR 定义 |
| CRC 累加失败 | CS 计算错误 |
| 红外不通 | 距离 / 角度 |

## 深度检查清单

- RS485 半双工 DE 等待 UART TC。
- 串口参数与水表一致（默认 2400 8E1）。
- 帧格式 68 ... 68 ... 16 解析正确。
- 表地址 7 字节 BCD（默认 9999999999999）。
- 控制码主站 / 从站 / 异常三种区分。
- DI 4 字节字典正确。
- DATA BCD 编码解码正确。
- CS 校验字节计算正确。
- 读数据流程。
- 写数据密码流程。
- 块读协议支持。
- 异常 ERR 字段处理。
- 红外通信（手持抄表）。
- 通信速率自适应。
- 历史数据读取。
- ESAM 安全扩展（关键表）。
- 多表轮询避免总线冲突。
- 数据上行映射（MQTT / OPC UA / IEC 104）。
