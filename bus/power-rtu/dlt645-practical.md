# DL/T 645 Practical Guide

## 目标

本文用于把 DL/T 645 工程链路调通：RS485 接线、串口参数、帧收发、数据项解析、密码流程、读写操作和调试方法。

## 硬件接线

```text
MCU TX  → RS485 DI
MCU RX  ← RS485 RO
GPIO    → RS485 DE/RE
A/B     → 电表 A/B
GND     → 参考地
```

工程注意：

- 半双工：DE 等待 UART TC。
- 长线两端 120Ω 终端。
- 工业现场隔离收发器。
- 多表并接时主站分时轮询。

## 串口参数

```text
2400 8E1  （默认）
4800 8E1
9600 8E1
```

不同厂家电表支持的波特率可能不同。

## 帧格式速记

```text
68 A0 A1 A2 A3 A4 A5 68 C L D0 D1 D2 D3 [DATA] CS 16
```

字段：

```text
68：起始符（2 个）
A0..A5：表地址 6 字节 BCD
68：第二个起始符
C：控制码
L：数据长度（D0..DATA 总字节数）
D0..D3：数据标识 DI 4 字节
DATA：数据（可变）
CS：校验字节 = 68 到 DATA 累加和取低 8 位
16：结束符
```

## 报文示例（十六进制）

### 广播读当前组合有功总电能（DI=00000000）

主站：

```text
68 AA AA AA AA AA AA 68 01 04 00 00 00 00 CS 16
```

CS 计算：

```text
0x68 + 0xAA*6 + 0x68 + 0x01 + 0x04 + 0x00*4 = 0x68+0x408+0x68+0x01+0x04 = 0x478 → 0x78
```

实际：

```text
0x68 + 0xAA*6 = 0x68 + 0x408 = 0x470
0x68 + 0x01 + 0x04 + 0x00 + 0x00 + 0x00 + 0x00 = 0x73
总计 0x470 + 0x73 = 0x4E3 → 取低 8 位 = 0xE3
```

响应（单表）：

```text
68 12 34 56 78 90 12 68 81 08 00 00 00 00 00 01 02 03 04 CS 16
```

字段：

```text
12 34 56 78 90 12 ：表地址
78 15 04 0x81 ：控制码 0x81
08：数据长度 8（4 字节 DI + 4 字节数据）
00 00 00 00：DI
00 01 02 03 04：电能值（BCD 编码 0x0001020304 → 10.2340 kWh 后 BCD 解读）
```

实际 BCD 解码：

```text
原始字节（BCD 高字节在前）：00 01 02 03 04
转为字符串：0001020304
电能 = 01023.04 / 100 = 102.304 kWh（4 位小数）
```

### 读 A 相电压 DI=02010100

主站：

```text
68 12 34 56 78 90 12 68 01 04 02 01 01 00 CS 16
```

响应：

```text
68 12 34 56 78 90 12 68 81 06 02 01 01 00 XX XX CS 16
```

DATA：2 字节 BCD，电压 = XX.XX V（1 位小数）。

例：

```text
DATA = 0x22 0x01 → 220.1 V
```

## 控制码速查

```text
主站 → 从站
0x01 读数据
0x02 读后续数据
0x04 写通讯地址
0x06 写数据
0x08 修改密码
0x0A 事件清零

从站 → 主站
0x81 读响应
0x82 读后续响应
0x84 写响应
0x88 修改密码响应
0xC1 异常响应（ERR 字段）
```

## 读 / 写流程

### 读数据

```text
1. 主站发 0x01 + DI
3. 从站回 0x81 + DI + DATA
5. 主站解析 DATA
```

### 写数据

```text
1. 主站发 0x08 + DI=00000007 + 旧密码 + 新密码（修改密码）
3. 从站回 0x88 成功
5. 主站发 0x06 + DI + DATA（写数据）
7. 从站回 0x84 成功
```

写通讯地址（0x04 控制码）：

```text
1. 主站发 0x04 + 新地址
3. 从站回 0x84 确认（地址变更）
```

注意：645 写通讯地址前**必须**验证密码。

## 密码管理

DI 00000007 用于密码读写：

```text
D0=00 D1=00 D2=00 D3=07
```

读写密码字段：

```text
读密码 1：DI=00000007 + LEN=4 4 字节密码
写密码：DI=00000007 + 旧密码 4 字节 + 新密码 4 字节
```

## 多帧协议（块读）

块读数据项超过单帧容量时：

```text
1. 主站发 0x01 + DI（D0 最高位 = 1 表示后续有帧）
3. 从站回 0x81 + DI + 部分数据（D0 最高位 = 1）
5. 主站发 0x02 + DI（读后续）
7. 从站回 0x82 + DI + 后续部分
9. 重复直到读完
```

实际工程中电表常自带块读支持：

```text
DI=000100FF 表示读所有正向有功电能（含 4 个费率 + 总）
DI=0201FF00 表示读所有瞬时量
```

## 调试工具

- USB-RS485 转换器。
- 抄表器：宁波三星、海兴、南京联宏等厂家调试工具。
- Wireshark：DL/T 645 dissector。
- 串口调试助手：AccessPort、ComTools。

## 调试步骤

1. 用 USB-RS485 转换器 + 抄表软件先调通单表。
2. 确认表地址 6 字节 BCD（出厂 999999999999）。
3. 串口参数 2400 8E1 与表一致。
4. 发读命令 0x01 + DI=00000000，确认能读回总电能。
5. 测试读 A 相电压 / 功率等瞬时量。
6. 测试写密码 + 写数据流程。
7. 多表并接：分时轮询，避免冲突。

## 常见问题

| 现象 | 优先检查 |
| --- | --- |
| 完全无响应 | A/B、波特率、校验、地址 |
| 表读不到数据 | 表地址错、未配地址、广播模式不支持 |
| 数据格式错 | DI 字节序、BCD 解码 |
| 多帧读完不完整 | 0x02 后续读流程未实现 |
| 写数据失败 | 密码错误、权限不足 |
| ERR 错误码 | 查 ERR 定义：02=无数据、04=密码错、05=其他 |
| CRC 累加失败 | CS 计算错误 |

## 实战检查清单

- RS485 半双工 DE 时序正确。
- 串口参数 2400 8E1（默认）。
- 表地址 6 字节 BCD 解析正确。
- 控制码区分主站 / 从站。
- DI 4 字节编码正确。
- DATA BCD 解码正确。
- CS 校验字节正确。
- 读流程正常。
- 写流程密码验证正确。
- 多帧协议（块读）支持。
- 异常 ERR 字段处理。
- 多表分时访问避免总线冲突。
