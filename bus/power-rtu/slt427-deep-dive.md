# SL/T 427 Deep Dive

## 目标

本文深入 SL/T 427 工程细节，重点解决水质要素扩展、历史数据回传、多中心站切换、加密信道和现场排障。

## 协议栈分层

```text
物理层：4G / GSM / 北斗 / 光纤 / 卫星 IoT
链路层：TCP / UDP / 短信
应用层：SL/T 427 信息帧
```

SL/T 427 与 SZY 206 同源，作为水资源监测的扩展。

## 协议版本

- SL/T 427-2014（当前主流）
- 部分省份扩展版本

## 帧结构（与 SZY 206 兼容）

### 链路帧

```text
F1/F2/F3/F4 + 中心站地址 + 测站地址 + 链路标识 + CRC + 帧尾
```

### 信息帧

```text
STX + LEN + 中心站地址 + 测站地址 + FC + 数据 + CRC16 + ETX
```

## CRC16 计算

SL/T 427 CRC16 与 SZY 206 / SL 651 / Modbus 相同算法：

```text
多项式：0xA001
初值：0xFFFF
低字节在前
```

## 功能码扩展

在 SZY 206 基础上扩展：

```text
0x35   历史数据回传
0x60   多中心站切换
0x61   多中心站切换应答
```

## 报文解析步骤

```text
1. 收到 STX（0x02）→ 启动
3. 读 LEN（1 字节）
5. 读 LEN - 1 个字节
7. 解析中心站地址、测站地址、FC
9. 读数据段（FC 决定格式）
11. 读 CRC16
13. 读 ETX（0x03）
15. 验证 CRC16
```

## 水质要素详解

SL/T 427 完整水质要素：

```text
pH：6.0-9.0（生活饮用水）
电导率：0-5000 μS/cm
浊度：0-100 NTU
溶解氧：0-15 mg/L
氨氮：0-50 mg/L
COD：0-2000 mg/L
总磷：0-50 mg/L
总氮：0-100 mg/L
高锰酸盐指数：0-50 mg/L
BOD5：0-1000 mg/L
悬浮物：0-1000 mg/L
水温：0-50 °C
```

水质数据格式：

```text
每项：要素编码 + 测量类型 + 数值
```

工程实践：

```text
水质监测仪：
  多参数水质探头
  RS485 / Modbus RTU 输出
  RTU 通过 Modbus 读取 → SL/T 427 上报
```

```text
灌区用水：综合用水量
灌区渠首流量：进水流量
灌区渠尾流量：出水流量
灌区水位：渠系水位
灌区水闸开度：开度百分比
灌区土壤含水率：0-100%
```

灌区数据格式：

```text
每项：要素编码 + 测量类型 + 数值
```

## 取水许可要素

```text
年许可取水量：年度许可
季度累计取水量：本季度累计
月累计取水量：本月累计
日累计取水量：本日累计
```

许可判断：

```text
1. 测站实时上报累计取水量
3. 中心站对比日 / 月 / 年许可
5. 超阈值 → 告警 + 控制
7. 超许可 → 阀门关断（自动）
```

工程实现：

```text
1. 配置许可阈值
3. 实时上报累计取水量
5. 中心站计算：累计 / 许可
7. 超 80% 告警
9. 超 100% 控制
11. 超 110% 自动关阀
```

## 历史数据回传（FC=0x35）

```text
中心站发送请求：
  起始时间 + 结束时间 + 数据要素
测站分批上传：
  FC=0x35 + 时间段 + 数据
```

工程实现：

```text
1. 测站本地存储历史数据（Flash / SD）
3. 中心站发送请求
5. 测站读取本地数据
7. 分批打包（每批 < 1500 字节）
9. 上传
11. CRC 验证
```

数据压缩：

```text
gzip / LZ4 压缩历史数据
适合长时段回传
```

## 多中心站切换（FC=0x60 / 0x61）

```text
测站配置多中心站：
  主中心站（省级）
  备用中心站（地市级）

主中心站失效：
  心跳失败 ≥ 3 次
  TCP 断开
  切换备用
```

工程实现：

```text
测站状态机：
  STATE_CONNECT_PRIMARY
  STATE_CONNECT_SECONDARY
  STATE_CONNECTING_BACKUP

切换流程：
  1. 主中心站心跳失败
  3. 测站尝试重连 3 次
  5. 失败 → 切备中心站
  7. 发 F2 链路建立
  9. 发 FC=0x60 切换请求
  11. 等 FC=0x61 确认
  13. 进入业务
```

## 加密信道

加密扩展：

DES / 3DES / AES-128 / AES-256
密钥：每台设备独立
密钥协商：连接建立时

工程实现：

```text
1. 连接建立时密钥协商
3. 加密 FC=0x51（DES）/ 0x52（AES）
7. 数据段加密
9. CRC 验证
11. 业务交互
```

## GSM 短信备份

短信编码：

```text
短信内容 = SL/T 427 信息帧（去 STX/ETX）
PDU 7-bit 编码
中心站号：固定 SIM 卡号
```

工程实现：

```text
1. TCP 连接失败 → 切到短信
3. 短信内容 = SL/T 427 信息帧
5. PDU 编码
7. AT 指令发送
```

## 与 SZY 206 区别

| 维度 | SZY 206 | SL/T 427 |
| --- | --- | --- |
| 应用 | 基础水资源 | 水资源扩展 |
| 重点 | 取水流量 | 水质 + 灌区 + 取水许可细化 |
| 编码 | 基础要素 | 扩展要素（水质 / 灌区） |
| 中心站 | 单 / 双中心站 | 多中心站 |
| 加密 | 可选 | 部分省份强制 |
| 历史数据 | 简单 | 完整历史回传 |
| 设备类型 | 流量计为主 | 流量计 + 水质仪 + 阀门 |

## 现场常见故障

| 现象 | 优先检查 |
| --- | --- |
| TCP 连不上 | IP / 端口 / 4G 信号 |
| 链路建立失败 | 地址错 |
| 水质数据收不到 | 要素编码错 |
| 历史回传失败 | 时间 / 数据段 |
| 多中心站切换失败 | 备中心站配置 |
| 加密失败 | 密钥 / 算法 |
| 取水许可判断错 | 阈值 / 许可状态 |
| GSM 短信失败 | SIM 卡 / 信号 |

## 深度检查清单

- TCP 端口与省级一致。
- 测站地址 / 中心站地址 BCD 编码正确。
- 链路建立 F2 流程跑通。
- 链路维持 F1 心跳正常。
- 自报周期符合省级要求。
- 水质数据上报正常。
- 灌区数据上报正常（如需要）。
- 历史数据回传支持。
- 多中心站切换支持。
- 加密信道（如省级要求）。
- 设备状态上报支持。
- 取水许可精细化。
- CRC 计算正确。
- 要素编码正确。
- BCD 编码正确。
- VPN / 专网配置。
