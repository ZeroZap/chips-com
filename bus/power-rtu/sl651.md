# SL 651-2014

## 定位

SL 651-2014 是水利部行业标准《水文监测数据通信规约》，用于水文站 / 雨量站 / 水位站 / 流量站等测站与中心站之间的通信。

```text
SL 651-2014：当前主流
SL 651-1998：第一版（部分老测站）
```

## 应用场景

```text
河道 / 水库 / 堤防：水位、流量、流速
雨水情：雨量、土壤含水率
水电站：水位、流量、闸位
城市水文：内涝监测
```

## 协议分层

```text
物理层：4G / 北斗 / 光纤 / 短信
链路层：TCP（主）/ UDP / 短信（GSM 备份）
应用层：信息帧
```

## 网络结构

```text
中心站（server，多个）
    ↕
测站（client，多个）→ 中心站
```

每个测站：

- 一个测站对应一个中心站（默认）
- 多中心站需要测支持多 TCP 长连接

## 协议版本

- SL 651-2014（最新）
- 部分省份扩展版本（湖南、广东等）
- 部分省份要求接入省级水文中心测试才能落地

## 帧结构（两类）

### 链路帧（链路管理）

```text
帧首 + 中心站地址 + 测站地址 + 链路标识 + 校验 + 帧尾
```

帧首标识：

```text
F1：链路维持帧
F2：链路建立帧
F3：链路释放帧
F4：链路测试帧
```

链路标识：

```text
0x10：链路建立确认
0x11：链路维持
0x12：链路释放
0x13：测试应答
```

### 信息帧（业务数据）

```text
STX + LEN + 中心站地址 + 测站地址 + 功能码 + 数据段 + CRC16 + ETX
```

```text
STX = 0x02
LEN = 1 字节（含中心站地址起，到 ETX 前）
中心站地址 = 1-2 字节 BCD
测站地址 = 1-2 字节 BCD
功能码 = 1 字节
数据段 = 可变
CRC16 = 2 字节（从 STX 后第一个字节到 CRC 前）
ETX = 0x03
```

## 功能码（FC）

| FC | 含义 | 方向 |
| --- | --- | --- |
| 0x30 | 自报小时数据 | 测站→中心 |
| 0x31 | 自报分钟数据 | 测站→中心 |
| 0x32 | 加报（实时加报） | 测站→中心 |
| 0x33 | 控制命令（召测） | 中心→测站 |
| 0x34 | 召测应答 | 测站→中心 |
| 0x35 | 控制应答 | 测站→中心 |
| 0x36 | 设置参数 | 中心→测站 |
| 0x37 | 设置参数应答 | 测站→中心 |
| 0x38 | 时间校准 | 中心→测站 |
| 0x39 | 时间校准应答 | 测站→中心 |
| 0x3A | 控制命令（开关闸等） | 中心→测站 |
| 0x3B | 控制应答 | 测站→中心 |
| 0x40 | 状态查询 | 中心→测站 |
| 0x41 | 状态查询应答 | 测站→中心 |
| 0x50 | 应急广播 | 中心→测站 |

## 报文示例

### 链路建立

测站 → 中心：

```text
F2 + 中心站地址 + 测站地址 + 0x10 + CRC + 帧尾
```

中心 → 测站确认：

```text
F2 + 中心站地址 + 测站地址 + 0x10 + CRC + 帧尾
```

### 自报小时数据（FC=0x30）

```text
STX + LEN + 中心站地址 + 测站地址 + 0x30 + 数据 + CRC + ETX
```

数据段：

```text
YYMMDDHHmm  时间
雨量0XX.x  雨量
水位0XX.xxx  水位
流量0XX.xxx  流量
```

例：

```text
STX 24 01 02 30
   2409181015  时间
   0005.0  雨量 5.0 mm
   0023.45  水位 23.45 m
   0050.32  流量 50.32 m³/s
CRC 16-bit
ETX
```

### 召测（FC=0x33）

中心 → 测站：

```text
STX + LEN + 中心站地址 + 测站地址 + 0x33 + 数据 + CRC + ETX
```

数据段：

```text
要素类型 0x01   召测所有实时要素
```

测站应答（FC=0x34）：

```text
STX + LEN + 中心站地址 + 测站地址 + 0x34 + 数据 + CRC + ETX
```

### 时间校准（FC=0x38）

```text
STX + LEN + 中心站地址 + 测站地址 + 0x38 + 时间 + CRC + ETX
```

时间格式：YYMMDDHHmmss（6 字节 BCD）。

## 水文要素编码

SL 651-2014 用 4 字节编码标识水文要素：

```text
0x00 雨量
0x10 水位
0x20 流量
0x30 流速
0x40 含沙量
0x50 闸位
0x60 蒸发量
0x70 水温
0x80 气温
0x90 湿度
0xA0 风力
0xB0 风向
0xC0 电源电压
0xD0 设备状态
```

每个要素测量精度编码：

```text
0x01 瞬时值
0x02 累计值
0x03 平均值
0x04 最大值
0x05 最小值
```

## 数据格式

水文要素数据编码：

```text
数值 = 数字 + 单位小数位 + 单位

例：水位 23.45 m
编码 5 位：02345 + 0x03（1 位小数）

具体：
  雨量 0x00 + 0x01：瞬时雨量 4 字节 BCD，单位 0.1 mm
  水位 0x10 + 0x01：瞬时水位 4 字节 BCD，单位 0.01 m
  流量 0x20 + 0x01：瞬时流量 5 字节 BCD，单位 0.01 m³/s
```

工程实践：

- 与中心站确认要素编码字典。
- 不同水文要素精度不同。
- 数据格式 BCD 编码。

## 通信流程

### 链路建立

```text
1. 测站主动连接中心站 TCP
3. 测站发 F2 链路建立
5. 中心站回 F2 链路建立确认
9. 进入业务交互
```

### 链路维持

```text
测站每 1-5 分钟发 F1 链路维持帧
中心站回 F1 链路维持确认
```

### 链路释放

```text
中心站发 F3 链路释放
测站发 F3 链路释放确认
```

### 业务交互

```text
定时自报（每 1 / 5 / 30 分钟 / 1 小时）
召测应答
控制命令应答
时间校准
设置参数
```

## 自报策略

```text
定时自报（FC=0x30 / 0x31）：
  每 1 / 5 / 30 分钟 / 1 小时上报一次
  要素固定

加报（FC=0x32）：
  雨量加报：降雨累计量达到阈值
  水位加报：水位超警 / 变幅超阈值
  流量加报：流量超警
```

## 加报触发

工程常见加报阈值：

```text
雨量：累计雨量超过 5 mm（可配置）
水位：水位变幅超过 0.05 m / 5 min
流量：流量变幅超过 10%
闸位：闸位变化超 5 cm
```

## 控制命令（FC=0x3A）

中心可下发控制命令：

```text
闸门升降
阀门开关
泵启停
设备维护状态切换
```

控制应答（FC=0x3B）：

```text
测站收到 → 应答 + 执行结果
```

## GSM 短信备份

SL 651 支持 GSM 短信作为备用信道：

```text
主信道：TCP 失败 → 短信备用信道
短信内容：SL 651 信息帧
编码：PDU + 7-bit
```

工程实现：

- 短信发送失败 → 重发 3 次。
- 短信中心号预配置。
- 测站 SIM 卡开通短信功能。

## 多信道策略

```text
1. 主信道（TCP）：优先
3. 备用信道 1（GSM 短信）：TCP 不可用
5. 备用信道 2（北斗短报文）：无运营商信号
7. 备用信道 3（卫星 IoT）：偏远地区
```

## 链路密码（可选）

部分省份要求链路加密：

```text
链路密码：测站 + 中心预共享
内容加密：DES / AES
```

## 适用场景

- 河道 / 水库水位监测。
- 雨量站。
- 地下水监测。
- 水电站上游监测。
- 城市内涝监测。
- 灌区监测。
- 取水口监测（与 SZY206 配套）。

## 检查清单

- TCP 长连接已建立。
- 链路建立 F2 流程跑通。
- 链路维持 F1 心跳正常。
- 自报周期符合省级要求。
- 召测应答能正常返回。
- 控制命令能正确应答。
- 时间校准能正常执行。
- 设置参数能生效。
- 加报阈值合理。
- 多信道备份（GSM / 北斗）。
- 短信备份信道正常。
- 链路密码（如省级要求）。
