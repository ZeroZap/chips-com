# IEC 61850

## 定位

IEC 61850 是变电站自动化国际标准，用于变电站内部 IED（Intelligent Electronic Device）之间、IED 与 SCADA 系统之间的通信。

```text
IEC 61850-1: 总览
IEC 61850-2: 术语
IEC 61850-3: 一般要求
IEC 61850-4: 系统项目管理
IEC 61850-5: 通信要求
IEC 61850-6: SCL 配置语言
IEC 61850-7: 基础信息和结构（ACSI）
IEC 61850-8: MMS 映射
IEC 61850-9: SV 采样值
IEC 61850-10: 一致性测试
```

## 应用领域

- 数字化变电站。
- 智能变电站。
- 配电站自动化。
- 新能源场站（风电、光伏、储能）监控。

## 协议分层

```text
物理层：以太网（100BASE-TX / 光纤）
链路层：以太网 MAC
网络层：IPv4 / IPv6
传输层：TCP（MMS）/ UDP（无）/ 直接映射（GOOSE / SV）
应用层：MMS / GOOSE / SV
```

## 通信模型

### MMS（Client/Server）

```text
TCP 端口 102
Client（SCADA / RTU）→ Server（IED）
MMS 服务：GetNameList / Read / Write / InformationReport / Initiate / ...
```

### GOOSE（Publisher/Subscriber）

```text
多播 MAC：01-0C-CD-01-xx-xx
Publisher（保护 IED）→ Subscriber（保护 IED）
基于 IEC 61850-8-1（GOOSE）
```

### SV（Sampled Values）

```text
多播 MAC：01-0C-CD-02-xx-xx / 04-xx-xx
Publisher（合并单元 MU）→ Subscriber（保护 IED）
基于 IEC 61850-9-2
```

## 建模层次

```text
物理设备（PD = Physical Device）
  └─ 逻辑设备（LD = Logical Device）
      └─ 逻辑节点（LN = Logical Node）
          └─ 数据对象（DO = Data Object）
              └─ 数据属性（DA = Data Attribute）
```

实际引用路径：

```text
LD0/CILO1.EnaOpn.stVal
逻辑设备 LD0 / 逻辑节点 CILO1 / 数据对象 EnaOpn / 数据属性 stVal
```

## 逻辑节点（LN）类

IEC 61850-7-4 定义标准 LN 类：

### 公共 LN（域 L）

```text
LPHD  物理设备信息
LLN0  逻辑节点零（每个 LD 必有）
```

### 保护 LN（域 P）

```text
PIOC  瞬时过流保护
PDIF  差动保护
PTOC  定时限过流
PVOC  电压过流
PZSU  零序电压
PDPR  方向功率
PHIZ  高阻抗差动
```

### 控制 LN（域 C）

```text
CSWI  开关控制器
CILO  联锁
```

### 测量 LN（域 M）

```text
MMXU  三相测量
MSQI  序分量
MHAI  谐波
```

### 互感器 LN（域 T）

```text
TCTR  电流互感器
TVTR  电压互感器
```

### 开关设备 LN（域 X）

```text
XCBR  断路器
XSWI  隔离开关
```

### 状态 LN（域 S）

```text
SPS   单点状态
DPS   双点状态
ENS   枚举状态
INS   整数状态
```

### 自动 LN（域 A）

```text
ANCR  模拟控制
ARCO  弧光控制
```

## 数据对象（DO）举例

每个 LN 有多个 DO。常用 DO：

```text
Mod    模式（On / Blocked / Test）
Beh    行为
Health 健康（OK / Warning / Alarm）
Loc    就地 / 远方
OpOpn  开放操作
OpCls  闭合操作
EnaOpn 允许开放
EnaCls 允许闭合
Pos    位置（断路器分 / 合 / 中间）
Trip   跳闸
Alm    报警
```

## ACSI 服务

IEC 61850-7-2 定义 ACSI（Abstract Communication Service Interface）：

```text
DataAccess 服务：
  GetDataValues
  SetDataValues
  GetDataDefinition
  GetDataDirectory

DataSet 服务：
  CreateDataSet
  DeleteDataSet
  GetDataSetValues

ReportControl：
  Buffered Report（Buffered Report Control Block, BRCB）
  Unbuffered Report（Unbuffered Report Control Block, URCB）

Control（命令）：
  Select / SelectWithValue
  Cancel
  Operate
  CommandTermination

GOOSE Control：
  GetGoCBValues
  SetGoCBValues
  SendGOOSEMessage

SV Control：
  GetSvCBValues
  SetSvCBValues

File Transfer：
  GetFile
  SetFile
  DeleteFile
  RenameFile

TimeSync：
  UTC time sync
```

## 报告（Report）机制

```text
数据集（DataSet）：
  LN.DO.LN.DO... 多数据点集合

报告控制块：
  BRCB（Buffered）：报告 + 缓冲
  URCB（Unbuffered）：报告 + 不缓冲

触发选项：
  Data Change（dchg）
  Quality Change（qchg）
  Data Update（dupd）
  Integrity Period（integrity）
  General Interrogation（GI）
```

工程实践：

```text
1. 订阅 IED 数据集
3. 配置 BRCB / URCB
5. 启动报告
7. 接收 InformationReport 报文
```

## MMS 映射

MMS（ISO 9506）承载 ACSI：

```text
对象：Domain / Named Variable / Named Variable List
服务：Read / Write / InformationReport / Initiate / GetNameList / ...

报文：BER 编码
TCP 端口 102
```

MMS PDU 类型：

```text
Initiate Request
Initiate Response
GetNameList Request
GetNameList Response
Read Request
Read Response
Write Request
Write Response
InformationReport Request
...
```

## GOOSE 协议

GOOSE 用于保护跳闸和告警传输：

```text
gMMS PDU = GOOSE PDU

字段：
  goCBRef       报告控制块引用
  datSet        数据集引用
  goID          GOOSE ID
  t             时间戳
  stNum         状态序号
  sqNum         序列号
  test          测试标志
  confRev       配置版本
  ndsCom        需要重传
  numDatSetEntries 数据集条目数
  data          数据
```

GOOSE 帧格式：

```text
以太网帧：
  多播 MAC 01-0C-CD-01-xx-xx
  Ethertype 0x88B8
  APPID
  Length
  Reserved
  APDU（gMMS 头 + 数据）
```

传输机制：

```text
变位时立即发送（突发）
之后周期性重发（4ms, 8ms, 16ms, 32ms, ... 退避）
直到接收确认
```

## SV 协议

SV（IEC 61850-9-2）用于合并单元传输采样值：

```text
svMMS PDU = SV PDU

字段：
  svCBRef       控制块引用
  smvID         SV ID
  smpCnt        采样计数
  confRev       配置版本
  smpSynch      同步状态
  smpRate       采样率
  ...
  ASDU（采样值 + 状态）
```

SV 帧：

```text
多播 MAC 01-0C-CD-04-xx-xx
Ethertype 0x88BA
APPID
...
```

采样率：

```text
IEC 61850-9-2 LE：4.8 kHz（保护）/ 14.4 kHz（电能质量）
IEC 61850-9-2：4 kHz（标准保护）/ ...
```

## SCL 配置

SCL（Substation Configuration Language）是 XML 配置：

```text
ICD（IED Capability Description）：
  IED 能力描述（厂家提供）

CID（Configured IED Description）：
  实例化 + 已配置 IED（系统集成商提供）

SCD（Substation Configuration Description）：
  整个变电站配置

SSD（System Specification Description）：
  系统规范

IID（Instantiated IED Description）：
  实例化 IED 描述
```

SCL XML 结构：

```xml
<SCL xmlns="http://www.iec.ch/61850/2003/SCL">
  <IED name="IED1">
    <AccessPoint name="AP1">
      <Server>
        <LDevice inst="LD1">
          <LNode inst="1" lnClass="XCBR"/>
          ...
        </LDevice>
      </Server>
    </AccessPoint>
  </IED>
  <DataTypeTemplates>
    <LNodeType id="LTC_1" lnClass="XCBR">
      <DO name="Pos" type="DPC"/>
      ...
    </LNodeType>
  </DataTypeTemplates>
  <Substation name="Sub1">
    <VoltageLevel name="VL1">
      <Bay name="Bay1">
        <ConductingEquipment name="Breaker1" type="CBR"/>
      </Bay>
    </VoltageLevel>
  </Substation>
</SCL>
```

## 时间同步

IEC 61850 时间同步：

```text
方式 1：IEEE 1588 PTP（精确时间协议）
方式 2：NTP（简单网络时间协议）
方式 3：IEC 61850-9-3 电力时间同步（基于 1PPS）
```

SV 采样同步：

```text
基于 IEEE 1588 PTP 同步
采样精度：1 μs
```

## 一致性测试

IEC 61850-10 定义一致性测试：

```text
PICS（Protocol Implementation Conformance Statement）
PIXIT（Protocol Implementation Extra Information for Testing）
测试工具：KEMA（DNV）、IEDEMER
```

## MMS 协议栈

```text
应用层：MMS（BER 编码）
表示层：ASN.1 BER
会话层：MMS Session
传输层：TCP（端口 102）
```

## Client（SCADA / RTU）实现要点

```text
1. MMS Initiate 服务（连接建立）
3. GetNameList（获取 IED 命名空间）
5. Read（读数据对象）
7. Write（写配置）
9. InformationReport（订阅报告）
11. Select / Operate（命令）
13. GetFile / SetFile（文件传输）
15. 报告控制块配置
17. GOOSE 监听（如需）
19. SV 订阅（如需）
```

## Server（IED / RTU）实现要点

```text
1. ICD 文件解析（生成 LD/LN/DO 树）
3. CID 文件解析（生成实例化对象）
5. MMS 服务实现（Read/Write/Report）
7. 数据采集 → 上报
9. 命令处理（Select/Operate）
11. GOOSE 发布（如保护 IED）
13. SV 发布（如合并单元）
15. 时间同步（IEEE 1588）
```
