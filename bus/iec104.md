# IEC 60870-5-104

## 定位

IEC 60870-5-104（简称 IEC 104）是把 IEC 60870-5-101 的应用层（ASDU）移植到 TCP 上的协议，用于电力系统调度主站和远动终端（RTU）之间的通信。

```text
IEC 101 = 串行（RS485/RS232）远动，FT1.2 帧
IEC 104 = 101 的 TCP 版本，端口 2404
```

应用层 101 和 104 共用同一套 ASDU，区别只在传输层。104 是国内电力 RTU 项目立项标配。

## 数据模型

IEC 60870-5 用 ASDU（Application Service Data Unit）描述数据：

| ASDU 类型号 | 含义 | 方向 | 时序 |
| --- | --- | --- | --- |
| 1 (M_SP_NA_1) | 单点信息 | M_ | 不带 |
| 2 (M_SP_TB_1) | 单点信息 | M_ | CP24 |
| 3 (M_DP_NA_1) | 双点信息 | M_ | 不带 |
| 4 (M_DP_TB_1) | 双点信息 | M_ | CP24 |
| 5 (M_ST_NA_1) | 步位置信息 | M_ | 不带 |
| 9 (M_ME_NA_1) | 归一化测量值 | M_ | 不带 |
| 11 (M_ME_NB_1) | 标度化测量值 | M_ | 不带 |
| 13 (M_ME_NC_1) | 短浮点测量值 | M_ | 不带 |
| 15 (M_IT_NA_1) | 累积量 | M_ | 不带 |
| 20 (M_PS_NA_1) | 带变位标志的成组单点 | M_ | 不带 |
| 30 (M_SP_TB_2) | 单点带 CP56 时序 | M_ | CP56 |
| 31 (M_DP_TB_2) | 双点带 CP56 时序 | M_ | CP56 |

## 帧结构（APCI + ASDU）

```text
68 Length [Control4] [TypeId1] [VSQ1] [COT2] [Addr2] [ASDU body]
```

- 启动字符：`0x68`。
- 长度：APDU 剩余字节数（4 字节控制域 + ASDU 长度，不含启动字符、不含长度字段本身）。
- 控制域：4 字节，区分 I / S / U 三种格式。
- ASDU：类型标识、VSQ（可变结构限定词）、COT（传输原因）、公共地址 + ASDU 信息体。

## 三种 APDU 格式

```text
I 格式（信息传输）：
  发送序列号 N(S) + 接收序列号 N(R)，各 2 字节低字节在前。

S 格式（监视确认）：
  仅接收序列号 N(R)，2 字节低字节在前。

U 格式（启动 / 停止 / 测试）：
  4 字节定义：STARTDT / STOPDT / TESTFR，子功能 0/1（激活/确认）。
```

U 格式控制域字节（常见值）：

```text
0x07 00 00 00    STARTDT_ACT
0x0B 00 00 00    STARTDT_CON
0x13 00 00 00    STOPDT_ACT
0x23 00 00 00    STOPDT_CON
0x43 00 00 00    TESTFR_ACT
0x83 00 00 00    TESTFR_CON
```

## 通信流程

典型建立 + 第一次总召唤：

```text
1. 主站：U STARTDT_ACT
2. 从站：U STARTDT_CON
3. 主站：I 含 C_IC_NA_1 总召唤命令（激活，QOI=1）
4. 从站：I 含 C_IC_NA_1 激活确认
5. 从站：I 含各测量 ASDU（总召唤响应，QOI=1）
6. 从站：I 含 C_IC_NA_1 激活结束
8. 周期性时钟同步：C_CS_NA_1（CP56 时间）
```

后续事件触发按需上传（变位 / 阈值越限）。

## 关键参数

| 参数 | 含义 | 典型值 |
| --- | --- | --- |
| k | 最大未确认 I 帧数 | 12 |
| w | 最新接收确认序号 | 8 |
| t0 | 建立连接超时 | 10 s |
| t1 | 发送 I 帧超时 | 15 s |
| t2 | 接收确认超时（强制 S 帧） | 10 s |
| t3 | 空闲测试间隔 | 20 s |
| 公共地址 | 站址（ASDU 内） | 1..65535 |

## 命令选择 / 执行 / 撤销

下行命令带两个步骤：

```text
Select (激活)：C_xx_y_1 SE = 1
Execute (执行)：C_xx_y_1 SE = 0
Cancel (撤销)：可选
```

COT（传输原因）字段编码命令状态：

```text
激活（6）、激活确认（7）、停止激活（8）、停止激活确认（9）
```

## 时间格式

```text
CP24Time2a（4 字节）：秒 + 分 + 时 + 日（8 bit）
CP56Time2a（7 字节）：毫秒（16 bit）+ 分（8 bit）+ 时（8 bit）+ 日（8 bit）+ 星期-月（8 bit）+ 年（8 bit）
```

CP56 最高两位之一表示无效/替代/夏令时。

## 适用场景

- 国内变电站 RTU 上行。
- 配电自动化终端。
- 风电 / 光伏场站监控。
- 储能 EMS 上行。
- 工业能源管理。
