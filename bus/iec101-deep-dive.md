# IEC 60870-5-101 Deep Dive

## 目标

本文深入 IEC 101 协议栈细节，重点解决 FT1.2 帧解析、控制域编码、平衡 / 非平衡传输状态机、FCB 翻转、ASDU 映射、CP56 时间、双点命令、突发上传策略和现场排障。

## 协议栈分层

```text
物理层：RS485 / RS232 / 光纤串口
链路层：FT1.2 帧
应用层：ASDU（与 IEC 104 共用）
```

101 是 104 的串行版本，应用层 100% 复用。区别在链路层：

```text
FT1.2 帧（固定 / 可变长度）
控制域 1 字节（104 是 4 字节）
校验字节 CS（104 无）
FCB/FCV 翻转（104 用 N(S)/N(R) 序号）
```

## FT1.2 帧格式细节

固定长度帧 11 字节（含启动字符和结束字符）：

```text
[10] [01] [C] [A] [00] [CS] [16]
```

可变长度帧：

```text
[68] [L] [L] [68] [C] [A] [ASDU] [CS] [16]
```

注意可变长度帧有两个 0x68 启动字符夹着长度字段。这是为了快速定位：

```text
1. 收 0x68 → 启动
2. 读 L
3. 等下一个 0x68 → 验证
4. 读 C 和 A
5. 读 ASDU
6. 读 CS
7. 读 0x16
```

帧定界错误处理：

```text
收到 0x10 但不是期望帧 → 检查是不是固定长度帧
收到 0x68 后长度异常 → 丢弃
连续 0x16 之前没收到完整帧 → 校验错
```

## 控制域字节编码

控制域 1 字节 8 bit：

```text
bit 7：DIR（1 = 从站→主站，0 = 主站→从站）
bit 6：PRM（启动位）
bit 5：FCB（帧计数位）
bit 4：FCV（帧计数有效）
bit 3..0：功能码
```

主站启动帧（PRM=1）：

```text
DIR=0, PRM=1, FCV, FCB, FC[3:0]
bit 7 = 0
bit 6 = 1
bit 5 = FCB
bit 4 = FCV
bit 3..0 = FC

控制域 = 0x40 + (FCB<<5) + (FCV<<4) + FC
```

从站响应帧（PRM=0）：

```text
DIR=1, PRM=0
bit 7 = 1
bit 6 = 0
bit 5 = DFC（数据流控制）
bit 4 = ACD（访问要求）
bit 3..0 = FC

控制域 = 0x80 + (DFC<<5) + (ACD<<4) + FC
```

DFC = 1：表示从站暂时无法接收新数据
ACD = 1：表示从站有 1 级用户数据待上传

## FCB / FCV 翻转机制

非平衡模式下：

```text
主站对同一从站：
  复位远方链路后，FCV=1, FCB=0
  第 1 次数据请求 FCV=1, FCB=0
  收到从站响应后：FCB = !FCB
  第 2 次：FCV=1, FCB=1
  ...
```

从站响应必须复制主站请求的 FCB。

工程实现：

```text
主站维护一个 FCB 状态机（每个从站独立）
从站收到 FCV=0（如复位命令）时重置 FCB
```

## 平衡模式状态机

平衡模式（IEC 101:2003 平衡模式变体）：

```text
双方都可起传输，但同一时刻只有一方在发
1. 一方请求链路状态
2. 另一方响应链路状态
3. 一方发起数据
4. 另一方响应
```

平衡模式应用较少，主要在厂站 RTU 高实时场景。

## ASDU 字段详解

与 IEC 104 共享，但 IOA 在 101 中常为 2 字节：

```text
类型标识：1 字节
VSQ：1 字节（SQ 位 + 数量）
COT：2 字节（101 早期可能 1 字节）
公共地址：1 字节（101 早期）/ 2 字节（扩展）
IOA：2 字节（早期）/ 3 字节（扩展）
```

**注意：实际工程中很多 RTU 用 3 字节 IOA（101/104 兼容）**。

工程实践：与主站确认 IOA 字节数。

## CP56Time2a（与 104 共用）

7 字节结构（同 104 详述）：

```text
[0]：毫秒低 8 位
[1]：毫秒高 8 位 + IV + 夏令时
[2]：分钟
[3]：小时
[4]：日
[5]：星期 + 月
[6]：年（相对 2000）
```

工程实现：

```text
101/104 RTU 应在时钟同步后更新本地 RTC
CP56 编解码与 104 一致
```

## 平衡 / 非平衡模式差异

非平衡（UNB）：

```text
主站主导：
  1. 主站发请求
  2. 从站响应
  3. 单向通信
```

平衡（BAL）：

```text
双向可发起：
  1. 任一方发请求
  3. 另一方响应
  4. 通常先建立链路
```

工程选择：

- 国内配电 RTU → 非平衡
- 海外厂站 → 平衡

## ASDU 通用分类（GI）

101/104 共用 GI 扩展机制（ASDU 240-249）。

GI 用于自定义数据扩展，是 RTU 配网场景的关键扩展。

## 双点命令选择 / 执行 / 撤销

```text
第 1 阶段：SE=1（选择），双点命令内容（分=01 或 10）
从站返回激活确认（COT=7，SE=1）

第 2 阶段：SE=0（执行），双点命令内容
从站返回激活确认（COT=7，SE=0）
从站完成后返回变位响应 M_DP_NA_1

撤销：SE=1 + 命令码 = 撤销
从站返回停止激活（COT=8/9）
```

工程注意：

- 选择阶段不动作，避免误操作。
- 执行阶段带最终校验。
- 撤销用于主站主动取消。

## 突发上传

101 突发上传与 104 相同：

```text
1. 变位 → M_SP_TB_1 / M_DP_TB_1
3. 越限 → M_ME_NC_1 + 突发标志
4. 累积量增量 → M_IT_NA_1
```

101 受限：串行链路慢，突发时易阻塞。

```text
策略：
  1. 排队，按 FCB 翻转依次发送
  2. 缓存溢出时丢弃老事件
  3. 主站优先级高于突发（k 限速）
```

## 抓包排障

串口转 TCP 后用 Wireshark 解析（dissector 有限）：

```text
1. 物理层：A/B 信号、波特率、校验
2. 帧定界：10 01 / 68 启动字符
4. 控制域：DIR/PRM/FCB/FCV
5. ASDU：Type/VSQ/COT/IOA
6. CS 校验值
```

工程排障清单：

```text
1. 帧定界错：检查启动字符识别逻辑
3. CS 错：检查校验和计算
4. 控制域错：检查 DIR/PRM 掩码
5. ASDU 错：检查类型映射
6. FCB 不同步：检查状态机
```

## 现场常见故障

| 现象 | 优先检查 |
| --- | --- |
| 完全无帧 | A/B、波特率、校验、地址 |
| 帧定界错 | 启动字符识别、CS 校验 |
| 控制域解析错 | DIR/PRM 位掩码 |
| 总召唤响应不全 | ASDU 映射、IOA 偏移 |
| 命令执行无确认 | SE 选择 → 执行 |
| FCB 不同步 | 状态机初始化 / 复位 |
| 突发数据堆积 | 缓存策略 |
| 间歇中断 | 1. 终端电阻；2. RS485 干扰；3. 偶校验 |

## 深度检查清单

- 串口参数与主站一致。
- FT1.2 帧两种格式（固定 / 可变）解析正确。
- 控制域 DIR/PRM/FCB/FCV/DFC/ACD 解析完整。
- FCB 状态机正确（主站 / 从站独立）。
- 平衡 / 非平衡模式按应用选择。
- ASDU 类型 / VSQ / COT / IOA 解析完整。
- 公共地址与 IOA 字节数与主站对齐。
- CS 校验正确。
- CP56Time2a 编解码正确。
- 双点命令选择 → 执行 → 撤销流程完整。
- 突发上传策略合理（缓存 + 优先级）。
- 时钟同步流程跑通。
- 总召唤 / 累积量召唤流程跑通。
- 复位链路 / 复位进程命令支持。
- RS485 半双工 DE 等待 TC。
- 隔离 / 终端电阻 / 偏置电阻符合工业要求。
- 长帧最大长度（255 字节）和 RTU 实际响应长度匹配。
