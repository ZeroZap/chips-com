# HJ 212-2017 Practical Guide

## 目标

本文用于把 HJ 212 工程链路调通：TCP 接入、数据帧解析、心跳、实时 / 分钟数据上传、命令应答和省级平台对接。

## TCP 接入

HJ 212 是 TCP 长连接协议。

```text
现场 RTU → TCP:port → 省级 / 地市级环保平台
```

常见端口：
- 8000（部分省份）
- 5000（部分省份）
- 9501（特定省份）

工程注意：

- 不同省份端口不同，部署前必须确认。
- 中心站是 server，RTU 是 client。
- 长连接 + 心跳保活。

## 帧格式速记

```text
##QN=YYYYMMDDhhmmsszzz;ST=22;CN=2011;PW=123456;MN=ABC1234567890;Flag=5;CP=&&
数据段
&&\r\n
```

字段：

```text
QN  ：请求编号（YYYYMMDDhhmmsszzz）
ST  ：系统编号（22 = 污染源）
CN  ：命令编号
PW  ：密码 6 位
MN  ：设备唯一编号 13 位
Flag：标志位
CP=&&：数据起始
&&：数据结束
\r\n：结束符
```

## 报文示例

### 心跳包（CN=1000）

```text
##QN=20260928153045123;ST=22;CN=1000;PW=123456;MN=ABC1234567890;Flag=0;CP=&&
&&\r\n
```

### 实时数据（CN=2011）

```text
##QN=20260928153045200;ST=22;CN=2011;PW=123456;MN=ABC1234567890;Flag=0;CP=&&
a21026-Rtd=123.45,a21026-Flag=N;
a21002-Rtd=15.32,a21002-Flag=N;
a21011-Rtd=56.78,a21011-Flag=N;
&&\r\n
```

### 分钟数据（CN=2021）

```text
##QN=20260928153100000;ST=22;CN=2021;PW=123456;MN=ABC1234567890;Flag=0;CP=&&
a21026-Rtd=124.5,a21026-Flag=N,a21026-Avg=124.0,a21026-Max=126.0,a21026-Min=122.0;
&&\r\n
```

### 命令应答（CN=3031）

```text
##QN=20260928153110500;ST=22;CN=3031;PW=123456;MN=ABC1234567890;Flag=0;CP=&&
&&\r\n
```

## 数据帧解析步骤

```text
1. 收到 ## 标识开始
3. 解析 ; 分隔的字段（key=value）
5. 读 CP=&& 标记数据段开始
7. 解析数据段（; 分隔每条因子）
9. 读 && 数据段结束
11. 读 \r\n 报文结束
```

工程实现：

```text
parser 状态机：
  IDLE → HEADER → DATA → END
每段匹配对应结束符（##、CP=&&、&&\r\n）
```

## 字段编码

数据段每个因子格式：

```text
<因子>-Rtd=<实时值>,<因子>-Flag=<状态>;
```

`<因子>` 是 HJ 212 因子字典（如 a21026 流量）。

`<状态>`：

```text
N  正常
B  异常
F  超标
M  维护
T  停运
C  校准
K  超上限
L  超下限
V  离线数据
D  故障
```

## 心跳处理

```text
现场→中心：CN=1000 每 1-3 分钟
中心→现场：CN=1001 应答

超时：3-5 分钟未收到 → 链路异常
重连：TCP 断开后立即重连
```

## 命令处理

中心 → 现场命令：

| CN | 命令 | 现场响应 |
| --- | --- | --- |
| 1001 | 心跳应答 | - |
| 2012 | 实时数据应答 | - |
| 3021 | 命令请求 | 3031 应答 + 执行 |
| 9011 | 设置参数请求 | 9031 应答 |

命令请求示例（设置校准时间）：

```text
##QN=20260928153110000;ST=22;CN=3021;PW=123456;MN=ABC1234567890;Flag=0;CP=&&
DataTime=202609281530;Pol-a:123456;&&\r\n
```

## 设置参数（CN=9011）

中心可设置：

```text
Pol-time  采样时间间隔
Pol-Interval  上传间隔
DataTime  时间校准
OverLimit  超标阈值
MN        设备编号
```

## CRC 校验

HJ 212-2017 规定部分场景使用 CRC 校验（Modbus CRC16 算法）：

```text
计算：除了首部 ## 和结束 && 之间的所有字节
附加：结果 4 字节十六进制大写，置于字段前面
```

但 HJ 212-2017 中 CRC 是非必填，需要对接的省级平台要求时再实现。

## 现场调试步骤

1. 确认 MN（设备编号）已注册到省级平台。
2. 确认 PW（密码）与省级一致。
3. TCP 长连接到省级平台（中心站端口）。
4. 发心跳包 CN=1000，确认收到 CN=1001 应答。
5. 发实时数据 CN=2011，确认收到 CN=2012 应答。
6. 发分钟数据 CN=2021（每小时 1 次）。
8. 测试命令请求 CN=3021 应答 CN=3031。

## 常见问题

| 现象 | 优先检查 |
| --- | --- |
| TCP 连接失败 | 端口、IP、防火墙、SIM 卡流量 |
| 收到应答但解析失败 | ## 和 &&\r\n 边界识别 |
| 心跳超时 | TCP 长连接保活、心跳周期 |
| 实时数据未入库 | 因子编码 / 数据状态 / Flag 字段 |
| 命令无应答 | QN 编号、CN 命令、密码权限 |
| MN 不匹配 | 设备注册、平台字典 |
| 超标漏报 | Flag-N=F 标记、超标阈值 |

## 实战检查清单

- TCP 端口已开（确认省级平台端口）。
- MN（13 位）已注册到省级平台。
- PW（6 位）密码与省级一致。
- 心跳周期符合省级要求。
- 心跳应答正常。
- 实时数据周期正常上传。
- 分钟数据周期正常上传。
- 命令请求能正确应答。
- 设置参数生效。
- 因子编码与省级平台字典一致。
- 数据状态 Flag-N 字段正确。
- 超标数据标识正确。
- TCP 长连接保活。
- 异常断开重连。
