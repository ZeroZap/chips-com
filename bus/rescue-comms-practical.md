# Rescue Communications 调试速查

## 目标

救援通讯终端的研发、产线、户外现场调试速查。覆盖卫星 SOS / 短报文 / PLB / 应急蜂窝 / 户外对讲五大路线，重点是链路建立、定位精度、电池续航、错误码。

## 最小接线（以 inReach Mini 2 嵌入式模组为例）

```text
Iridium 9603 模组
─────────────────
VDD (3.3V~5V) ──── 主电源（峰值 1.5 A 发射瞬间）
GND ──────────── 地
TX/RX ────────── MCU UART（9600/115200 bps，默认 AT 命令）
RI (Ring Indicator) ── 唤醒 MCU（消息到达中断）
ANT ──────────── 卫星天线（全向陶瓷 / 贴片）
SIM ──────────── Iridium SBD 卡（运营商提供）
```

**关键约束**：

- 卫星天线对天空仰角 > 60°（开阔场景）
- 模组与 MCU 共地，电平匹配（3.3V TTL）
- 电源瞬态电流大，必须用低 ESR（Equivalent Series Resistance，等效串联电阻）钽电容或陶瓷电容
- 天线馈线 < 50 mm，阻抗 50Ω
- 远离 Wi-Fi/BLE 天线（2.4 GHz 谐波干扰 L 频段）


## 调试步骤

1. **看天线方向**：卫星 App（如 `Satellite Tracker`、`星图`）确认当前仰角 > 30°
2. **看模组供电**：示波器看发射瞬间电压跌落（必须 < 0.3V）
3. **看入网时间**：冷启动 45 s 内完成注册，否则检查天线 / SIM
4. **看 SBD 收发**：发"位置 + 时间戳"到地面站，验证回环
5. **看 PLB 自检**：长按测试键 5 s，看 LED 闪灯编码（GPS 锁定 / 406 MHz 发射 / 121.5 MHz 发射）
6. **看电池**：低温 -20°C 测 24+ 小时发射
7. **看加密链路**：抓包验证端到端加密生效（无明文位置）

## 常见问题速查

| 现象 | 优先检查 |
| --- | --- |
| 模组入网慢（> 60 s） | 天线仰角 / 卫星覆盖边缘 / SIM 卡 |
| SBD 发送失败 | IMEI 未注册 / 信号弱（RSSI < 110 dBm） |
| 双向消息延迟 > 5 min | Iridium 拥塞 / 移动遮挡 / 入网丢失 |
| PLB 自检不过 | 电池过期 / GPS 锁定失败 / 406 MHz 频偏 |
| 北斗 RDSS 无位置 | 用户卡未激活 / 模组 S/N 未注册 |
| 卫星模组发射时 MCU 复位 | 电源瞬态电流不够 / 大电容失效 |
| iPhone 14 SOS 不显示 | 区域不支持 / 未开通 / 蜂窝有信号自动走蜂窝 |
| inReach 离线时位置缓存丢失 | 关闭了 GPS / 设备关机 |
| DSC 误触发 | 测试模式未关 / MMSI 重复 |
| 电池 1 年就掉电 | 自放电率超标 / 严寒环境 |
| 海岸边定位漂移 | 多径干扰 / 卫星几何分布差 |

## 5 秒钟定位

| 现象 | 一句话定位 | 首选动作 |
| --- | --- | --- |
| 卫星模组不入网 | 天线 / SIM / 区域 | 拿到户外空旷处，看 LED |
| 短报文发不出去 | 信号弱 / 注册失败 | AT 命令 `AT+CSQ` 看 RSSI |
| PLB 自检失败 | 电池 / GPS | 长按 5 s，看闪灯次数 |
| 北斗 RDSS 无定位 | 卡 / 模组 | 检查 SIM 卡槽 + S/N 注册 |
| iPhone SOS 不响应 | 区域不支持 | 查 Apple 区域覆盖地图 |
| inReach 双向消息延迟 | Iridium 拥塞 | 换时段 / 走短报文不追踪 |
| DSC 测试不响应 | MMSI 重复 | 检查设备库重复 |
| 电池快耗尽 | 严寒 / 自放电 | 查温度曲线 + 电池规格 |
| 卫星方位 App 显示 0 颗 | 区域覆盖空 | 走 PLB 兜底 |
| 卫星链路在飞机上断 | 高频段被屏蔽 | 走 ELT 406 MHz |

## inReach / Garmin 实战注意

- **inReach Mini 2 跟踪间隔 10 min**，电池 14 天；跟踪 1 min，电池 5 天
- **预设消息 vs 自由消息**：预设消息（"OK"、"需要救援"）走 Iridium 免费通道，自由消息走付费通道
- **蓝牙配对**：iOS / Android App 与 inReach 配对后，蓝牙是 inReach 的"控制台"，**不替代卫星链路**
- **离线模式**：inReach 关闭追踪但保留 SOS 能力
- **双向消息队列**：进入盲区时排队，出来时统一发送

## 北斗短报文实战注意

- **RDSS 链路需要用户卡**，类似 SIM；2023 起部分省份可与北斗 SIM 合一
- **短报文 + 定位合一**：发送时自动附带位置（无需 GPS）
- **频度限制**：1 次/秒，14 次/分钟，70 次/小时
- **汉字 UTF-8 编码**：1 汉字 = 3 字节，限 1000 汉字 = 3000 字节 → 实际限制 1000 汉字

## Apple Emergency SOS 实战注意

- **必须空旷 + 树荫外 + 楼顶外**才能搜到卫星
- **指向方向**：iOS 指引界面会显示卫星方位和方向，跟着走
- **预填问卷**：出发前在 iOS Health App 填"医疗 ID"，紧急时一并发送
- **不覆盖中国**：用华为 Mate 60 Pro 北斗短报文
- **电池模式**：低电量（< 5%）也能用 Emergency SOS 至少 5 小时

## PLB 实战注意

- **GPS 锁定需要 > 35 s**，耐心等待
- **碰撞保护**：ACR PLB 撞击感应器可自动启动
- **121.5 MHz 副载波**：SAR 直升机定向用，飞机到位后才有用
- **注册**：必须去 COSPAS-SARSAT 官网（406registration.com）注册，否则 SAR 拿到位置也找不到人
- **电池保质期**：从出厂日开始算，5 年后必须更换

## 检查清单

```text
□ 电源：发射瞬间峰值 1.5 A，留 2× 余量
□ 天线：仰角 > 30°，馈线 < 50mm
□ SIM：Iridium / 北斗用户卡有效
□ 模组 IMEI / S/N 已注册到运营商
□ 协议版本：SBD IX 协议 v2.0+
□ 定位：GPS 冷启动 < 35 s
□ 加密：端到端 AES-256，密钥周期 24h
□ 续航：-20°C 24+ 小时发射测试
□ 错误码：AT 命令 log + 模组 LED 编码可读
□ PLB 注册：406registration.com 完成
□ 多模备份：蜂窝 + 卫星 + 短报文 + PLB 至少 3 路
□ 户外测试：实际登山/海上 7 天 + 团队 24h 待命
```
