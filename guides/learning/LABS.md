# Labs · 可执行实验路线

## 目标

本文把“实验标题”升级为可执行实验卡。每个实验包含：

- 目标与前置条件。
- 接线/参数。
- 操作步骤。
- 预期现象与通过判据。
- 常见失败与证据。

实验卡不替代器件手册，具体寄存器、引脚和命令以实际平台为准。

## 使用方式

1. 先读对应协议文档，再按实验卡操作。
2. 每次实验记录固件版本、硬件版本、工具和接线。
3. 至少保存一种原始证据：波形、逻辑分析仪解码、抓包、寄存器 dump 或串口日志。
4. 失败时先记录现象，不要直接改代码掩盖问题。
5. 实验完成后把结果反向补充到对应协议文档或故障案例。

## LAB-01 GPIO 按键去抖与中断

目标：验证输入上下拉、中断触发和软件去抖。

接线：

```text
按键一端 -> GPIO 输入
按键另一端 -> GND
GPIO 配置上拉输入
```

步骤：

1. 配置 GPIO 为上拉输入，确认空闲为高。
2. 配置下降沿中断，记录 100 次按键触发次数。
3. 改为“中断唤醒 + 20 ms 定时采样确认”。
4. 用逻辑分析仪同时看按键电平和中断服务标记。

预期与判据：

- 空闲电平稳定，无明显漂移。
- 机械抖动期间只产生一次有效按键事件。
- 长按/短按状态机可区分。
- 连续 1,000 次按键无丢键、无重复触发。

常见失败：

- 浮空输入导致中断风暴。
- 中断标志未清导致重复进入。
- 去抖时间小于按键抖动时间。
- 低功耗模式下上下拉失效。

## LAB-02 PWM 舵机/LED 调光

目标：验证 PWM 频率、占空比、极性和负载驱动。

接线：

```text
PWM 输出 -> 舵机信号 / LED 驱动 / MOSFET 栅极
GND 共地
```

步骤：

1. 输出 50 Hz、1.0/1.5/2.0 ms 脉宽，观察舵机角度。
2. 输出 1 kHz、1%~99% 占空比，记录 LED 电流和亮度。
3. 用双通道示波器测量周期、脉宽、上升沿和过冲。
4. 扫描占空比，观察最小/最大有效占空比。
5. 感性负载时测量续流和电源纹波。

判据：

- 频率误差在晶振/定时器误差范围内。
- 脉宽与角度/亮度单调对应。
- 无明显过冲、振铃或电源跌落。
- 占空比边界行为符合设计。

常见失败：

- PSC/ARR 计算错误。
- 极性反了。
- 预装载未更新导致窄脉冲。
- 负载电流超过驱动能力。

## LAB-03 ADC 采样与噪声

目标：验证参考电压、采样时间、源阻抗和噪声。

接线：

```text
可调电源/分压 -> ADC 输入
ADC 输入脚加 RC 滤波（按需）
```

步骤：

1. 输入 0%、25%、50%、75%、100% 满量程，记录原始值。
2. 改变源阻抗（1 kΩ/10 kΩ/100 kΩ），观察读数变化。
3. 在 PWM/通信工作时采样，比较同步与异步采样。
4. 采集 1,024 点做 FFT，观察噪声频谱。
5. 高低温/不同电源电压下重复测量。

判据：

- 读数与输入电压在误差预算内一致。
- 源阻抗变化不引起明显偏差。
- 噪声峰值不落在关键测量频段。
- 校准后零点/满量程误差满足规格。

常见失败：

- Vref 不稳或用 VDD 直接做参考。
- 采样时间不足。
- 输入超范围/保护二极管导通。
- 地平面噪声耦合。

## LAB-04 UART DMA 环形接收

目标：验证 DMA 接收、空闲中断和不定长帧解析。

接线：

```text
MCU TX/RX <-> USB-UART
GND 共地
```

步骤：

1. 配置 UART + DMA 环形缓冲 + IDLE 中断。
2. PC 连续发送固定长度和随机长度帧。
3. 模拟高波特率、突发数据和长时间运行。
4. 人为制造溢出/断线，观察恢复。
5. 记录丢包、溢出和帧错误计数。

判据：

- 连续 100,000 字节无丢包。
- 随机长度帧边界正确。
- 溢出后能恢复，不永久卡死。
- CPU 负载在可接受范围。

常见失败：

- DMA 半传输/传输完成处理错误。
- 环形缓冲回绕覆盖未读数据。
- IDLE 中断清除顺序错误。
- 高波特率下中断延迟过大。

## LAB-05 I2C 总线恢复

目标：验证 SDA 被拉低后 9 clock 恢复流程。

接线：

```text
MCU SCL/SDA <-> 目标设备
上拉电阻按总线电容选择
```

步骤：

1. 正常读写设备 ID。
2. 用 GPIO/故障注入把 SDA 拉低。
3. 观察总线死锁和超时。
4. 执行 9 clock + STOP 恢复。
5. 恢复后重新读设备 ID。

判据：

- 正常读写稳定。
- 死锁能被检测到。
- 9 clock 后 SDA 释放。
- 恢复后通信正常，错误计数可追踪。

常见失败：

- SCL 不是开漏/上拉不足。
- 恢复时序不正确。
- 设备在恢复后仍需复位。
- 多主场景下恢复冲突。

## LAB-06 QSPI Flash 与 XIP

目标：验证 QE、dummy、地址模式和 XIP。

步骤：

1. 单线 SPI 读 JEDEC ID。
2. 置 QE，切换 Quad 读同一段数据。
3. 扫描 dummy cycle，找到稳定边界。
4. 写入递增 pattern，覆盖低/高地址并读回。
5. 配置 XIP，从 Flash 执行代码；擦写后做 cache 失效。

判据：

- ID 与 BOM 一致。
- 单线/四线读数据一致。
- 全地址 pattern 0 错误。
- XIP 启动/擦写/复位循环稳定。

常见失败：

- QE 未使能。
- dummy 不足。
- 24/32 位地址模式错误。
- XIP 擦写期间取指冲突。

## LAB-07 CAN FD 终端与错误帧

目标：验证终端、差分波形、错误帧和 Bus Off。

接线：

```text
两个 CAN 节点 + 两端 120 Ω
CAN 分析仪接入总线
```

步骤：

1. 断电测 CANH-CANL 电阻，确认约 60 Ω。
2. 两节点互发经典 CAN 帧。
3. 切换到 CAN FD，逐步提高数据段速率。
4. 拔掉一个终端，观察错误帧和 Bus Off。
5. 记录 TEC/REC、错误帧和恢复时间。

判据：

- 终端电阻符合预期。
- 经典 CAN/CAN FD 在目标速率下 0 错误。
- 错误注入后能恢复。
- 差分波形无明显振铃/过冲。

常见失败：

- 终端过多/缺失。
- 数据段速率超过收发器/拓扑能力。
- 采样点/SJW 不合适。
- 共模/地电位差。

## LAB-08 RS485 Modbus RTU 方向控制

目标：验证 DE/RE 时序和 Modbus RTU 帧完整性。

接线：

```text
MCU UART <-> RS485 收发器 <-> USB-RS485
终端/偏置按总线长度配置
```

步骤：

1. 以 9600/115200 读取从站寄存器。
2. 用逻辑分析仪同时看 UART TX、DE 和 A-B。
3. 扫描 DE 关闭延时，观察最后字节丢失边界。
4. 多节点轮询，记录 CRC 错和超时。
5. 加长线/加干扰，观察误码和恢复。

判据：

- 帧完整、CRC 正确。
- DE 关闭不截断最后字节。
- 多节点轮询无地址冲突。
- 长线误码率满足要求。

常见失败：

- TXE 而非 TC 关 DE。
- A/B 接反。
- 终端/偏置错误。
- 地电位差/浪涌。

## LAB-09 Ethernet PHY/RGMII Link

目标：验证 PHY 复位、MDIO、Link 和 RGMII 时序。

步骤：

1. 读 PHY ID 和 Link 状态。
2. 强制 100M 全双工，再恢复自协商。
3. 用 `ethtool`/`dmesg` 查看速率、双工和错误计数。
4. 用示波器看 RGMII 时钟/数据时序。
5. 大流量 ping/iperf，记录丢包和 CRC 错误。

判据：

- PHY ID 正确。
- Link 稳定在目标速率/双工。
- 吞吐达到规格的 90% 以上。
- 无持续 CRC/丢包错误。

常见失败：

- PHY 地址/MDIO 上拉错误。
- 复位/时钟时序不满足。
- RGMII delay 重复叠加。
- 磁性器件/Bob Smith/PCB 问题。

## LAB-10 BLE GATT 连接与吞吐

目标：验证广播、连接参数、GATT 读写和吞吐。

步骤：

1. 手机/nRF Connect 扫描并连接。
2. 读取设备信息、服务和特征。
3. 调整 connection interval、MTU、TX power。
4. 连续读写/通知，记录吞吐和断连。
5. 在 Wi-Fi/金属遮挡/远距离下重复。

判据：

- 广播/连接稳定。
- GATT 读写/通知正确。
- 吞吐满足应用需求。
- 弱信号下按策略重连。

常见失败：

- 连接参数与调度冲突。
- MTU 未协商。
- 2.4 GHz 干扰。
- 长任务阻塞协议栈。

## LAB-11 LoRaWAN 入网与 ADR

目标：验证 Join、上下行、ADR 和占空比。

步骤：

1. 核对 region/sub-band/DevEUI/AppKey。
2. 触发 OTAA Join，记录 Join Request/Accept。
3. 发送不同长度上行，观察 DR/SF/SNR。
4. 开启 ADR，移动/遮挡后观察速率调整。
5. 长时间运行，检查占空比和重试。

判据：

- Join 成功且稳定。
- 上下行数据正确。
- ADR 能根据链路质量调整。
- 不违反占空比/重试策略。

常见失败：

- 频点/sub-band 不匹配。
- 晶振频偏导致接收窗口错过。
- 网关/Network Server 配置错误。
- 天线/匹配不良。

## LAB-12 IEC 60870-5-104 总召

目标：验证 TCP 连接、STARTDT、总召和遥控。

步骤：

1. 建立 TCP 连接（端口 2404）。
2. 发送 STARTDT，确认从站响应。
3. 执行总召，解析 ASDU/COT/信息对象。
4. 执行遥控选择/执行，观察 ACT/CON。
5. 抓包并检查 K/W、t1/t2/t3 和序号。

判据：

- 链路建立/保持稳定。
- 总召数据与点表一致。
- 遥控选择/执行流程正确。
- 超时/断链可恢复。

常见失败：

- 公共地址/点表不一致。
- K/W 窗口/确认不及时。
- ASDU 长度/类型错误。
- 防火墙/NAT 断链。

## LAB-13 USB DFU 升级与回退

目标：验证 DFU 下载、校验、启动和失败回退。

步骤：

1. 进入 DFU，读取状态和能力。
2. 分块下载正确镜像，校验并重启。
3. 下载错误地址/错误 CRC 镜像，观察拒绝。
4. 升级中断电，观察回退/恢复。
5. 记录 DFU 日志、metadata 和 Flash dump。

判据：

- 正确镜像升级后正常启动。
- 错误镜像不破坏 Bootloader/恢复入口。
- 断电后可回退或重新进入 DFU。
- 版本/硬件信息正确。

常见失败：

- 镜像 load address/向量表错误。
- 擦除保护区域。
- metadata/boot flag 未更新。
- 回退入口不可用。
