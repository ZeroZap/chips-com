# GPIO

## 定位

GPIO 是通用输入输出口，是芯片与外部世界最基础的连接方式。它既可以独立完成按键、LED、复位、电源使能等控制，也可以作为 I2C、SPI、UART 等总线的辅助信号（片选、中断、方向控制、复位）。

GPIO 的工程问题通常不在“会不会点灯”，而在以下边界：

- 电平域是否匹配。
- 输入是否始终有确定状态。
- 输出驱动能力和斜率是否合适。
- 中断是否会抖动、丢失或误触发。
- 低功耗、复位和量产测试是否可控。

## 电气边界

| 项目     | 关注点                    | 典型风险                          |
| -------- | ------------------------- | --------------------------------- |
| 电平域   | VDDIO、VIH、VIL、VOH、VOL | 3.3V 器件直连 1.8V 芯片，或反过来 |
| 输入耐压 | 引脚是否 5V tolerant      | 超过绝对最大额定值导致漏电或损坏  |
| 输出电流 | 单脚和总灌/拉电流         | 多脚同时驱动 LED 导致压降、发热   |
| 上下拉   | 内部上下拉阻值和精度      | 内部弱上拉被外部电路拉偏          |
| 输入漏电 | 输入漏电流和模拟开关      | 高阻节点缓慢漂移                  |
| ESD      | HBM、CDM、系统级 ESD      | 连接器暴露引脚没有 TVS            |

设计时先确认：

```text
外部器件输出高/低电平，是否落在 MCU 的 VIH/VIL 范围内
MCU 输出高/低电平，是否落在外部器件的 VIH/VIL 范围内
所有输入在断电、复位、悬空时是否有确定状态
```

## 输入模式

### 浮空输入

浮空输入只读取引脚电平，不提供默认状态。它适合外部已经有强驱动或明确上下拉的信号，不适合按键、连接器输入和长线。

浮空输入的风险：

- 悬空时电平随机跳变。
- 输入级可能产生额外功耗。
- 中断会被噪声反复触发。

### 上拉 / 下拉输入

| 模式 | 默认状态 | 典型用途                           |
| ---- | -------- | ---------------------------------- |
| 上拉 | 高       | 低有效按键、开漏中断、片选默认无效 |
| 下拉 | 低       | 高有效按键、使能信号默认关闭       |

内部上下拉通常较弱（几十 kΩ 量级），只能保证“有确定状态”，不一定能对抗外部干扰或长线漏电。按键、连接器和板间信号优先使用外部上下拉。

### 模拟输入

引脚配置为模拟输入时，数字输入级通常会被关闭，以减少漏电和干扰。ADC 采样脚必须确认：

- 引脚处于模拟模式。
- 上下拉已关闭。
- 相邻高速数字信号没有耦合。

## 输出模式

### 推挽输出

推挽输出可以主动拉高和拉低，驱动能力强，边沿陡。适合：

- LED。
- 蜂鸣器。
- 复位、使能、片选。
- 需要快速边沿的数字信号。

注意：

- 两个推挽输出不能直接对接，否则可能形成短路。
- 驱动长线或大电容负载时，边沿会变缓并产生过冲。
- 多脚同时翻转会增加电源噪声和地弹。

### 开漏输出

开漏输出只能主动拉低，高电平由上拉电阻提供。适合：

- I2C 等线与总线。
- 多个器件共享中断线。
- 不同电压域之间的电平转换。
- 需要“释放总线”而不是主动驱动高的场景。

开漏输出的上升沿由 RC 决定：

```text
t_rise ≈ 2.2 × R_pullup × C_bus
```

上拉越大，上升沿越慢；上拉越小，功耗和低电平灌电流越大。

### 驱动能力与斜率

很多 MCU 支持可配置驱动强度（2/4/8/12 mA 等）和斜率（slow/fast）。选择原则：

- 低速控制信号优先用较低驱动和较慢斜率，降低 EMI。
- 高速信号需要足够驱动，但要控制过冲和振铃。
- 多脚并行走线时避免同时高速翻转。
- 驱动 LED 时按电流计算限流电阻，不要依赖引脚内阻。

## 中断与唤醒

GPIO 中断常见触发方式：

```text
上升沿
下降沿
双边沿
高电平
低电平
```

工程上要注意：

- 双边沿中断可能在同一机械抖动中触发多次。
- 低电平中断在电平持续期间可能反复进入。
- 中断标志必须在处理前清除，避免丢失或重复。
- 低功耗唤醒脚通常有独立的边沿/电平要求。
- 深睡眠时部分 GPIO 可能失去上下拉或保持能力。

按键中断建议采用“中断唤醒 + 定时采样确认”的方式，而不是在中断里直接认为按键有效。

## 去抖与状态机

机械按键抖动通常持续几毫秒到几十毫秒。常见方案：

| 方案       | 特点                   | 适用          |
| ---------- | ---------------------- | ------------- |
| 软件延时   | 简单，但阻塞           | 裸机简单场景  |
| 定时采样   | 稳定，易扩展           | 大多数产品    |
| 状态机     | 可识别短按、长按、双击 | 复杂按键      |
| RC 滤波    | 硬件成本低，边沿变缓   | 按键、复位    |
| 施密特触发 | 抗慢变信号             | 模拟/数字混合 |

一个可复用的按键状态机：

```c
typedef enum {
    KEY_IDLE,
    KEY_DEBOUNCE,
    KEY_PRESSED,
    KEY_RELEASE_DEBOUNCE
} key_state_t;

void key_task(key_t *k, bool raw_level, uint32_t now_ms)
{
    switch (k->state) {
    case KEY_IDLE:
        if (raw_level == k->active_level) {
            k->state = KEY_DEBOUNCE;
            k->timestamp = now_ms;
        }
        break;
    case KEY_DEBOUNCE:
        if (now_ms - k->timestamp >= 20) {
            k->state = (raw_level == k->active_level) ? KEY_PRESSED : KEY_IDLE;
        }
        break;
    case KEY_PRESSED:
        if (raw_level != k->active_level) {
            k->state = KEY_RELEASE_DEBOUNCE;
            k->timestamp = now_ms;
        }
        break;
    case KEY_RELEASE_DEBOUNCE:
        if (now_ms - k->timestamp >= 20) {
            k->state = (raw_level != k->active_level) ? KEY_IDLE : KEY_PRESSED;
        }
        break;
    }
}
```

## 寄存器与初始化流程

以常见 MCU 为例，GPIO 初始化通常包括：

1. 使能 GPIO 端口时钟。
2. 配置引脚复用功能（GPIO / 外设 / 模拟）。
3. 配置方向（输入 / 输出）。
4. 配置输出类型（推挽 / 开漏）。
5. 配置上下拉。
6. 配置驱动强度和斜率。
7. 配置中断触发方式和优先级。
8. 清除中断标志并使能中断。

伪代码：

```c
gpio_init(GPIOA, PIN5,
          GPIO_MODE_OUTPUT,
          GPIO_OTYPE_PUSH_PULL,
          GPIO_PULL_NONE,
          GPIO_SPEED_LOW);
gpio_write(GPIOA, PIN5, 1);
```

初始化前要确认引脚没有被调试接口、BOOT 配置、低功耗保持或安全功能占用。

## 常见故障树

```text
GPIO 不工作
├── 电源/地
│   ├── VDDIO 缺失或电压不对
│   ├── 地不共地
│   └── 复位未释放
├── 配置
│   ├── 端口时钟未使能
│   ├── 引脚复用错误
│   ├── 方向配置错误
│   ├── 输出类型错误
│   └── 上下拉配置错误
├── 电气
│   ├── 外部短路/过载
│   ├── 输入超范围
│   ├── 开漏缺上拉
│   └── 驱动能力不足
└── 软件
    ├── 中断标志未清
    ├── 中断优先级/屏蔽
    ├── 读写时序错误
    └── 低功耗模式关闭了 GPIO
```

| 现象           | 优先检查                                 |
| -------------- | ---------------------------------------- |
| 输入乱跳       | 浮空、上下拉缺失、长线干扰、地不干净     |
| 输出不动       | 端口时钟、复用、方向、外部短路、安全锁定 |
| 输出电平不对   | 电平域、开漏缺上拉、负载过重、驱动能力   |
| 中断频繁触发   | 抖动、边沿配置、噪声、标志未清           |
| 中断不触发     | 引脚复用、触发边沿、屏蔽、优先级         |
| 低功耗唤醒失败 | 唤醒脚配置、上下拉保持、睡眠模式限制     |
| 复位后状态异常 | BOOT 引脚、调试脚、外部上下拉、复位时序  |

## 测量方法

- 用万用表确认静态高低电平和上下拉。
- 用示波器看边沿、过冲、振铃和上升/下降时间。
- 用逻辑分析仪确认中断触发和软件采样时刻。
- 按键/连接器信号要做插拔、ESD 和长线测试。
- 低功耗场景测量休眠电流，确认没有浮空输入或上下拉冲突。

## 设计检查清单

- 每个输入都有确定默认状态。
- 按键和连接器有外部上下拉或明确驱动。
- 开漏输出有合适上拉和上升沿预算。
- 输出电流不超过单脚和总电流限制。
- 高速/长线信号有斜率、串阻或终端策略。
- 中断脚有去抖和标志清除策略。
- 调试脚、BOOT 脚、复位脚在量产时可控。
- 低功耗唤醒脚在睡眠期间保持有效。
- 连接器暴露引脚有 ESD/浪涌保护。
- 关键测试点可达。

## 最小实验

1. 配置一个推挽输出，驱动 LED，测量高/低电平和电流。
2. 配置一个上拉输入，接按键，观察抖动并实现 20 ms 去抖。
3. 配置双边沿中断，记录 100 次按键触发的实际次数。
4. 配置开漏输出，加上拉电阻，测量上升沿并计算 RC。
5. 进入低功耗模式，用 GPIO 边沿唤醒，测量休眠电流和唤醒时间。
