# JTAG / SWD

## 定位

JTAG 和 SWD 是芯片调试与编程接口，用于：

- 下载/烧录固件。
- 断点、单步、寄存器/内存访问。
- 读取芯片 ID、状态和错误信息。
- 边界扫描/生产测试（JTAG）。
- 量产校准、密钥注入和生产配置。

它们不是普通数据通信总线，而是**调试访问端口**。工程上最关心的是：能不能稳定连上、能不能量产、会不会被低功耗/安全配置锁死。

## JTAG

### 信号

| 信号  | 方向           | 作用             |
| ----- | -------------- | ---------------- |
| TCK   | 调试器 -> 目标 | 测试时钟         |
| TMS   | 调试器 -> 目标 | TAP 状态机控制   |
| TDI   | 调试器 -> 目标 | 数据输入         |
| TDO   | 目标 -> 调试器 | 数据输出         |
| TRST  | 调试器 -> 目标 | 复位 TAP，可选   |
| VTref | 目标 -> 调试器 | 目标 IO 参考电压 |
| GND   | 共地           | 参考地           |

JTAG 使用 TAP 状态机，通过 TMS 在状态间迁移，通过 TDI/TDO 移位指令和数据。多个器件可以菊花链连接。

### 特点

- 引脚较多。
- 支持边界扫描。
- 适合多器件链、FPGA/CPLD、生产测试。
- 时钟速率和链长相关。
- 需要正确识别 IR/DR 长度。

## SWD

### 信号

| 信号  | 方向           | 作用                 |
| ----- | -------------- | -------------------- |
| SWCLK | 调试器 -> 目标 | 串行时钟             |
| SWDIO | 双向           | 命令/数据            |
| NRST  | 调试器 -> 目标 | 复位，可选但强烈建议 |
| VTref | 目标 -> 调试器 | 目标 IO 参考电压     |
| GND   | 共地           | 参考地               |

SWD 常见于 ARM Cortex-M。它用两根线完成调试访问，引脚少，适合小封装和量产测试点。

### SWD 协议要点

- 通过 SWDIO 发送请求包。
- 目标返回 ACK（OK/WAIT/FAULT）。
- 数据传输带奇偶校验。
- 支持多字读写、批量传输。
- 需要 line reset 序列恢复同步。
- 时钟频率可降速以提高稳定性。

调试器连接失败时，降速和 line reset 是最常用的第一步。

## VTref

调试器通常需要目标板参考电压：

```text
VTref
```

它告诉调试器目标 IO 电平是 1.8 V、3.3 V 还是其他电压。VTref 缺失或接错会导致：

- 调试器不识别目标。
- 电平不匹配，通信不稳定。
- 目标或调试器 IO 受损。

VTref 应接目标板的 IO 电源域，而不是随便接一个电源。

## 复位与连接

推荐连接：

```text
SWCLK
SWDIO
GND
VTref
NRST
```

`NRST` 的作用：

- 连接时复位目标，进入调试状态。
- 从低功耗/错误状态恢复。
- 量产烧录时保证已知状态。
- 支持 connect under reset。

有些应用会禁用复位脚或把它复用为 GPIO，导致调试器无法连接。设计时应保留调试复位能力。

## 低功耗与安全

常见“连不上”的原因不是硬件坏，而是芯片状态：

- 应用进入深睡眠，关闭了调试时钟。
- 看门狗反复复位。
- 读保护/RDP 生效。
- 安全启动禁止调试。
- BOOT 配置从错误介质启动。
- 调试引脚被复用为普通 GPIO。
- 时钟配置错误导致内核不运行。

排查顺序：

1. 确认供电、GND、VTref。
2. 用 connect under reset。
3. 降低 SWD/JTAG 时钟。
4. 检查 BOOT/复位/调试引脚。
5. 尝试擦除/解锁流程。
6. 检查读保护和安全配置。

## 量产烧录

量产测试点设计：

- 测试点要大、可达、防误触。
- GND 至少两个点，缩短回流。
- VTref 与目标 IO 同域。
- NRST 可控。
- SWCLK/SWDIO 加适当串阻/ESD 保护。
- 测试点不要被结构件遮挡。
- 夹具探针压力和接触电阻可控。

量产流程：

```text
上电 -> 连接 -> 读 ID -> 擦除 -> 烧录 -> 校验 -> 配置 -> 锁定 -> 复位 -> 功能测试
```

要记录：

- 芯片 ID、固件版本、校准值。
- 烧录时间、工位、操作员。
- 失败原因和重试次数。
- 读保护/安全配置状态。

## 信号完整性

调试接口虽然速率不高，但线长、夹具和干扰仍会影响：

- SWCLK/SWDIO 走线尽量短。
- 避免与高速/大电流信号并行。
- 长线/夹具加串阻和地回流。
- ESD 保护不能影响信号边沿。
- 多器件 JTAG 链注意 TCK/TMS 分布和终端。
- 调试器地线与目标地可靠连接。

## 常见故障树

```text
连接不上
├── 供电/GND/VTref
├── 调试器驱动/目标选择
├── 调试引脚复用/被占用
├── 复位/BOOT 配置
├── 低功耗/看门狗
├── 读保护/安全启动
└── 硬件焊接/连接器

连接不稳定
├── 时钟过高
├── 线长/夹具接触
├── 地回流差
├── ESD/串阻影响边沿
└── 目标电源噪声

下载中断
├── Flash 擦写期间掉电
├── 看门狗/低功耗
├── 时钟切换
├── 调试器超时
└── 目标复位

芯片锁死
├── 读保护/RDP
├── 安全启动
├── 调试脚复用
├── 低功耗关闭调试
└── BOOT 介质错误
```

| 现象           | 优先检查                         |
| -------------- | -------------------------------- |
| 连接不上       | 供电、GND、VTref、复位、引脚复用 |
| 下载中断       | 时钟过高、线长、接触、电源       |
| 芯片锁死       | 低功耗、读保护、复位脚、BOOT     |
| SWDIO 异常     | 上拉、复用、被应用占用、ESD      |
| 量产良率低     | 测试点、夹具、探针、地回流       |
| 连接后程序跑飞 | 复位/时钟配置、调试暂停影响      |

## 测量方法

- 万用表确认 VTref、GND、复位电平。
- 示波器看 SWCLK/SWDIO 边沿和噪声。
- 逻辑分析仪解码 SWD 请求/ACK。
- 用调试器日志确认连接阶段和错误码。
- 量产夹具做接触电阻和重复插拔测试。

## 设计检查清单

- 调试接口引脚未被误复用。
- VTref 接目标 IO 电源域。
- GND 可靠，测试点足够。
- NRST 可控，保留 connect under reset 能力。
- SWCLK/SWDIO 有适当串阻/ESD 保护。
- 低功耗模式不关闭调试时钟，或提供恢复方式。
- 读保护/安全配置有解锁和量产流程。
- 多器件 JTAG 链的 IR/DR 长度和拓扑确认。
- 测试点、夹具、探针可达。
- 量产测试覆盖 ID、烧录、校验、锁定和功能。

## 最小实验

1. 用 SWD 连接目标，读取芯片 ID 和闪存大小。
2. 降低 SWD 时钟，比较不同线长下的连接稳定性。
3. 进入低功耗模式，测试 connect under reset 是否能恢复。
4. 用 JTAG 链连接两个器件，确认 IR/DR 长度。
5. 用量产夹具连续烧录 100 次，记录失败率和接触问题。
