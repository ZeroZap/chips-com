# RS232 / RS485

## 定位

RS232 和 RS485 是串行通信的电气标准。它们经常承载 UART 字节流，但**不是 UART 本身**。

分层关系：

```text
应用层：Modbus RTU / 自定义协议 / AT 命令
字节层：UART 帧（起始位、数据位、校验、停止位）
电气层：RS232 / RS485 / RS422 / TTL
物理层：连接器、线缆、终端、隔离、防护
```

工程上最常见的错误，是把“UART TTL”“RS232”“RS485”混为一谈。

## RS232

### 电气特点

- 单端信号。
- 使用正负电压表示逻辑，常见 ±3 V ~ ±15 V。
- 逻辑通常是反相的：负电压为逻辑 1，正电压为逻辑 0。
- 点对点连接。
- 抗干扰能力弱于差分总线。
- 不能直接接 MCU 的 UART TTL 引脚。

常见转换芯片：

```text
MAX232
MAX3232
SP3232
CH340/CP2102 的 RS232 版本
```

### 典型连接

```text
MCU UART TX/RX <-> RS232 Transceiver <-> DB9/RJ45 <-> 外部设备
```

最少需要：

```text
TXD
RXD
GND
```

硬件流控时还需要：

```text
RTS
CTS
```

### RS232 注意事项

- 电平转换芯片需要电荷泵电容，电容值和布局按手册。
- 外部设备可能只接 TX/RX/GND，不要假设流控一定可用。
- 长线、强干扰环境优先考虑隔离或转 RS485。
- DB9 的 2/3 脚定义有 DTE/DCE 差异，必要时用交叉线。
- 热插拔和地电位差可能损坏收发器。

## RS485

### 电气特点

- 差分信号，A/B（或 D+/D-）。
- 抗共模干扰能力强。
- 支持多点总线。
- 常见两线半双工；四线全双工为 RS422/RS485 全双工变体。
- 接收器共模范围通常为 -7 V ~ +12 V。
- 标准节点数受单位负载限制，常见 32 单位负载；1/8 负载器件可扩展到更多节点。

典型结构：

```text
MCU UART <-> RS485 Transceiver <-> A/B Bus
```

### 半双工方向控制

RS485 收发器通常有：

```text
DE：Driver Enable，发送使能
RE：Receiver Enable，接收使能（低有效常见）
```

典型控制：

```text
发送：DE=1，RE=1（或按芯片定义）
接收：DE=0，RE=0
```

方向切换时序非常关键：

1. 软件把数据写入 UART。
2. 等待 UART 移位寄存器真正发完（TC/TXE，而不是 TXE）。
3. 再关闭 DE。
4. 保留少量保持时间，避免最后字节被截断。

常见错误是“TXE 一置位就关 DE”，导致最后一个字节或停止位丢失。

### 终端与偏置

长线 RS485 两端通常各加：

```text
120 Ω 终端电阻
```

中间节点不加终端。终端用于吸收反射，阻值应接近线缆特性阻抗。

空闲时 A/B 可能悬空，需要偏置电阻让接收器保持确定状态：

```text
A 上拉，B 下拉
```

偏置电阻会增加总线负载和功耗，阻值需要和终端、节点数、速率一起计算。

### 拓扑与线缆

推荐：

- 手拉手总线拓扑。
- 分支尽量短。
- 使用双绞线。
- A/B 使用同一对双绞线。
- 屏蔽层按现场接地规范处理。
- 避免星形、长分支和不同阻抗线缆混用。

### 隔离与防护

工业现场建议考虑：

- 隔离收发器或外部隔离模块。
- TVS/气体放电管/浪涌保护。
- 共模电感。
- 屏蔽双绞线。
- 独立隔离电源。
- 正确的接地和等电位连接。

隔离不是“可选的高级功能”，在地电位差、长线、雷击和强干扰场景通常是必需项。

## RS232 / RS485 / TTL 对比

| 项目     | TTL UART         | RS232                  | RS485                      |
| -------- | ---------------- | ---------------------- | -------------------------- |
| 信号方式 | 单端             | 单端                   | 差分                       |
| 典型电平 | 0/3.3 V 或 0/5 V | ±3~±15 V               | 差分，共模 -7~+12 V        |
| 逻辑     | 正逻辑           | 常见反相               | 差分极性                   |
| 距离     | 板内短           | 十几米量级，取决于速率 | 百米到千米量级，取决于速率 |
| 拓扑     | 点对点           | 点对点                 | 多点总线                   |
| 抗干扰   | 弱               | 中                     | 强                         |
| 典型用途 | MCU/模块         | 仪器、工控机、老设备   | 工业现场、Modbus RTU       |

## 常见故障树

```text
RS232 不通
├── TTL 直连 RS232（缺转换芯片）
├── TX/RX 交叉/直连错误
├── 电平不足/电荷泵电容错误
├── 地不共地
├── 流控未接但软件启用
└── 连接器 2/3 脚定义不匹配

RS485 不通
├── TTL 直连 A/B（缺收发器）
├── A/B 接反
├── DE/RE 控制错误
├── 终端/偏置错误
├── 共地/隔离问题
├── 地址/波特率/校验不一致
└── 总线冲突

RS485 最后字节丢失
├── DE 关闭过早
├── 未等待 TC/TXE
├── 方向切换延时不足
└── 驱动能力/终端不匹配

RS485 偶发错误
├── 终端缺失/过多
├── 分支过长
├── 地电位差
├── 浪涌/ESD
├── 线缆阻抗不匹配
└── 波特率/采样点余量不足
```

| 现象           | 优先检查                        |
| -------------- | ------------------------------- |
| 完全无数据     | 转换芯片、使能、接线、地、电源  |
| 能收不能发     | DE/RE、UART TX、方向控制        |
| 最后字节丢失   | DE 关闭时机、TC 标志            |
| 多节点不稳定   | 终端、偏置、拓扑、地址冲突      |
| 长线偶发错误   | 隔离、屏蔽、接地、共模干扰      |
| A/B 接了还不通 | 厂商 A/B 命名可能相反，尝试交换 |
| 热插拔后损坏   | TVS、隔离、地电位差、浪涌       |

## 测量方法

- 示波器看 RS232 的正负电平和边沿。
- 差分探头看 RS485 A-B 差分波形和共模电压。
- 逻辑分析仪解码 UART 字节，确认帧边界。
- 用万用表测断电时 A-B 电阻，判断终端是否合适。
- 用电流探头/隔离探头检查地电位差和浪涌。
- 长线测试要做不同波特率、不同节点数、不同线缆长度组合。

## 设计检查清单

- TTL/RS232/RS485 层级区分清楚。
- 收发器型号、供电、使能逻辑确认。
- DE/RE 时序和最后字节处理正确。
- 终端电阻只加在总线两端。
- 偏置电阻和节点数匹配。
- A/B 极性与连接器定义确认。
- 长线/现场场景有隔离、TVS、共模电感。
- 屏蔽层和接地策略明确。
- 连接器、测试点、指示灯可达。
- 量产测试覆盖收发、方向切换和长线误码。

## 最小实验

1. MCU UART 经 RS232 收发器连接 PC，验证 9600/115200 收发。
2. 两个 RS485 节点互发数据，测量 A-B 差分波形。
3. 扫描 DE 关闭延时，观察最后字节丢失边界。
4. 断电测量 A-B 电阻，验证终端数量。
5. 加长线、加节点、加干扰源，记录误码率和恢复行为。
