# CAN PHY

## 定位

CAN PHY 是 CAN 总线的物理层，负责把 CAN 控制器的数字信号转换为 `CANH/CANL` 差分信号，并把总线上的差分电平还原为数字接收信号。

典型结构：

```text
MCU CAN Controller <-> CAN Transceiver <-> CANH/CANL Bus
```

MCU 的 `CAN_TX/CAN_RX` 是单端逻辑信号，**不能直接接总线**。必须经过 CAN 收发器。

CAN PHY 的工程问题集中在：

- 差分电平与共模范围。
- 终端电阻和总线拓扑。
- 收发器环路延迟。
- ESD/浪涌/隔离。
- CAN FD 高速数据段的信号完整性。

## 显性与隐性

CAN 使用差分信号：

```text
显性 dominant：CANH 与 CANL 有明显差分
隐性 recessive：CANH 与 CANL 差分接近 0
```

经典 CAN 中通常理解为：

```text
dominant = 0
recessive = 1
```

多个节点同时发送时，显性会覆盖隐性，这就是 CAN 仲裁的物理基础。

注意：显性/隐性描述的是差分状态，不是简单的“CANH 高、CANL 低”。测量时要看 `CANH - CANL` 的差分电压和共模电压。

## 终端电阻

高速 CAN 总线两端通常各加：

```text
120 Ω
```

等效并联：

```text
120 Ω // 120 Ω = 60 Ω
```

断电测量 `CANH` 与 `CANL` 之间，典型约 60 Ω。如果测得：

| 测量值         | 可能原因                         |
| -------------- | -------------------------------- |
| 约 120 Ω       | 只有一端终端                     |
| 约 60 Ω        | 两端终端正常                     |
| 约 40 Ω 或更低 | 终端过多                         |
| 开路/很大      | 终端缺失、线缆断开、连接器未插好 |

不要在每个节点都加 120 Ω。终端应放在总线物理两端，而不是任意节点。

### 分裂终端

有些设计使用“分裂终端”：

```text
CANH -- 60 Ω -- 中点 -- 60 Ω -- CANL
              |
           电容到地
```

优点：

- 提供共模偏置/稳定共模电压。
- 改善 EMC。
- 中点电容可以滤除共模噪声。

注意：

- 两个 60 Ω 串联等效仍是 120 Ω。
- 中点电容和布局要按收发器/EMC 要求设计。
- 不是所有场景都需要分裂终端。

## 共模与偏置

CAN 收发器有共模输入范围。总线共模电压超出范围时，接收器可能误判。

常见共模问题：

- 节点之间地电位差。
- 长线共模干扰。
- 隔离电源/非隔离电源混用。
- 屏蔽层接地不当。

解决方向：

- 使用隔离 CAN 收发器。
- 增加共模电感。
- 统一地/等电位连接。
- 使用屏蔽双绞线并正确接地。
- 检查收发器共模范围是否覆盖现场条件。

## 拓扑与线缆

推荐：

- 手拉手总线拓扑。
- 分支尽量短。
- 使用 120 Ω 双绞线。
- CANH/CANL 使用同一对双绞线。
- 避免星形、长分支、不同阻抗线缆混用。
- 连接器、终端、节点位置按总线两端布置。

高速 CAN 和 CAN FD 对拓扑更敏感。CAN FD 数据段速率越高，允许的线长、分支和寄生电容越小。

## 收发器选型

常见关注项：

| 项目     | 说明                                   |
| -------- | -------------------------------------- |
| 速率     | 经典 CAN / CAN FD / CAN XL             |
| 供电     | 5 V、3.3 V、双电源                     |
| 共模范围 | 是否满足现场地电位差                   |
| 隔离     | 是否需要隔离电源和隔离收发器           |
| 环路延迟 | 影响 CAN FD 采样点和总线长度           |
| ESD/浪涌 | 系统级防护等级                         |
| 低功耗   | 待机、唤醒、远程唤醒                   |
| 故障保护 | 总线短路、热关断、TXD dominant timeout |

CAN FD 选型不能只看“支持 5 Mbps”，还要看环路延迟、对称性、共模和 EMC。

## 环路延迟与 CAN FD

CAN FD 在仲裁阶段使用标称速率，在数据段切换到更高速率。高速数据段对以下因素更敏感：

```text
收发器环路延迟
总线传播延迟
节点数量
线缆长度
终端和分支
采样点配置
```

如果数据段速率提高后出现偶发错误：

- 降低数据段速率。
- 缩短总线/分支。
- 更换低延迟收发器。
- 调整采样点/SJW。
- 检查终端和共模。
- 用示波器看数据段边沿和振铃。

## 隔离与防护

工业/车载现场建议考虑：

- 隔离 CAN 收发器。
- 隔离电源。
- TVS/ESD 保护。
- 共模电感。
- 屏蔽双绞线。
- 正确的连接器和线束固定。

隔离不是万能的：隔离两端仍需 EMC 防护，隔离电源的爬电距离、耐压和认证要满足现场要求。

## 常见故障树

```text
CAN 完全无通信
├── 收发器电源/使能
├── CAN_TX/CAN_RX 接反或复用错误
├── 终端缺失/总线开路
├── 波特率不一致
├── 收发器损坏
└── 总线短路到电源/地

CAN 单节点 ACK Error
├── 总线上没有其他节点
├── 其他节点未上电/未初始化
├── 终端/电平异常
├── 收发器 TX 或 RX 损坏
└── 节点处于 Listen-only/回环模式

Bus Off
├── 终端/拓扑/干扰
├── 波特率/采样点
├── 地电位差/共模
├── 收发器或线束故障
└── 软件错误恢复策略

CAN FD 数据段偶发错误
├── 数据段速率过高
├── 收发器环路延迟
├── 线缆/分支过长
├── 采样点/SJW 不合适
├── 终端/共模/EMC
└── 时钟精度
```

| 现象             | 优先检查                            |
| ---------------- | ----------------------------------- |
| 无通信           | 收发器、电源、终端、波特率、TXD/RXD |
| 单节点 ACK Error | 是否有其他节点、终端、收发器        |
| 断电测不是 60 Ω  | 终端缺失/过多、线缆断开             |
| 偶发错误帧       | 拓扑、分支、线缆、共模、采样点      |
| Bus Off 反复     | 干扰、终端、地电位差、错误恢复      |
| CAN FD 高速误码  | 数据段速率、环路延迟、线长、采样点  |
| 热插拔损坏       | ESD/TVS、隔离、地电位差             |

## 测量方法

- 断电测 CANH-CANL 电阻，确认终端。
- 用差分探头看显性/隐性差分电压和共模电压。
- 用 CAN 分析仪看错误帧、TEC/REC、Bus Off。
- 用示波器看 CAN FD 数据段边沿、振铃和眼图。
- 用电流探头/隔离探头检查地电位差和浪涌。
- 高低温、低压、长线、多节点做余量测试。

## 设计检查清单

- 收发器型号、速率、供电、共模范围确认。
- CAN_TX/CAN_RX 极性和复用正确。
- 终端只放在总线两端，等效 60 Ω。
- 分裂终端/偏置/共模电容按设计。
- 总线拓扑、分支、线缆阻抗满足速率要求。
- CAN FD 数据段速率与收发器环路延迟匹配。
- 隔离、TVS、共模电感按现场等级设计。
- 连接器、测试点、终端使能跳线可达。
- 软件有 Bus Off 恢复和错误计数日志。
- 量产测试覆盖终端、收发、错误帧和 Bus Off。

## 最小实验

1. 两个节点互发经典 CAN 帧，测量 CANH/CANL 差分波形。
2. 断电测 A-B 电阻，验证 60 Ω。
3. 拔掉一个终端，观察错误帧和通信状态。
4. 提高 CAN FD 数据段速率，记录误码和眼图变化。
5. 加入共模干扰/地电位差，观察隔离与非隔离方案的差异。
