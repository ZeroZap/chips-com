# ADC / DAC

## 定位

ADC（Analog-to-Digital Converter）把模拟电压转换为数字量；DAC（Digital-to-Analog Converter）把数字量转换为模拟电压。

它们连接的是“真实世界的模拟量”和“数字系统”，工程问题通常来自：

- 参考电压不稳定。
- 输入源阻抗过高。
- 采样时间不足。
- 地平面和电源噪声。
- 校准和增益/偏置误差。
- DAC 输出负载过重。

ADC/DAC 不是“读一个寄存器”这么简单，必须把**模拟前端、参考源、采样时序和数字滤波**作为一个整体设计。

## 核心参数

### ADC

| 参数                | 含义            | 影响                 |
| ------------------- | --------------- | -------------------- |
| Resolution          | 分辨率，N 位    | 最小可分辨电压       |
| Vref                | 参考电压        | 满量程和绝对精度     |
| Sampling Rate       | 采样率          | 可测信号带宽         |
| Input Range         | 输入范围        | 过压/欠压风险        |
| Input Impedance     | 输入阻抗        | 采样时间与源阻抗匹配 |
| INL / DNL           | 积分/微分非线性 | 实际转换曲线偏差     |
| Offset / Gain Error | 偏置/增益误差   | 可通过校准修正       |
| Noise               | 输入噪声        | 有效位数和抖动       |

N 位 ADC 的理想量化台阶（LSB）：

```text
LSB = Vref / 2^N
```

电压换算（单端、无符号）：

```text
Voltage = Raw / 2^N × Vref
```

如果使用 `2^N - 1` 作为满量程，需要和芯片手册的转换公式保持一致。不同 ADC 的满量程定义可能不同。

### DAC

| 参数             | 含义     | 影响                |
| ---------------- | -------- | ------------------- |
| Resolution       | 分辨率   | 输出电压步进        |
| Output Range     | 输出范围 | 是否满足后级需求    |
| Settling Time    | 建立时间 | 高速波形/阶跃响应   |
| Slew Rate        | 压摆率   | 大信号变化速度      |
| Output Impedance | 输出阻抗 | 负载调整率          |
| Glitch           | 切换毛刺 | 上电/更新瞬间的尖峰 |
| Reference        | 参考源   | 输出精度和噪声      |

DAC 输出通常需要缓冲器或驱动器才能带较大负载。

## 误差预算

ADC 总误差不是单一指标，而是多项误差的组合：

```text
总误差 ≈ 参考电压误差
       + 量化误差
       + INL/DNL
       + 偏置误差
       + 增益误差
       + 输入源/采样误差
       + 噪声
       + 温度漂移
```

工程上先判断“哪一项占主导”：

- 如果读数整体偏移，优先查偏置和参考。
- 如果读数比例偏差，优先查增益和分压电阻。
- 如果读数跳动，优先查噪声、源阻抗和采样时间。
- 如果只在高温/低温异常，优先查温漂和参考源。

## 采样时间与源阻抗

SAR ADC 采样阶段可以等效为：

```text
源阻抗 Rs + 采样开关电阻 Rsw -> 采样电容 Csample
```

建立时间近似：

```text
t_settle ≈ (Rs + Rsw) × Csample × ln(2^(N+1))
```

实际计算需要查手册中的 `Csample`、`Rsw` 和推荐采样时间。工程判断：

- 源阻抗越高，所需采样时间越长。
- 多通道轮询时，通道切换后要留足建立时间。
- 高阻信号优先加运放缓冲，而不是无限延长采样时间。
- 采样时间过长会降低最大采样率。

常见输入结构：

| 输入源                     | 建议                          |
| -------------------------- | ----------------------------- |
| 低阻分压（几 kΩ 以下）     | 可直接采样，确认采样时间      |
| 高阻传感器（几十 kΩ 以上） | 加运放缓冲或降低采样率        |
| 热电偶/电桥                | 加仪表放大器、滤波和偏置      |
| 电流采样                   | 加差分放大/隔离，注意共模范围 |

## 参考电压

Vref 决定 ADC 的绝对精度。常见来源：

- 芯片内部参考。
- 外部基准芯片。
- 电源电压直接作为参考。
- DAC/ADC 专用参考引脚。

注意：

- 内部参考通常精度和温漂较差。
- 用 VDD 做参考会把电源噪声直接带入结果。
- 外部基准需要合适的去耦和负载能力。
- 参考引脚上的噪声会按比例出现在所有通道。

高精度测量建议使用外部基准，并在固件中记录基准电压和校准系数。

## 输入保护与滤波

ADC 输入通常不能承受超出范围或负压。常见保护：

- 串联限流电阻。
- 对地/对电源肖特基钳位。
- TVS。
- RC 低通滤波。
- 运放跟随/缓冲。

RC 滤波截止频率：

```text
fc = 1 / (2πRC)
```

选择原则：

- `fc` 低于采样率的一半，抑制混叠。
- 电阻不能太大，否则影响采样建立。
- 电容不能太大，否则增加建立时间。
- 保护二极管漏电会影响高阻信号。

## 校准

常见校准项：

```text
Offset：零输入时的读数
Gain：已知输入下的比例误差
Vref：实际参考电压
Temperature：温漂补偿
```

两点校准：

```text
raw_low, volt_low
raw_high, volt_high
gain = (volt_high - volt_low) / (raw_high - raw_low)
offset = volt_low - gain × raw_low
voltage = gain × raw + offset
```

校准点应覆盖实际使用范围，并在温度稳定后进行。量产校准需要记录校准值、日期和工位。

## 过采样与滤波

过采样可以降低噪声、提高有效分辨率：

```text
每 4 倍过采样，理论信噪比改善约 6 dB（1 bit）
```

实现方式：

- 硬件过采样（部分 MCU 支持）。
- 软件累加平均。
- 滑动平均。
- 中值滤波抑制脉冲噪声。
- IIR/FIR 低通滤波。

注意：

- 过采样不能修复参考电压误差或 INL。
- 平均会降低更新率。
- 中值滤波适合抑制尖峰，不适合连续噪声。
- 采样必须避开开关电源、PWM 和通信突发时刻。

## DAC 输出设计

DAC 输出常见问题：

- 直接带负载导致电压跌落。
- 容性负载导致振荡。
- 更新瞬间毛刺。
- 上电默认输出不确定。
- 参考电压噪声直接出现在输出。

建议：

- 需要带负载时加运放缓冲。
- 容性负载加串联小电阻隔离。
- 上电时先设置为安全值。
- 关键输出加 RC 滤波。
- 高速波形关注建立时间和压摆率。

## 常见故障树

```text
ADC 读数异常
├── 参考电压
│   ├── Vref 不稳/噪声大
│   ├── 用 VDD 做参考
│   └── 参考去耦不足
├── 输入
│   ├── 超范围/负压
│   ├── 源阻抗过高
│   ├── 分压电阻误差
│   └── 输入滤波时间常数过大
├── 采样
│   ├── 采样时间不足
│   ├── 多通道切换未建立
│   └── 采样率/时钟配置错误
├── 噪声
│   ├── 地平面分割
│   ├── PWM/电源耦合
│   └── 数字信号串扰
└── 校准
    ├── 未校准
    ├── 校准点不合理
    └── 温漂未补偿

DAC 输出异常
├── 参考电压/输出范围
├── 负载过重/容性负载
├── 未缓冲/建立时间不足
├── 更新时序/毛刺
└── 上电默认状态不安全
```

| 现象         | 优先检查                               |
| ------------ | -------------------------------------- |
| ADC 值飘     | 参考电压、输入阻抗、采样时间、噪声、地 |
| ADC 饱和     | 输入超范围、分压错误、保护二极管导通   |
| 读数整体偏移 | 偏置、参考电压、校准                   |
| 读数比例偏差 | 增益、分压电阻、Vref                   |
| 多通道串扰   | 采样时间不足、通道切换、输入滤波       |
| DAC 输出不准 | 负载、参考、缓冲、增益配置             |
| DAC 输出振荡 | 容性负载、运放稳定性、布线             |
| 上电毛刺     | DAC 默认值、使能顺序、滤波             |

## 测量方法

- 用高精度万用表/校准源确认输入电压和参考电压。
- 用示波器看 ADC 输入脚的建立过程、噪声和干扰。
- 用 FFT 分析 ADC 采样数据的噪声频谱。
- 用阶跃信号测量 DAC 建立时间和过冲。
- 用电流探头观察 DAC 带负载时的输出电流。
- 在高温/低温下重复测量，确认温漂。

## 设计检查清单

- 输入电压范围、共模范围和耐压确认。
- Vref 来源、精度、温漂和去耦确认。
- 采样时间与源阻抗匹配。
- 多通道切换留足建立时间。
- 输入滤波截止频率合理。
- 保护电路不影响高阻信号。
- ADC 地/参考地与数字地处理合理。
- 校准点和校准流程明确。
- DAC 输出负载、缓冲和容性负载稳定。
- 上电/复位时 DAC 输出安全。
- 量产测试包含参考、零点和满量程校验。

## 最小实验

1. 用精密电源输入 0%、25%、50%、75%、100% 满量程，记录 ADC 原始值和误差。
2. 改变输入源阻抗（1 kΩ/10 kΩ/100 kΩ），观察采样时间和读数变化。
3. 在 PWM 工作时采样 ADC，比较同步采样和异步采样的噪声。
4. DAC 输出阶跃，测量建立时间、过冲和毛刺。
5. DAC 带 1 kΩ/10 kΩ/100 kΩ 负载，测量输出电压跌落。
