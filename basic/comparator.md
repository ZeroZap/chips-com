# Comparator

## 定位

比较器（Comparator）把两个模拟电压进行比较，并输出数字高低电平：

```text
V+ > V-  -> 输出高（或低，取决于极性/接法）
V+ < V-  -> 输出低（或高）
```

它和运放（Op-Amp）的区别：

| 项目 | 比较器 | 运放 |
| --- | --- | --- |
| 工作状态 | 开环/正反馈，饱和输出 | 通常闭环负反馈 |
| 输出 | 数字逻辑电平 | 模拟电压 |
| 速度指标 | 传播延迟 | 增益带宽/压摆率 |
| 用途 | 阈值检测、过零、窗口 | 放大、滤波、缓冲 |

比较器常用于：

- 过压/欠压/过流检测。
- 电池低电量告警。
- 零交叉检测。
- 光耦/霍尔/红外信号整形。
- 正弦波转方波。
- 窗口比较和电源监控。
- 替代 ADC 做简单阈值判断。

## 核心参数

| 参数 | 含义 | 影响 |
| --- | --- | --- |
| Input Offset | 输入失调电压 | 阈值误差 |
| Input Bias Current | 输入偏置电流 | 高阻信号误差 |
| Common-Mode Range | 共模输入范围 | 超出后比较错误 |
| Propagation Delay | 传播延迟 | 响应速度 |
| Hysteresis | 迟滞 | 抗抖动/噪声 |
| Output Type | 推挽/开漏 | 上拉、电平匹配 |
| Supply Range | 供电范围 | 与逻辑电平兼容 |
| Power Consumption | 功耗 | 电池/低功耗场景 |

## 迟滞

没有迟滞时，输入在阈值附近抖动会导致输出反复翻转：

```text
VIN 在 VREF 附近有噪声
-> 输出高/低反复跳变
-> 中断风暴、计数器误增、功耗上升
```

迟滞通过正反馈或内部配置实现：

```text
VTH+ = 上限阈值
VTH- = 下限阈值
Hysteresis = VTH+ - VTH-
```

设计原则：

- 迟滞宽度大于输入噪声峰峰值。
- 迟滞不能大到影响测量精度/响应时间。
- 高阻输入要加滤波和合适的偏置。
- 机械/慢变信号优先加迟滞 + RC。

## 输出类型

### 推挽输出

- 可主动拉高/拉低。
- 边沿快，驱动能力强。
- 不能直接线与多个输出。

### 开漏输出

- 只能主动拉低，高电平靠上拉。
- 适合不同电压域、线与中断。
- 上拉电阻影响上升沿和功耗。
- 多个开漏输出可以共享一根线。

开漏上拉计算：

```text
t_rise ≈ 2.2 × R_pullup × C_load
```

## 内部比较器

很多 MCU 内置比较器，常见功能：

- 可选正/负输入引脚。
- 内部参考电压/分压。
- 可配置迟滞。
- 输出极性。
- 输出到定时器/中断/ADC。
- 低功耗模式唤醒。
- 窗口比较器（部分型号）。

使用内部比较器时注意：

- 输入引脚要配置为模拟模式。
- 内部参考的精度和温漂。
- 比较器输出到内部外设的路由。
- 休眠时的偏置/唤醒时间。
- 输入共模范围。

## 外部比较器

外部比较器适合：

- 需要更高速度/精度。
- 需要独立供电/宽共模。
- 需要开漏/推挽特定输出。
- 需要车规/工业级认证。
- MCU 内部比较器数量不够。

选型关注：

```text
传播延迟
输入失调
共模范围
迟滞
输出类型
供电/功耗
封装/温度等级
```

## 窗口比较器

窗口比较器判断输入是否在 `[VL, VH]` 内：

```text
VIN < VL  -> 欠压
VL <= VIN <= VH -> 正常
VIN > VH  -> 过压
```

实现方式：

- 两个比较器 + 逻辑门。
- 专用窗口比较器芯片。
- MCU 内部比较器 + 软件组合。

常用于电源监控、电池管理、故障保护。

## 零交叉检测

零交叉比较器把交流信号转换为方波：

```text
VIN > 0 -> 输出高
VIN < 0 -> 输出低
```

注意：

- 输入需要限幅/保护。
- 过零附近的噪声需要迟滞或滤波。
- 传播延迟会影响相位。
- 高阻分压要保证共模范围。

## 常见故障树

```text
比较器输出不翻转
├── 供电/使能
├── 输入共模超范围
├── 参考电压错误
├── 输出上拉缺失（开漏）
├── 引脚复用/模拟模式
└── 比较器未使能

输出反复抖动
├── 输入噪声
├── 迟滞不足
├── 阈值接近噪声带
├── 地/电源干扰
└── 高阻输入拾取干扰

阈值不准
├── 输入失调
├── 参考电压误差
├── 分压电阻误差
├── 输入偏置电流
└── 温度漂移

响应太慢
├── 传播延迟
├── 输入压摆率不足
├── 输出上拉过大
└── 滤波时间常数过大
```

| 现象 | 优先检查 |
| --- | --- |
| 输出不翻转 | 供电、共模、参考、上拉、引脚复用 |
| 输出抖动 | 迟滞、滤波、地噪声、阈值 |
| 阈值偏差 | 失调、参考、分压、偏置电流 |
| 响应慢 | 传播延迟、压摆率、上拉、滤波 |
| 低功耗异常 | 比较器偏置、唤醒时间、电源 |
| 高温异常 | 失调/参考温漂、输入漏电 |

## 测量方法

- 用可调电源扫描输入，记录输出翻转点和迟滞宽度。
- 用示波器看输入/输出延迟和抖动。
- 用万用表确认参考电压和分压。
- 用噪声源/干扰源验证迟滞和滤波。
- 高低温下重复阈值测量。

## 设计检查清单

- 输入共模范围覆盖实际信号。
- 参考电压/分压精度满足阈值要求。
- 迟滞宽度大于噪声峰峰值。
- 开漏输出有合适上拉。
- 输入有保护/限幅/滤波。
- 输出电平和后级逻辑兼容。
- 传播延迟满足系统响应。
- 低功耗场景确认偏置和唤醒时间。
- 关键阈值有测试点/校准方式。
- 量产测试覆盖翻转点、迟滞和输出电平。

## 最小实验

1. 用可调电源扫描输入，测量上/下翻转阈值和迟滞。
2. 在阈值附近注入噪声，比较有无迟滞的输出抖动。
3. 用开漏比较器加上拉，测量上升沿和功耗。
4. 搭建窗口比较器，验证欠压/正常/过压三种状态。
5. 测量输入阶跃到输出翻转的传播延迟。
