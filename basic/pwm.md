# PWM

## 定位

PWM（Pulse Width Modulation，脉宽调制）用固定周期内的高电平比例表示平均功率或控制量。它本身不是通信协议，但广泛用于：

- LED 调光、背光。
- 蜂鸣器、无源蜂鸣器发声。
- 直流电机调速、加热控制。
- 舵机角度控制。
- 风扇调速。
- 经 RC/LC 滤波后作为低成本 DAC。
- 开关电源和功率变换控制。

PWM 的工程核心是三个量：**频率、占空比、分辨率**，以及它们与定时器时钟、负载特性和 EMI 的平衡。

## 核心参数

| 参数       | 含义         | 典型关注                       |
| ---------- | ------------ | ------------------------------ |
| Frequency  | PWM 频率     | 闪烁、噪声、开关损耗、控制带宽 |
| Period     | 周期         | 与频率互为倒数                 |
| Duty Cycle | 占空比       | 高电平时间 / 周期              |
| Resolution | 占空比分辨率 | 可调的最小步进                 |
| Polarity   | 极性         | 高有效或低有效                 |
| Dead Time  | 死区         | 互补输出时防止直通             |
| Jitter     | 抖动         | 边沿位置不稳定                 |
| Slew Rate  | 斜率         | EMI、过冲和开关损耗            |

## 定时器计算

以常见定时器为例：

```text
PWM 频率 = TimerClock / ((PSC + 1) × (ARR + 1))
占空比   = CCR / (ARR + 1)
分辨率   = log2(ARR + 1) 位
```

其中：

- `PSC` 是预分频。
- `ARR` 是自动重载值。
- `CCR` 是比较值。

示例：定时器时钟 72 MHz，PSC=71，ARR=999：

```text
计数时钟 = 72 MHz / 72 = 1 MHz
PWM 频率 = 1 MHz / 1000 = 1 kHz
分辨率   = log2(1000) ≈ 9.97 bit
```

如果希望 20 kHz、12 位分辨率：

```text
ARR + 1 = 4096
计数时钟 = 20 kHz × 4096 = 81.92 MHz
PSC = round(TimerClock / 81.92 MHz) - 1
```

实际可用频率和分辨率受定时器位宽、时钟源和分频器限制。高频与高分辨率通常不可兼得。

## 占空比边界

占空比不是任意值都能稳定输出：

- `CCR = 0` 通常输出 0% 或 100%，取决于极性和比较模式。
- `CCR = ARR + 1` 可能产生全高或溢出行为。
- 极小占空比可能被输出级、驱动电路或负载吃掉。
- 极大占空比可能无法完全关断。

软件应把占空比限制在 `[min_duty, max_duty]`，并对边界做显式处理。

## 更新与影子寄存器

很多定时器支持预装载/影子寄存器：

- 写入 `CCR` 后，在更新事件时生效。
- 可以避免中途改占空比产生窄脉冲。
- 多通道同步更新时尤其重要。

如果软件频繁改占空比，建议：

1. 使能 `CCR` 预装载。
2. 在更新中断或同步事件中批量更新。
3. 避免在 PWM 输出过程中直接改 `ARR`。

## 极性与负载

| 负载     | 常见需求       | 注意                     |
| -------- | -------------- | ------------------------ |
| LED      | 高有效或低有效 | 低有效时注意上电默认状态 |
| 蜂鸣器   | 方波频率       | 无源蜂鸣器需要特定频率   |
| 直流电机 | 高频 PWM       | 续流、驱动管、死区       |
| 舵机     | 50 Hz 周期     | 脉宽通常 1~2 ms          |
| 加热丝   | 低频 PWM       | 继电器/固态继电器寿命    |
| 风扇     | 20~30 kHz      | 避免可听噪声和轴承共振   |

PWM 输出通常不能直接驱动功率负载，需要三极管、MOSFET、驱动 IC 或继电器。感性负载必须加续流二极管或吸收电路。

## 舵机控制

常见舵机：

```text
周期：约 20 ms（50 Hz）
脉宽：约 1.0 ms ~ 2.0 ms
中位：约 1.5 ms
```

不同舵机的脉宽范围、死区和最大角度不同，必须以手册为准。工程上注意：

- 上电时先输出中位或安全位置。
- 限制脉宽范围，避免机械限位。
- 多舵机同时动作时考虑电源电流。
- 舵机信号线远离电机电源线。

## LED 调光

LED PWM 频率选择：

- 低于 100 Hz 可能被人眼察觉闪烁。
- 1~3 kHz 常见，兼顾调光线性和开关损耗。
- 摄像头拍摄时可能出现频闪，需要更高频率或同步。
- 深度调光时低占空比的线性度会变差。

人眼对亮度的感知不是线性的，调光曲线通常需要 Gamma 校正：

```text
duty = (brightness / max_brightness) ^ gamma
```

`gamma` 常取 2.2 左右，具体按产品观感调整。

## PWM 作为 DAC

PWM + RC 低通滤波可以得到低成本模拟电压：

```text
Vout ≈ VDD × duty
截止频率 fc = 1 / (2πRC)
```

设计要点：

- PWM 频率远高于 RC 截止频率。
- 纹波与 `VDD`、占空比、RC 时间常数有关。
- 输出阻抗较高，后级可能需要运放缓冲。
- 负载会改变 RC 时间常数和输出电压。

如果需要较高精度，优先使用真实 DAC；PWM DAC 适合设定值、偏置和低速控制。

## 互补输出与死区

电机半桥/全桥驱动常使用互补 PWM：

```text
CH1  高侧驱动
CH1N 低侧驱动
```

死区用于避免上下管同时导通：

```text
高侧关断后，等待 t_dead，再开通低侧
低侧关断后，等待 t_dead，再开通高侧
```

死区太小会直通，太大则降低有效占空比和效率。死区时间按驱动管、栅极电阻和开关速度计算，并用示波器确认。

## 常见故障树

```text
PWM 无输出
├── 定时器时钟未使能
├── 引脚复用不是 AF/PWM
├── 定时器未启动
├── 输出通道未使能
├── 刹车/故障输入被触发
└── 低功耗或安全功能关闭了定时器

PWM 频率不对
├── 时钟源错误
├── PSC/ARR 计算错误
├── 定时器位宽溢出
└── 中心对齐/边沿对齐模式不同

PWM 占空比不对
├── CCR 写错通道
├── 预装载未更新
├── 极性反了
├── 比较模式错误
└── 死区/互补输出影响
```

| 现象           | 优先检查                                   |
| -------------- | ------------------------------------------ |
| 没波形         | 时钟、复用、通道使能、定时器启动、刹车输入 |
| 频率不对       | 时钟源、PSC、ARR、计数模式                 |
| 占空比反了     | 极性、比较模式、低有效驱动                 |
| 占空比跳变     | 预装载、更新事件、软件竞争                 |
| 电机发热/直通  | 死区、驱动管、栅极电阻、续流               |
| LED 闪烁       | PWM 频率、调光曲线、电源纹波               |
| 蜂鸣器声音不对 | 频率、占空比、驱动方式                     |
| 输出过冲/EMI   | 斜率、串阻、PCB 走线、负载                 |

## 测量方法

- 示波器测量周期、脉宽、上升/下降时间和过冲。
- 用占空比统计功能确认长时间稳定性。
- 电流探头观察电机/感性负载的续流和浪涌。
- 逻辑分析仪确认多通道相位和死区。
- 摄像头场景检查 LED 频闪和快门同步。

## 设计检查清单

- 定时器时钟和计数模式确认。
- 频率、ARR、PSC、CCR 计算正确。
- 占空比边界和最小/最大限制明确。
- 引脚复用和输出通道正确。
- 极性与驱动电路匹配。
- 预装载和更新事件使用正确。
- 互补输出死区经过测量确认。
- 感性负载有续流/吸收。
- 大电流负载有独立驱动和电源裕量。
- EMI 敏感场景控制斜率、串阻和布线。
- 上电/复位/低功耗时输出处于安全状态。

## 最小实验

1. 输出 1 kHz、50% 方波，测量频率和占空比误差。
2. 扫描 1%~99% 占空比，记录 LED 亮度和电流。
3. 输出 50 Hz 舵机信号，测量 1.0/1.5/2.0 ms 脉宽。
4. 用 10 kΩ + 100 nF 做 RC 滤波，测量 PWM DAC 纹波。
5. 配置互补 PWM 和死区，用双通道示波器测量死区时间。
